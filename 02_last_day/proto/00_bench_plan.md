# Bench plan — прототипирование Last Day

**Дата**: 2026-07
**Статус**: active
**Базируется на**: Decision 06 (combine-архитектура), Decision 08 (refined FX palette), audit/20-22 (инженерия/акустика Last Day)

---

## Принцип

**Сначала прототипируем то, что может убить концепт, а не то, что приятно паять.**

Узлы ранжированы по «неизвестность × последствия»:

| Категория | Узлы | Правило |
|---|---|---|
| **A — экзистенциальные** | Capacitive oil pickup; Tongue-резонатор | Если не работают — концепт модуля пересматривается. Прототипировать первыми, параллельно |
| **B — рабочие риски** | Motor+PLL на низких RPS; поведение масляной плёнки; Solar amp | Если не работают — меняется реализация, концепт живёт |
| **C — известная схемотехника** | Pultec shelves; TAR/CICADA/EMBER; MELT/BBD; perform-switches; solenoid driver | Риск ≈ 0. Не паять, пока категория A не дала «go» |

## Карта зависимостей

```
Rig #1 (oil pickup) ──┬─→ Rig #3 (motor+PLL) ──→ M1: ИНТЕГРАЦИЯ — делэй звучит
                      │
Rig #2 (tongue) ──────┤   (независим, параллельно с #1)
                      │
Rig #4 (solar) ───────┴─→ Категория C (Pultec EQ, TAR/CICADA/EMBER, perform)
                              └─→ M2: полный breadboard-франкенштейн
                                    └─→ M3: KiCad rev A
```

## Milestones

- **M0** — Rig #1 и #2 дали go/no-go. Решение: продолжаем как задумано / включаем fallback.
- **M1** — Rig #1 + Rig #3 собраны вместе: гитара на входе, эхо на выходе. Первый настоящий oil-can delay. Записать аудио, датировать.
- **M2** — Полный breadboard: pickup + motor + tongue-EQ + solar + 1–2 character FX. Всё «франкенштейном», но играет.
- **M3** — Схема в KiCad rev A по результатам M2 (номиналы — измеренные, не расчётные).

## Инструментарий

Минимальный набор (без осциллографа можно жить, но тяжело):

- **Осциллограф** — любой, хоть DSO138 ($25) для нулевой итерации; лучше 2-канальный USB (Hantek ~$70).
- **Звуковая карта + REW/Audacity** — «бедный анализатор спектра»: свипы, THD, SNR, частотные отклики. Бесплатно и точнее дешёвого скопа на аудиочастотах.
- **Генератор сигналов** — функция REW/смартфон-приложение через звуковуху, либо XR2206-kit ($8).
- **Мультиметр** — есть у всех.
- **Лабораторный БП** ±12В — или два 12В адаптера + виртуальная земля.

## Дисциплина: чего НЕ делать до M0

- Не рисовать PCB.
- Не покупать корпуса, ручки, футсвичи.
- Не прототипировать HEAT (вязкость проверяется маслом из холодильника vs с батареи).
- Не собирать stereo dual-tap (второй электрод = copy-paste после «go»).
- Не трогать Last Night (его reverb-ядро прошло аудит, путь в прототип понятен, ничего не блокирует).
