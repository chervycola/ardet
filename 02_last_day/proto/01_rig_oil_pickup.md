# Rig #1 — Capacitive oil pickup testbed

**Категория**: A (экзистенциальный риск)
**Вопрос**: переносит ли масляная плёнка на вращающемся диске электростатическую поляризацию от write-электрода к read-электроду с измеримым SNR?
**Если no-go**: fallback-ветки — (а) магнитный tract (D02 D2 option A, архив), (б) BBD-делэй с oil-hydrophone как colour-фильтром.

## Сборка

```
                 write pad          read pad
                 (FR4 медь)         (FR4 медь)
                    ▼ зазор ~1мм       ▼
   ═══════════════════════════════════════════  ← диск (GND через щётку/ось)
              ▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒
              ▒▒▒▒▒ масляная ванна ▒▒▒▒          ← диск погружён нижней частью
              ▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒
```

- Диск заземлён (щётка на ось или подшипник, проверить контакт мультиметром < 10Ω).
- Write и read pads на регулируемых стойках, стартовый зазор 1.0мм (щуп).
- Углы: write на «выходе» диска из ванны, read через 90° по ходу вращения.
- Read: pad → коакс (короткий!) → OPA1642 unity-gain high-Z buffer (10МΩ bias) → gain ×10 → звуковуха/скоп.
- Всё в металлической коробке/фольге — стенд ловит 50Гц как антенна, экранирование обязательно.

## Процедура

### Тест 1 — Static transfer (диск стоит)
Синус 1кГц на write, читаем read. Ожидание: прямая ёмкостная связь write→read (паразитная). **Записать её уровень — это наш «нулевой фон»**, всё полезное должно быть выше него. Если паразитная связь огромна — разнести pads дальше / добавить заземлённый guard-trace между ними.

### Тест 2 — Rotating transfer (главный тест)
Диск вращается (начать с 33 RPM = 0.55 RPS). Синус 1кГц, write ±5В.
- Есть ли на read компонента, **задержанная** относительно write? Проверка: подать burst (5 циклов 1кГц), смотреть время прихода на read. Ожидаемая задержка для 90° при 0.55 RPS ≈ **450мс**.
- Если burst виден с задержкой — **концепт жив**. Померить амплитуду.

### Тест 3 — Матрица параметров
Для каждой комбинации записать амплитуду read и SNR:

| Параметр | Значения |
|---|---|
| Write уровень | ±5В / ±10В / ±20В |
| Скорость | 0.55 / 0.75 RPS (+ выше, если привод позволяет) |
| Масло | минеральное / касторовое / глицерин |
| Зазор write | 0.5 / 1.0 / 2.0 мм |
| Площадь pad | 20×20 / 20×40 мм |
| Частота | свип 100Гц–5кГц (REW) |

### Тест 4 — Multi-revolution persistence
Burst на write → write замолкает → считаем, сколько раз burst возвращается на read (оборот за оборотом) до ухода под шум. **Это go/no-go для «800мс+ через касторовое масло»** и данные для FEEDBACK-дизайна.

### Тест 5 — Практические гадости
- Разбрызгивание масла на «максимальной» скорости привода.
- Равномерность плёнки: амплитуда read стабильна оборот к обороту или «плавает» (нужен ли wiper)?
- Дрейф за 30 минут непрерывной работы (масло греется от трения?).

## Go / No-go

| Критерий | Go | Борьба | No-go |
|---|---|---|---|
| SNR @ 1кГц, лучшая комбинация | ≥ 30dB | 15–30dB (нужен лучший preamp / больше write) | < 15dB |
| Полоса | до ≥ 3кГц | 1–3кГц (делэй будет тёмным — может, и ок) | < 1кГц |
| Persistence (касторовое) | ≥ 2 оборота | 1–2 | сигнал не живёт и одного оборота |
| Стабильность плёнки | ±3dB оборот к обороту | ±10dB | хаос |
