# 02 · Last Day — delay/amp/EQ-финализатор (Phase 2)

Комбайн «раскалённого полудня»: oil-can delay (capacitive, Tel-Ray) + solar amp (LED baseline + солнечная модуляция) + resonant EQ с tongue-резонатором + hot palette FX (TAR / CICADA / EMBER). Вторая разработка очереди: ship Phase 2 (Months 9–27). Формат: 40HP Eurorack + big-box pedal. Diptych-пара к Last Night.
