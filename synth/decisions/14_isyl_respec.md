## Контекст

Канон v6.5 описывает модуль 1 как LED-tonewheel: диск ∅60–80мм, LED+фотодиод,
BLDC с оптическим энкодером и PLL, 16 HP, два голоса (LIGHT + контактный DUST).
Приоритет по audit/30 — Phase 3-4, R&D 6–9 месяцев после ship Last Night.

R&D-сессия 2026-07 (дизайн + расчёты + прошивка) вывела архитектуру на
следующее поколение. Ключевой внешний фактор: Decision 15 вводит оптическую
шину серии, для которой ISYL — источник света; LED физически не может
дать коллимированный луч для зеркального тракта, feedback-петли и
межмодульной передачи.

## Что фиксируется

1. **Источник света — лазер** 650 нм, ≤5 мВт (class 3R), с модуляцией тока
   (= бесплатный оптический VCA / AM IN до всякой механики).
2. **Сервоконтур строя — цифровой**: gimbal BLDC + SimpleFOC (velocity loop)
   + магнитный энкодер AS5047P + RP2040. Экспо-конвертация, глайд и
   auto-gearshift — в прошивке. **Аудиотракт остаётся полностью аналоговым** —
   цифра касается только мотора. Прошивка v0.1 написана и приложена.
3. **Диск ∅100–120 мм**, три оптические дорожки (8/16/32 прорезей = f/2f/4f,
   drawbar-микс), строб-метки по ободу (кварцевый лок, видимый глазом),
   пыльное кольцо для DUST-стилуса. Печать на плёнке (grayscale waveforms)
   как основной формат, резка как премиум.
4. **Auto-gearshift**: октавные скачки переключением дорожки (мгновенно,
   без инерции), внутри октавы — физика мотора. Переключение мультиплексора
   по углу диска (в тёмной зоне) — анти-щелчок без дополнительного железа.
5. **Четыре голоса**: LIGHT (tonewheel) + MIRROR (зеркало на мембране,
   knife-edge, optical feedback) + CLOCK (низкие обороты = секвенсор) +
   **DUST (канонный пьезо-стилус — сохраняется без изменений)**.
6. **Инерция диска = физическое портаменто**; FOC-торможение даёт
   симметричный глайд, асимметричный "духовой" режим — флаг прошивки.

## Явные отказы

- **LED как источник** — нет коллимации: невозможны зеркальный тракт,
  feedback-осциллятор, шина Decision 15, FOCUS-контроль тембра линзой.
- **Оптический энкодер (1 метка/об)** — обновление петли раз в оборот,
  на низких RPM петля разваливается. AS5047P даёт 14 бит угла на кГц.
- **Аналоговый PLL (CD4046)** — мотор+диск = интегратор с большой инерцией,
  стабильность петли на диапазоне 300–12000 RPM не достигается разумной
  ценой. Строй при цифровой петле кварцованный по построению
  (нет температурного дрейфа — главного проклятия аналоговых VCO).
- **ESC-привод (гоночный FPV)** — коггинг и вой на низких оборотах;
  gimbal-мотор с FOC плавен во всём диапазоне.

## Смена приоритета (требует sign-off)

Канонный roadmap ставит ISYL в Phase 3-4. Предлагается **параллельный
Stage 0 трек** (~$60–80 железа, выходные): сервопетля на макетке по
протоколу ISYL_PROJECT §3. Обоснование в духе RISK_ASSESSMENT:
- де-рискует **два** модуля — тот же контур BLDC+точная скорость нужен
  Last Day (масляный диск, PLL-lock по канону §7);
- не конкурирует за ресурсы с Last Night (другой стек: механика/оптика
  vs акустика пластин);
- критерии прохождения гейта заданы численно (лок ±6 центов, октава
  вверх <300 мс, вниз <500 мс, нет слышимого коггинга <500 RPM).

## Открытое (не блокирует Stage 0)

- HP: 16 (канон) vs ≥24 (диск 100 мм). Варианты: диск 80 мм, вертикальная
  установка, принять 24.
- Семантика GATE: стоп мотора (драматично, медленно) vs мьют лазера
  (мгновенно, = AM).
- Нормализация MIRROR → FEEDBACK.
- Питание мотора: шина +12В (пик 1–1.5 А при разгоне — риск для слабых
  кейсов, см. ISYL_PROJECT §6.9) vs опциональный barrel-jack.
