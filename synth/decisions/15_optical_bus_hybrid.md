# Decision 15 — Оптическая шина серии: гибридная топология + retina-плата

**Дата**: 2026-07-07
**Статус**: locked (топология — зафиксирована пользователем); retina-спека — draft до KiCad
**Тип**: системная архитектура серии (вторая шина) + новый стандартный узел
**Ссылки**: `14_isyl_respec.md`, `../SYSTEM_SUICIDE.md` (§1, §4, §5, §7, §8),
`../PCB_DESIGN_SPEC.md` (retina = кандидат в PCB inventory)

## Контекст

Свет уже присутствует в серии фрагментарно: LED/лазер tonewheel (модуль 1),
вактролы (бывш. Is My-концепт), PSD-считывание маятника (модуль 5),
solar amp (модуль 7), стеклянные маятники с фотодиодами по четырём сторонам
(FAS-сессия 2026-07). Решение превращает совпадение в архитектуру:
**у System Suicide две шины — электрическая и световая.**

Ключевое свойство: частота (питч) — инвариант оптического тракта. Всё, что
цепь делает со светом (преломление, дым, рука, зеркала), — амплитудная
модуляция и waveshaping; период основного тона сохраняется. Приёмник в любой
точке цепи меряет строй всей системы целиком.

## Что фиксируется

### 1. Топология — гибрид (locked)

- **Внутри модулей — ретрансляция**: каждый оптический модуль принимает свет
  собственной retina-платой, обрабатывает электрически, излучает собственный
  лазер дальше. Юстировка локальна (заводская), мощность полная на каждом
  участке, обрыв луча локален, каждый модуль самодостаточен соло.
- **Сквозные байпас-окна**: у каждого оптического модуля пара окон-портов,
  через которые луч соседа проходит транзитом в обход перерождения.
  Перформанс-режим: единый луч через всю цепь, через дым, убиваемый ладонью.
  Хрупкость сквозной топологии = драматургия, включаемая осознанно.

### 2. Retina-плата (draft, → KiCad)

Стандартный кирпич-приёмник, проектируется один раз (аналогия: пассивный
картридж Decision 11):

- Фотодиод BPW34 (посадка также под SFH213), джампер режима
  (photovoltaic / photoconductive c обратным смещением).
- TIA на OPA2134 (bugdet-вариант TL072), R_f выбором джампера
  10к/100к/1М, C_f 4.7–10 пФ.
- Три выхода: **AUDIO** (AC-coupling), **BRIGHT CV** (LPF ~10 Гц, огибающая
  яркости), **GATE** (компаратор с гистерезисом).
- Посадка под knife-edge (лезвие на юстировочном винте) и резьба под
  тубус/коллиматор/красный фильтр (борьба с внешней засветкой).
- Габарит ориентировочно 25×40 мм, питание ±12В, экранируемая зона TIA.
- Опция «retina+глаз»: населённый вариант с драйвером лазера (передатчик
  ретрансляции) на той же плате — один P/N, два варианта сборки.

### 4. Двухконтурная калибровка строя

Внутренняя быстрая петля — энкодер (мс-реакции, невозможен вразнос).
Внешняя медленная петля истины — конечный приёмник: меряет реальную
частоту звука, раз в секунды подстраивает калибровку внутренней
(архитектура GPS-дисциплинированного генератора). Обязательная логика
«луч оборван → freeze last value». Для безэнкодерных голосов внешний
контур работает соло.

## Явные отказы

- **Чистый сквозной луч** как единственная топология — юстировка через
  несколько корпусов на вибрирующей сцене, бюджет 5 мВт не переживает
  3–4 отвода, один взмах руки гасит цепь ниже по течению.
- **Чистая ретрансляция без окон** — теряется перформативная возможность
  единого физического луча (дым, рука, свет как патч-кабель).
- **Один общий приёмник на серию вместо платы-кирпича** — четыре модуля
  требуют приёмников; четыре разные схемы = четырёхкратная отладка.

## Безопасность (наследуется всеми модулями шины)

Class 3R (≤5 мВт) максимум. Внутри корпусов лучи терминируются на
фотодиодах/ловушках. Наружу — только через байпас-окна, открытие которых —
осознанное действие перформера; в доках модулей — предупреждение.
Юстировка — в очках. Никогда не смотреть в луч через оптику.
