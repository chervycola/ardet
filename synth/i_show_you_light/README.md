# I SHOW YOU LIGHT — модуль 1 / R&D директория

Оптический tonewheel-осциллятор с кварцованным строем. Источник света
оптической шины серии (Decision 15).

**Статус**: активный R&D, Stage 0 (сервопетля) — железо заказывается.
Канон-статус: re-spec §1 SYSTEM_SUICIDE.md через `../decisions/14_isyl_respec.md`
(proposed, lock после прохождения Stage 0 гейта).

## Читать в порядке

1. `../decisions/14_isyl_respec.md` — что и почему меняется относительно канона.

3. `ISYL_PROJECT.md` §3 — Stage 0: BOM, распиновка, порядок оживления,

   retina-плата.
