# Is My — схемотехника узлов (макетный уровень)

Узловые схемы с номиналами. Все значения — **стартовые для макета**: финальная подстройка нелинейных узлов (ядро, фильтр) — на breadboard (R2/R14/R16). ASCII-схемы упрощённые, опускают шунты питания (0.1µF на каждый ОУ/OTA) и часть защит.

Опирается на `02_technical.md` (архитектура) и `signal_flow.svg` (тракт).

Обозначения: `R`=резистор, `C`=кондёр, `Q`=MOSFET, OTA=LM13700 (половина), номиналы в Ω/F если не указано иное.

---

## S0. Питание и опора

- Вход ±12V Eurorack. На плате:
  - `+12A / −12A` — аналог. LC-фильтр на входе: феррит + 47µF + 100nF на каждую шину.
  - `+5B` ← **buck TPS54202/LMR51420** из +12 (не LDO: шина кормит VBUS пульта ~150-250 мА,
    на LDO это ~1.4 Вт тепла). Выход buck: L 10µH, Cout 22µF ×2; раскладку buck держать
    у входного разъёма, подальше от MOSFET-ядра и VCF (S11.4).
  - `+3.3D` ← **MCP1700** из +5B (MCU, ЦАП-цифра, MAX3421E).
  - `Vref +4.096` ← **REF3040**, Cout 1µF + 100nF, буфер на OPA192 при раздаче на несколько узлов.
- Виртуальная земля аналога **AGND = 0V** (питание биполярное, виртуальная середина не нужна). Сигнальный размах ±5V ном.
- Цифровая земля DGND соединяется с AGND в одной точке у входного разъёма (звезда), феррит между ними.

## S2. Входной буфер + INPUT DRIVE (VCA)

```
AUDIO IN ──C1──┬── R2 ──┬───|+\ U1 (OPA1642)
              R1       │   |  >──┬─── buf_out ──► к DRIVE-VCA и clean tap
             100k    BAT54S      │
              │     (к ±12)   ┌──|−/
             GND               └── R3 ──┘   (×1, неинвертирующий)
C1=1µF film  R2=1k(защита)  R3=0 (или 1k/1k для ×2)
```

- Буфер ×1, Zin=100k. `C1` 1µF плёнка (срез ~1.6 Гц). `BAT54S` кламп к рельсам.
- **INPUT DRIVE** — OTA-VCA (LM13700) с линеаризующими диодами (чистое усиление до клипа ядра):

```
buf_out ──R_a(10k)──┬──► OTA-in(+)   ; диод-lin вкл.
                   R_b(1k)            ; делитель ≈11:1 — вход OTA малосигнальный
                    │
                   GND
Iabc ◄── V→I конвертер (ОУ + NPN, эмиттерный R к −12): Iabc = V_drive_ctrl / R_conv
OTA_out ──► R_load(22k) ──► U2 буфер ──► drive_out
```
- Усиление `Av ≈ (R_b/(R_a+R_b))·gm·R_load`, `gm ≈ 19.2·Iabc`. `R_conv=10k` → при `V_drive_ctrl` 0…+5V Iabc = 0…0.5 мА → gm до ~9.6 мС → **Av 0…~×19** (вгоняет в нелинейность ядра).
- **Управление Iabc — только через V→I конвертер** (ОУ держит эмиттер NPN на V_ctrl/R_conv). Прямой резистор с CV на вывод Iabc не годится: вывод сидит на −12+1.4В, ток не доходит до нуля → VCA не закрывается.
- `V_drive_ctrl` = сумма DRIVE-CV (с пульта/внешн., §S9).
- Линеаризующие диоды LM13700 включены (вывод 2/15, ток ~0.5-1 мА) — DRIVE должен усиливать чисто, грязь — дальше в MOSFET.

## S3. Variable PRE-HPF (бас ↔ fuzz)

ВЧ-фильтр 1-го порядка с управляемым срезом на OTA (OTA как управляемый резистор):

```
drive_out ──C_hp──┬───► next (MOSFET core / route)
                  │
                  R_var (OTA как VCR)
                  │
                 GND
f_hpf = 1/(2π·R_var·C_hp) ;  R_var ∝ 1/gm ∝ 1/Iabc
```
- `C_hp = 100nF`. Для `f_hpf` 20 Гц…2 кГц нужен `R_var` **80k…800Ω** (f и R обратно пропорциональны: 80k→20 Гц, 800Ω→2 кГц).
- OTA как VCR: `R_var ≈ 1/(k·gm)` (k — входной делитель OTA) → gm 12.5µS…1.25mS → **Iabc ≈ 0.65µ…65µА**, от `V_hpf_ctrl` (knob + HPF-CV, §S9) через V→I конвертер (как в S2).
- CCW (Iabc мал, R_var велик) → срез 20 Гц → весь низ в клип (жирно). CW → срез растёт → тонкий fuzz.
- Альтернатива (проще, без OTA): сдвоенный потенциометр 100k + переключаемые C — но теряем CV. OTA оставляем ради CV.

## S4. Двухкаскадное MOSFET-ядро + термосерва  ⟵ центр

Два logic-level N-MOSFET (донорские ESC; на макете — **BS170 / 2N7000 / IRLML2502**). `Vdd_core = +9V` (отдельный LDO из +12, чтобы клип был предсказуемым по уровню).

### S4.1. Stage 1 — мягкое насыщение (common-source, класс A)

```
            +9 (Vdd_core)
             │
            Rd1 10k
             │
   in ─Cg1─┬─┤D
  (HPF out)│ │
         Rg1│ Q1 (N-MOS)  ──► drain1 ─Cs12─► Stage2
         1M │ │
   bias1 ───┘ │S
             Rs1 100   ──► к серве (sense Iq1)
             │
            GND
Cg1=100n  Rg1=1M  Rd1=10k  Rs1=100  Cs12=100n
```
- Рабочая точка: серва (S4.3) держит `Vdrain1 ≈ +4.5V` (≈Vdd/2) → класс A, мягкая квадратичная сатурация.
- `bias1` — суммирование: серва (медленно) + BIAS-CV пользователя (через 100k, §S9) сдвигает рабочую точку → симметрия клипа.
- Усиление ~ −gm·Rd1; на сигнале раскачка в нелинейность Vgs².

### S4.2. Stage 2 — жёсткий клип/компрессия

```
            +9
             │
            Rd2 22k
             │
 drain1 ─Cs12┬─┤D
         Rg2 │ │
         1M  │ Q2  ──► drain2 ─Rlp─Clp─► core_out (через LPF anti-fizz)
  bias2 ─────┘ │S
             Rs2 47   ──► serva2 (sense Iq2)
             │
            GND
Rd2=22k (больше gain)  Rs2=47 (меньше degeneration → жёстче)
Rlp=1k + Clp=330p → LPF ~480кГц… вернее anti-fizz ~ ставим Rlp=2k2 Clp=1n → ~72кГц; точное на макете
```
- Больший gain + меньшая дегенерация → раскачка `Q2` **в отсечку и насыщение**, сток клиппит у 0/+9 → жёсткая компрессия чисто на транзисторе.
- Серва2 держит `Vdrain2 ≈ +4.5V` в покое; на сигнале клиппинг симметричен/асимметричен по BIAS.
- На больших Drive — period-doubling (саб-октава): зависит от Cs12 и паразитной ОС; **подбор на макете (R2)**.

### S4.3. Термосерва (одна на каскад, дуальный OPA2188)

**Сенсим ток покоя на резисторе ИСТОКА** (не сток! — см. ловушку ниже):

```
V_Rs(n) = Iq·Rs ──R_i(1M)──┬──|−\ U_servo (OPA2188, инв. интегратор)
                          Cs(1µF) |  >── bias(n) ──► в gate-bias сумму каскада
                           │   ┌──|+/
                          GND  Vref_q(n)  (опора Iq: ЦАП кан. G + делитель)
τ = R_i·Cs = 1 c → угол ~0.16 Гц (аудио и бас не трогает)
Vref_q1 = 45 мВ  (Iq1=0.45 мА × Rs1=100)  → Vdrain1 ≈ 9 − 0.45мА·10k ≈ +4.5V
Vref_q2 ≈ 10 мВ  (Iq2=0.20 мА × Rs2=47)   → Vdrain2 ≈ +4.5V
```
- Полярность петли: `Iq` вырос → `V_Rs` > `Vref_q` → выход интегратора пошёл **вниз** → gate-bias вниз → `Iq` вниз. Отрицательная ОС ✓.
- **Ловушка:** сенс по НАПРЯЖЕНИЮ СТОКА в этой же топологии даёт **положительную** ОС (Vdrain падает при росте Iq — знак переворачивается). Если сенсить сток — нужен дополнительный инвертор. Поэтому — исток.
- Интегратор усредняет `V_Rs` (аудио-составляющая давится τ=1с), держит ток покоя → компенсирует дрейф `Vth` любого донорского MOSFET (адаптация под экземпляр, §6.3 концепта). OPA2188 (offset 25µV) достаточно точен даже для Vref_q2=10мВ.
- BIAS-CV пользователя суммируется в тот же узел gate-bias **после** сервы (R 100k от BIAS, R 100k от сервы → узел затвора). Серва держит среднее, пользователь модулирует вокруг.
- Диапазон серва-захвата по Vth: ~1…4 В (logic-level). Вне — отбраковка/другой слот.

### S4.4. Переключение топологии (мультиплексор режимов)

Те же `Q1/Q2` (донорские MOSFET) перекоммутируются между SHAPER / RING / GATE аналоговыми ключами под mute (S6/A7). Принцип §10 держится: в **каждом** режиме MOSFET физически переключает/искажает.

```
MODE (от MCU) ─► DG419 ×2-3:
  SHAPER : Q1→Q2 каскад (S4.1/S4.2), затворы от audio+bias
  RING   : Q2-затвор ◄ PWM-компаратор (S4.5); Q2 коммутирует тракт
  GATE   : Q2 как series-ключ ◄ gate-логика (S4.6)
```
- Ключи — DG419L (малый charge injection). Линии аудио рвутся/коммутируются только в окне mute (ramp VCA→0, S8/A7), иначе щелчок.
- Несущий VCO (S4.5) и компараторы/детектор (S4.6) — общие узлы, питаются всегда, но подключаются к Q только в своём режиме.

### S4.5. RING — ШИМ-кольцевая модуляция

MOSFET **буквально коммутирует** на частоте несущей, скважность ведёт аудио → боковые полосы.

**(а) Несущий VCO (треугольник, частота от DRIVE):**
```
            ┌──────────────┐
 Iabc ◄─V_drive_ctrl       │  (gm OTA ∝ Iabc)
        │                  │
   ─────► OTA_int ─┬─ C_vco ┴─ tri_out ──┬──► на компаратор (S4.5б)
                  │  1n               │
                  └──── U_schmitt ◄────┘  (LM311 + гистерезис Rh)
f_c ≈ Iabc/(4·C_vco·V_hys) ;  Iabc 1.6µ…80µА → f_c 200 Гц…10 кГц
C_vco=1n, V_hys≈2В (Rh: 100k/100k делитель ОС)
```
- OTA-интегратор (LM13700) заряжает `C_vco`, Шмитт (LM311) переключает знак тока → треугольник. `Iabc` от DRIVE-CV через V→I конвертер (S2) → частота.

**(б) ШИМ-компаратор:**
```
 audio_in ──R(10k)──┬──|+\  U_pwm (LM311, откр. коллектор)
 BIAS_off ──R(100k)─┘  |  >── PWM ── (pull-up 4k7 → +9) ──► Q2-затвор (через ключ)
 tri_out ───────────── |−/
```
- Аудио сравнивается с треугольной несущей → **ШИМ, скважность = мгновенный уровень аудио**. `BIAS` смещает порог (DC-офсет на + входе) → рабочая точка скважности → «металличность».
- Pull-up 4k7 на **+9** (не +5): у донорских MOSFET `Vth` до ~4В — свинг затвора 0/+9 гарантирует полное открытие/закрытие с любым донором.

**(в) Коммутация и восстановление:**
```
PWM ─► Q2-gate ;  Q2 коммутирует аудио-тракт (series/shunt)
Q2_out ──R_rec(2k2)──┬── recovery LPF ──► core_out
                    C_rec(10n)
                     │
                    GND   f_rec ≈ 7 кГц (1-й порядок, МЯГКИЙ)
```
- `Q2` коммутирует сигнал на частоте несущей → перемножение → несущая×аудио, боковые полосы, инхармоничность.
- LPF восстановления **мягкий** (R_rec=2k2, C_rec=10n, ~7 кГц, 1-й порядок): на низкой несущей **PWM-tick остаётся слышим** — «голос материала» (§3.2). Глубина сглаживания — в Tone.

### S4.6. GATE — hard limiter + noise gate

Перкуссивный режим: верхний порог (Drive) лимитирует, нижний (Bias) гейтит. MOSFET — series-ключ гейта.

**(а) Hard limiter (верхний порог = Drive):**
```
 in ──R(10k)──┬──|−\ U_lim (OPA1642)
              │   |  >──┬── lim_out
   D1↑ D2↓ ◄──┴───|+/   │   (back-to-back клип в ОС)
   к ±V_clip            │
 V_clip ◄── Drive-CV (масштаб ±1…±5В)   Rf=47k
```
- Двусторонний клип в ОС ОУ; уровень среза `V_clip` задаётся Drive-CV → жёсткий лимит вершин. Диоды BAT54 (мягче) или 1N4148 (жёстче).

**(б) Детектор огибающей + компаратор (нижний порог = Bias):**
```
 lim_out ─► прец. выпрямитель (OPA1642 + 2×1N4148) ─► env
 env ──R(100k)──┬── RC ── env_dc ──|+\ U_gate (LM311)
               C(1µ)               |  >── GATE_ctrl ──► ключ Q2 / VCA
 Bias_thr ──────────────────|−/  (гистерезис Rh=1M)
 τ_env = 100k·1µ ≈ 10 мс
```
- Прецизионный двухполупериодный выпрямитель → огибающая. Сравнение с порогом `Bias_thr` (Bias-CV) на LM311 с гистерезисом (Rh=1M) — без дребезга у порога.
- `GATE_ctrl` управляет **series-ключом `Q2`** (или форсирует управляющий ток выходного VCA): env > Bias → открыт; ниже → закрыт.

**(в) Динамика гейта:**
- Атака быстрая (~0.5 мс — короткий заряд), релиз короткий (~20–50 мс, R/C ramp на управлении ключом) → **режет хвосты, акцентирует транзиенты** (§3.2).
- Ramp фронтов сглажен (RC ~1 мс), чтобы открытие/закрытие не щёлкало.

Стартовые номиналы RING/GATE — в сводке S10.

## S5. Резонансный VCF — оригинальная схема «Поливокса» (блок У4)

Фильтр перенесён с заводской схемы блока фильтра У4 синтезатора «Поливокс». Источники и полная
расшифровка — `refs/polivoks_vcf_vca.md` §2. Ядро и управление срезом — один в один, отступления
перечислены в конце раздела. Сеть управляющих токов и уровни — стартовые, расчётные (R25).

```
 УПРАВЛЕНИЕ СРЕЗОМ — экспонента на одном транзисторе
 +12 ────────────────── R1 100k ───┐
 TR_F (подстр. 100k от +12) ─ 220k ─┤
 CUTOFF knob (0…+12 В) ──── 200k ───┼──(−) U1 TL071 ;  (+) U1 → AGND
 CUTOFF CV ─── 150k + TR_S 50k ─────┘     R2 3k — между узлом (−) и выходом U1
        Q1 2N3904: база = узел (−) U1, эмиттер = выход U1,
                   коллектор ──┬─ R5 110k ─► выв.8 U2   (ток программирования)
                               └─ R8 110k ─► выв.8 U3

 ЯДРО — конденсаторов нет
 vcf_in ── R_in 330k ──┬──(−) U2 К140УД12 ;  (+) U2 → AGND
                       ├─ R4 1k → AGND
                       ├─ R3 47k ◄──────────────── выход U3 (LP)
                       └─ ток демпфирования ◄───── OTA (резонанс)
 выход U2 (BP) ── R6 47k ──┬──(+) U3 К140УД12 ;  (−) U3 → AGND
                           └─ R7 1k → AGND
 выход U3 (LP)

 РЕЗОНАНС — петля демпфирования оригинала, управляемая напряжением
 BP ── 100k ──┬──(+) OTA (½ LM13700) ;  выход OTA → узел (−) U2
              └─ 2k2 → AGND             Iabc = (5 В − V_reso) / 100k, не ниже нуля

 ВЫХОД
 MODE-F: LP (выход U3) / BP (выход U2) ── C 1µ ── инв. усилитель 22k/150k (OPA1642) ──► vcf_out
```

- **Принцип.** Интегратор — сам программируемый ОУ: его частота единичного усиления пропорциональна
  току программирования (вывод 8). Делители 47k/1k ослабляют сигнал ошибки в 48 раз и опускают
  диапазон в звуковую область. U2 инвертирует, U3 нет; ОС через R3 замыкает двухполюсную петлю
  (12 дБ/окт), с U2 снимается полосовой выход, с U3 — низкочастотный.
- **CUTOFF.** Все источники приходят токами в узел (−) U1. U1 держит на R2 напряжение, равное
  Uбэ Q1, поэтому ток коллектора растёт экспоненциально: ≈ 6 мкА управляющего тока на октаву
  (Uт·ln2 / R2 при 25 °C). 1 В/окт ↔ ≈ 168k, подстраивается TR_S (Dave Brown на таком же узле
  пришёл к 175k). Ток коллектора делится между U2 и U3 поровну. Потолок — ≈ 100 мкА на ОУ
  (предел R5/R8 при ±12 В): дальше Q1 насыщается, срез стоит на максимуме.
- **Привязка к частоте** — по сборке Brown (то же ядро и тот же R2 3k, ОУ NTE888M): 150 мкА
  в узле управления дают самовозбуждение ≈ 100 Гц, 117 мкА — ≈ 2 Гц, потолок ≈ 51 кГц.
  У КР140УД1208 срез получается чуть ниже, чем у NTE888M.
- **Расстановка токов (старт).** R1 даёт 120 мкА постоянного смещения, TR_F добирает до нижней
  границы (≈ 136 мкА суммарно — расчётные 20 Гц), ручка добавляет до 60 мкА (десять октав,
  до ≈ 20 кГц), CV с пульта 0…+5 В — до 30 мкА (пять октав поверх ручки). TR_F заодно поглощает
  разброс транзистора Q1. Если нормаль с пульта останется биполярной ±5 В, меняется только
  настройка TR_F.
- **RESONANCE.** Ток OTA, пропорциональный BP, втекает в узел входа и демпфирует петлю.
  При Iabc ≈ 52 мкА OTA эквивалентна заводской цепи «потенциометр на максимуме + R54 47k»
  (расчёт: gm · 2k2/102k2 = 1/47k). Меньше ток — выше добротность; ноль — самовозбуждение.
  `V_reso` = ручка RESO + RESO-CV, ток через V→I конвертер (как в S2).
  OTA линейна примерно до 1 В на BP. На большем размахе она насыщается, демпфирование слабеет,
  и резонанс получается злее, чем с линейным резистором оригинала. Если на макете это мешает —
  включить линеаризующие диоды LM13700 (ток диодов ≈ 0,5 мА, BP через 100k прямо на вход,
  Iabc до ≈ 0,5 мА): тогда демпфирование линейно во всём размахе (R25).
- **Filter Drive.** Ограничителей амплитуды в петле нет, как в оригинале: на самовозбуждении
  U2/U3 упираются в рельсы питания. Диоды не ставим (совпадает с принципом §10).
  Выходной усилитель клипует раньше ядра — уже при ≈ 1,5 В на его входе, так что с резонансом
  vcf_out доходит до полного размаха ≈ ±10 В.
- **Уровни.** Ядро работает на штатных для оригинала ~0,5 В: R_in 330k даёт усиление в полосе
  47k/330k ≈ 1/7, выходной усилитель 22k/150k возвращает ×6,8. Усилитель инвертирующий, чтобы
  его входы не видели размах до рельс. Его 22k нагружают ядро так же, как вход блока усилителей
  в оригинале (20k): на малых токах программирования выход К140УД12 слабый, тяжелее грузить
  нельзя. Вариант Brown под 10 В пик-пик: 470k и ×11.
- **Термодрейф.** Экспонента не скомпенсирована, как в оригинале: оценка ≈ +9 % тока на градус,
  около полутора полутонов на градус. Прогрев корпуса сдвигает срез на октаву и больше (R16).
- **Детали.** U2, U3 — К140УД12 в металле или КР140УД1208 в DIP-8, питание ±12 В. Прямые замены:
  µA776, MC1776, NTE888M. LM4250 — с пересчётом R5/R8 (в плате Shruthi 100k при ±5 В). (R24)

**Отступления от заводской схемы**
1. R_in 330k вместо 39k и выходной усилитель — согласование ядра с уровнем ±5 В Eurorack.
2. Потенциометр «Резонанс» с R54 47k заменён половиной LM13700 — чтобы сохранить CV-вход RESO
   и правый стик пульта. Чисто заводской вариант: потенциометр 100k между BP и AGND, движок
   через 47k в узел входа; тогда CV на резонанс пропадает.
3. TL071 и 2N3904 вместо КР140УД8Б и КТ315Г.
4. Сеть управляющих токов своя: в оригинале она разнесена по объединительной плате.

## S6. ROUTE pre/post (перестановка core ↔ VCF)

```
            ┌─ S_a ─► CORE_in        CORE_out ─ S_c ─┐
 pre_in ────┤                                        ├──► post_out
            └─ S_b ─► VCF_in          VCF_out ─ S_d ─┘
ROUTE=post: pre_in→CORE→VCF→post_out   (S_a,  CORE_out→VCF_in,  VCF_out→post)
ROUTE=pre : pre_in→VCF →CORE→post_out
```
- 2× **DG419** (или 4053) кросс-коммутируют вход/выход блоков. Управление — GPIO MCU от панельного свитча ROUTE.
- Переключение **только под mute** (выходной VCA в 0, S8) — общий de-click FSM с MODE (A7): ramp-down 20-40мс → switch → ramp-up.

## S7. Tone (tilt) + Bass (shelf)

```
TILT (Tone):  in ─┬─ R(10k) ── C(22n) ──┐          ВЧ-плечо
                  │                     ├─ wiper (Tone) ─► U(−) ─► tilt_out
                  └─ R(10k) ────────────┘          НЧ-плечо
pivot = 1/(2π·R·C) ≈ 700 Гц   (станд. tilt на одном ОУ, wiper между плечами)
BASS shelf:   tilt_out ─► low-shelf (~120Гц) на ОУ, gain ±12дБ от BASS knob
```
- **Tone** — tilt на одном ОУ (NE5532/OPA1642): подъём низа/срез верха и наоборот вокруг ~700 Гц. CV-управление через OTA-VCA в плече (Tone-CV с пульта).
- **Bass** — независимый низкочастотный шельф ~120 Гц, ±12 дБ, knob (CV опц.). Возвращает тело после клипа.

## S8. MIX (dry/wet) + выходной VCA по схеме «Поливокса» (блок У5) + mute

```
 MIX
 wet (tone/bass out) ─► OTA_W(+)  Iabc_W ◄─ V_mix
 dry (clean tap)     ─► OTA_D(+)  Iabc_D ◄─ (Vmax − V_mix)     ; противофаза
 OTA_W_out ─┐
 OTA_D_out ─┴─Σ─► MIX_out

 КАСКАД 1 — LEVEL
 MIX_out ─ C1 10µ ─ R2 150k ─┬─ выв.3 U1 К118УД1Б             R4 200 → узел +6 В
 баланс TR1 100k (от +12 до −12) ─ R3 20k ─┬─ выв.10 U1        R5 200 → узел +6 В
 U1: выв.7 → +12 ; выв.14 → AGND ; выв.12 ◄─ R6 100k ◄─ V_level (0…+6 В)
 выв.5 → (−) U2a, R9 200k в ОС ;  выв.9 → (+) U2a, R8 200k → AGND        (U2 — TL072)

 КАСКАД 2 — MUTE / ARM
 выход U2a ─ R13 20k ─┬─ выв.3 U3 К118УД1Б                     R16 200 → узел +6 В
 баланс TR2 100k ─ R15 20k ─┬─ выв.10 U3                       R17 200 → узел +6 В
 U3: выв.7 → +12 ; выв.14 → AGND ; выв.12 ◄─ R18 68k ◄─ ЦАП кан. F (0…4,096 В, после RC 1k+100n)
 выв.5 → (−) U2b, R20 200k в ОС ;  выв.9 → (+) U2b, R19 200k → AGND
 выход U2b ─ C3 10µ ─► выходной буфер ×2 (OPA1642) ─ 1k ─► AUDIO OUT

 Узел +6 В: эмиттерный повторитель BC547 (20k / 20k на базе от +12, 10µ на базе, 6k2 в эмиттере)
```

- **MIX** — без изменений: две OTA в противофазе (`Iabc_W ∝ MIX`, `Iabc_D ∝ 1−MIX`), суммирование
  на инвертирующем сумматоре. MIX-knob + MIX-CV → управляющие токи (S9).
- **VCA — заводская схема блока управляемых усилителей У5** (расшифровка — `refs/polivoks_vcf_vca.md`
  §3). Два каскада подряд, каждый — дифференциальная пара К118УД1Б и ОУ-вычитатель. Усиление пары
  пропорционально току её хвоста; управляющее напряжение через резистор входит в базу
  токозадающего транзистора микросхемы (вывод 12).
- **Каскад 1 = LEVEL.** `V_level` — сумма ручки LEVEL и LEVEL-CV, 0…+6 В, отрицательные значения
  отсекаются. **Каскад 2 = mute.** Рампа ЦАП (канал F) для ARM и де-клика при смене MODE/ROUTE (A7).
- **Уровни как в оригинале.** R2 150k приводит наш ±5 В к ≈ 7 мВ на паре — того же порядка, что
  в оригинале (0,5 В через 20k дают ≈ 5 мВ). После каскада 1 при полном LEVEL получается ≈ 1,3 В,
  как помечено на заводской схеме; каскад 2 и его делитель 20k/200 остаются заводскими. Сквозное
  усиление двух каскадов ≈ 0,5, выходной буфер добирает ×2 (оценка, подбор на макете — R25).
- **Вычитатели U2 — TL072 (или LF353).** Входы ОУ подключены к коллекторам пары напрямую, как
  в оригинале, а коллекторы стоят на ≈ +11,7 В — в 0,3 В от плюсовой шины. Нужен ОУ, чей синфазный
  диапазон доходит до плюса питания (в оригинале КР140УД8Б с полевыми транзисторами на входе).
  OPA1642 и NE5532 сюда не годятся. У TL072 это типовое, а не гарантированное значение —
  проверить на макете; запасной вариант — ОУ с rail-to-rail входом, например OPA2192 (R25).
- **Характер.** На штатном уровне пара почти линейна; горячий сигнал (резонанс, фузз) мягко
  насыщает её. Отдельной «грязи» не добавляем — она свойство схемы.
- **Токи управления.** 6 В через 100k и 4,096 В через 68k дают ≈ 50 мкА, как огибающая 0…+6 В
  оригинала. У токового зеркала внутри микросхемы порог ≈ 0,65 В: ниже него каскад закрыт.
  Для mute это полная тишина; для LEVEL — мёртвый ход в начале ручки, убирается смещением.
- **Баланс.** TR1 и TR2 сводят пары, чтобы управление не пролезало в звук. Настройка: минимум
  щелчка на mute-рампе и минимум постоянной составляющей при вращении LEVEL.
- **Отступления от заводской схемы.** (1) R2 150k вместо 20k — согласование уровня. (2) Оба каскада
  закрываются в ноль: резистор R7 24k, который в оригинале держит первый каскад приоткрытым,
  не ставится (место на плате оставить). (3) R18 68k вместо 100k — под размах ЦАП. (4) C3 10µ
  вместо 50µ: дальше стоит буфер с высоким входным сопротивлением. (5) TL072 и BC547 вместо
  КР140УД8Б и КТ315Г, подстроечники 100k вместо 68k.
- **Замена К118УД1Б.** Дискретный эквивалент на транзисторной сборке CA3046 / LM3046 (внутренняя
  схема — в даташите, см. справку). В нашем включении нужны четыре резистора из шести: нагрузки
  4k + 4k, 1,8k в эмиттере токозадающего транзистора и 1,7k последовательно с диодом; цепь
  4k + 5,7k висит на свободных выводах 8 и 11. Подложку сборки (вывод 13 CA3046) — на AGND. (R24)
- Выходной буфер OPA1642, ×2, посл. 1k, кламп. ARM-off и смена MODE/ROUTE → рампа канала F в ноль.

## S9. CV-кондиционирование

### S9.1. ЦАП → CV (из MIDI, пульт)
- DAC8568 (16-bit, Vref 4.096) → ОУ-масштабатор на канал: усиление/смещение под **±5V** (DRIVE/BIAS/CUTOFF/RESO/X/Y) и **0…+5V** (GATE). Схема: инв. сумматор с −Vref для биполярного смещения. Канал F (mute) идёт на второй каскад VCA напрямую, без масштабатора (S8).
- RC-сглаживание 1k+100n (~1.6кГц) на выходе каждого канала (давит ступеньки обновления).

### S9.2. Нормализация + аттенювертер (CV-in)
```
CV_in jack (switched) ─┬─(нет кабеля)─ norm ◄ DAC-канал (с пульта)
                       │
                    attenuverter: вход на оба конца pot через инв/прям буфер,
                    wiper → Σ в управляющую цепь параметра. центр=0 (−1…+1)
```
- При вставке штекера нормаль рвётся → внешнее CV. Аттенювертер на TL07x: один инвертор (−1), pot между прямым и инверсным, wiper = −1…+1.

### S9.3. Экспонента среза
- Отдельного экспандера нет: экспонента встроена в узел управления фильтра (S5, U1 + Q1),
  как в заводской схеме. CUTOFF-knob и CUTOFF-CV приходят туда токами.
  DRIVE и HPF — линейные.

## S11. Цифровая секция модуля: MCU + USB-host (MAX3421E) + ЦАП

Связь с пультом — USB-C, модуль = host (05 §4.1). TRS/опто-цепей нет.

### S11.1. Обвязка MAX3421E (SPI USB-host)

```
STM32G431                 MAX3421E (TQFP32, +3.3D)
  SPI1_SCK  ────────────► SCLK          XI ──[12 MHz кварц]── XO
  SPI1_MOSI ────────────► MOSI          │      18p ┴    ┴ 18p
  SPI1_MISO ◄──────────── MISO          GND
  GPIO_SS   ────────────► SS#
  GPIO_INT  ◄──────────── INT     (EXTI, активный уровень по конфигу)
  GPIO_RES  ────────────► RES#    (сброс при старте)
                          D+  ◄──┬──► USB-C receptacle D+
                          D−  ◄──┼──► USB-C receptacle D−
                                 └── USBLC6-2SC6 (ESD-кламп у разъёма)
```
- SPI: mode 0, до 26 МГц (ставим 8-10 МГц — заведомо стабильно на макете).
- Питание +3.3D, 100n у каждого вывода питания + 1µ рядом.
- Прошивка: режим HOST (референс-стек USB Host Shield 2.0 / USBH_MIDI),
  разворачивание 4-байтовых USB-MIDI пакетов → кольцевой буфер → `bsp_midi_rx_pop()`.
- Детач/аттач пульта → `bsp_midi_link_up()` (надёжнее таймаута, таймаут — второй эшелон).

### S11.2. VBUS-цепь (питание пульта от модуля)

```
+5B (buck) ──► TPS2553 (лимит 500 мА) ──► VBUS гнезда USB-C
                 │EN ◄─ GPIO MCU (вкл. после старта)
                 │FAULT# ─► GPIO MCU (перегрузка → LED/лог)
CC1 ──[56k]── +5B     CC2 ──[56k]── +5B    (Rp «default USB power» = host)
```
- 56k Rp на обеих CC-линиях объявляют модуль host'ом с 500 мА — пульту (~50 мА) с запасом.
- Cout у гнезда: 10µF + 100n. Feature: EN с задержкой ~100 мс после старта MCU —
  MAX3421E успевает инициализироваться до появления устройства.

### S11.3. SPI-шина: ЦАП и host на одной или раздельных?

- **Раздельные**: DAC8568 на SPI1, MAX3421E на SPI2 (у G431 их два) — рекомендация.
  ЦАП обновляется из control-loop 1 кГц детерминированно, host-стек дёргает шину
  непредсказуемо; разделение избавляет от арбитража.
- Если пинов не хватит — общая шина с раздельными SS допустима, но ЦАП-транзакции
  тогда только из главного цикла (не из ISR).

### S11.4. Раскладка цифры (EMC)

- Цифровой остров (MCU, MAX3421E, кварц, buck) — у нижнего края платы, рядом с
  USB-гнездом и шиной питания; аналог (ядро, VCF, OTA) — выше, за ферритовым барьером.
- Кварц 12 МГц — короткие дорожки, земляной полигон под ним, не вести аудио под кварцем.
- USB D± — дифпара ~90 Ω, длины согласованы, ESD у самого гнезда.
- buck: петля SW-L-C минимальная; синхронизировать частоту не требуется (≥500 кГц —
  вне аудио; проверить на It-6 отсутствие свиста в тракте).
