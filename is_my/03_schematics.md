# Is My — схемотехника узлов (макетный уровень)

Узловые схемы с номиналами. Все значения — **стартовые для макета**: финальная подстройка нелинейных узлов (ядро, фильтр) — на breadboard (R2/R14/R16). ASCII-схемы упрощённые, опускают шунты питания (0.1µF на каждый ОУ/OTA) и часть защит.

Опирается на `02_technical.md` (архитектура) и `signal_flow.svg` (тракт).

Обозначения: `R`=резистор, `C`=кондёр, `Q`=MOSFET, OTA=LM13700 (половина), номиналы в Ω/F если не указано иное.

---

## S0. Питание и опора

- Вход ±12V Eurorack. На плате:
  - `+12A / −12A` — аналог. LC-фильтр на входе: феррит + 47µF + 100nF на каждую шину.
  - `+5D` ← LDO **TPS7A4901** из +12A (вход через феррит, Cin 10µF, Cout 10µF). Питает MCU-rail.
  - `+3.3D` ← **MCP1700** из +5D.
  - `Vref +4.096` ← **REF3040**, Cout 1µF + 100nF, буфер на OPA192 при раздаче на несколько узлов.
- Виртуальная земля аналога **AGND = 0V** (биполярное питание, не нужна半). Сигнальный размах ±5V ном.
- Цифровая земля DGND соединяется с AGND в одной точке у входного разъёма (звезда), феррит между ними.

## S2. Входной буфер + INPUT DRIVE (VCA)

```
AUDIO IN ──C1──┬── R2 ──┬───|+\ U1 (OPA1642)
              R1       │   |  >──┬─── buf_out ──► к DRIVE-VCA и clean tap
             100k    BAT54S      │
              │     (к ±12)   ┌──|−/
             GND               └── R3 ──┘   (×1, неинвертирующий)
C1=1µF film  R2=1k(защита)  R3=0 (или 1k/1k для ×2)
```

- Буфер ×1, Zin=100k. `C1` 1µF плёнка (срез ~1.6 Гц). `BAT54S` кламп к рельсам.
- **INPUT DRIVE** — OTA-VCA (LM13700) с линеаризующими диодами (чистое усиление до клипа ядра):

```
buf_out ──Rin(2k2)──► OTA-in(+)   ; диод-lin вкл.
Iabc ◄── R_abc ◄── V_drive_ctrl   ; Iabc = (V_ctrl − (−12) − 1.4)/R_abc
OTA_out ──► R_load(22k) ──► U2 буфер ──► drive_out
```
- Усиление `Av ≈ gm·Rload`, `gm ≈ 19.2·Iabc` (при Tamb). Iabc 0…~1 мА → Av 0…~×20 (вгоняет в нелинейность).
- `V_drive_ctrl` = сумма DRIVE-CV (с пульта/внешн., §S9). `R_abc` = 39k (при V_ctrl 0…+10 даёт Iabc 0…~0.5мА; подбор под нужный максимум драйва).
- Линеаризующие диоды LM13700 включены (вывод 2/15 через 1мА) — DRIVE должен усиливать чисто, грязь — дальше в MOSFET.

## S3. Variable PRE-HPF (бас ↔ fuzz)

ВЧ-фильтр 1-го порядка с управляемым срезом на OTA (OTA как управляемый резистор):

```
drive_out ──C_hp──┬───► next (MOSFET core / route)
                  │
                  R_var (OTA как VCR)
                  │
                 GND
f_hpf = 1/(2π·R_var·C_hp) ;  R_var ∝ 1/gm ∝ 1/Iabc
```
- `C_hp = 100nF`. При `R_var` 80k…8M (gm от Iabc) → `f_hpf` ~20 Гц … ~2 кГц.
- OTA как VCR: вход через большой R (1M) на OTA, выход в обратную связь — стандартная схема «OTA-резистор». Iabc от `V_hpf_ctrl` (knob + HPF-CV, §S9) через R_abc=39k.
- CCW (Iabc мал, R_var велик) → срез 20 Гц → весь низ в клип (жирно). CW → срез растёт → тонкий fuzz.
- Альтернатива (проще, без OTA): сдвоенный потенциометр 100k + переключаемые C — но теряем CV. OTA оставляем ради CV.

## S4. Двухкаскадное MOSFET-ядро + термосерва  ⟵ центр

Два logic-level N-MOSFET (донорские ESC; на макете — **BS170 / 2N7000 / IRLML2502**). `Vdd_core = +9V` (отдельный LDO из +12, чтобы клип был предсказуемым по уровню).

### S4.1. Stage 1 — мягкое насыщение (common-source, класс A)

```
            +9 (Vdd_core)
             │
            Rd1 10k
             │
   in ─Cg1─┬─┤D
  (HPF out)│ │
         Rg1│ Q1 (N-MOS)  ──► drain1 ─Cs12─► Stage2
         1M │ │
   bias1 ───┘ │S
             Rs1 100   ──► к серве (sense Iq1)
             │
            GND
Cg1=100n  Rg1=1M  Rd1=10k  Rs1=100  Cs12=100n
```
- Рабочая точка: серва (S4.3) держит `Vdrain1 ≈ +4.5V` (≈Vdd/2) → класс A, мягкая квадратичная сатурация.
- `bias1` — суммирование: серва (медленно) + BIAS-CV пользователя (через 100k, §S9) сдвигает рабочую точку → симметрия клипа.
- Усиление ~ −gm·Rd1; на сигнале раскачка в нелинейность Vgs².

### S4.2. Stage 2 — жёсткий клип/компрессия

```
            +9
             │
            Rd2 22k
             │
 drain1 ─Cs12┬─┤D
         Rg2 │ │
         1M  │ Q2  ──► drain2 ─Rlp─Clp─► core_out (через LPF anti-fizz)
  bias2 ─────┘ │S
             Rs2 47   ──► serva2 (sense Iq2)
             │
            GND
Rd2=22k (больше gain)  Rs2=47 (меньше degeneration → жёстче)
Rlp=1k + Clp=330p → LPF ~480кГц… вернее anti-fizz ~ ставим Rlp=2k2 Clp=1n → ~72кГц; точное на макете
```
- Больший gain + меньшая дегенерация → раскачка `Q2` **в отсечку и насыщение**, сток клиппит у 0/+9 → жёсткая компрессия чисто на транзисторе.
- Серва2 держит `Vdrain2 ≈ +4.5V` в покое; на сигнале клиппинг симметричен/асимметричен по BIAS.
- На больших Drive — period-doubling (саб-октава): зависит от Cs12 и паразитной ОС; **подбор на макете (R2)**.

### S4.3. Термосерва (одна на каскад, дуальный OPA2188)

```
Vdrain(n) ──R_s1(1M)──┬──|−\ U_servo (OPA2188)
                      Cs(1µF) |  >── bias(n)  ──► в gate-bias сумму каскада
                      │    ┌──|+/
                     GND   Vref_q (=+4.5V, делитель от +9)
τ = R_s1·Cs = 1 c  → угол ~0.16 Гц (аудио и бас не трогает)
```
- Интегратор сравнивает усреднённый `Vdrain` с `Vref_q=+4.5V`, гонит gate-bias так, чтобы держать рабочую точку → компенсирует дрейф `Vth` любого донорского MOSFET (адаптация под экземпляр, §6.3 концепта).
- BIAS-CV пользователя суммируется в тот же узел gate-bias **после** сервы (R 100k от BIAS, R 100k от сервы → узел затвора). Серва держит среднее, пользователь модулирует вокруг.
- Диапазон серва-захвата по Vth: ~1…4 В (logic-level). Вне — отбраковка/другой слот.

### S4.4. RING / GATE (переключение топологии)

- Те же `Q1/Q2` перекоммутируются аналоговыми ключами (DG419) под mute (S6/A7):
  - **RING**: `Q2`-затвор от ШИМ-компаратора (LM311), несущая — треугольник VCO (LM13700), частота от DRIVE-CV; аудио на компаратор. Сток `Q2` коммутирует → боковые полосы.
  - **GATE**: детектор огибающей (прец. выпрямитель + RC) → LM311 с гистерезисом против BIAS-порога → ключ закрывает тракт; Drive = верхний клип-порог (диод/ключ).
- Детали RING/GATE — отдельная итерация; здесь фиксируем, что ключи и компараторы共享ятся.

## S5. Резонансный VCF (LP/BP, резонанс, Filter Drive)

2-полюсный OTA-фильтр на сдвоенном **LM13700** (две OTA + два буфера на чипе).

```
in ─Rin(220k)─► OTA_A(+) ──[gm_A]──┬─ C_A(1n) ─ GND   ; pole 1 (out = BP-ish)
                                   └─ bufA ──┬──► OTA_B(+) ──[gm_B]──┬─ C_B(1n)─GND
                                             │                      └─ bufB ──► LP_out
            ┌──────────── RESONANCE feedback ──────────────────────────┘
            │  R_fb(100k) + VCA/pot (Q)   → подмешивается в in (инвертно)
MODE-F: LP = LP_out ;  BP = bufA_out
CUTOFF: Iabc(A)=Iabc(B) от экспандера (§S9)  → f = gm/(2π·C)
C_A=C_B=1n → при gm 6µS…6mS → f ~1кГц… (диапазон масштабируется Iabc)
```
- **CUTOFF**: общий `Iabc` обеих OTA от экспоненциального конвертера (S9.3), диапазон ~20 Гц…16 кГц. `C=1nF`.
- **RESONANCE**: ОС со 2-го полюса в вход через `R_fb=100k` и регулятор Q (потенциометр или VCA по RES-CV). На максимуме — самовозбуждение.
- **Filter Drive**: при высоком Q петля ОС достигает рельс ±12 и **клиппит** → фирменная грязь. Не ограничиваем диодами — пусть клиппит об рельсы (характер).
- Буферы — Darlington-буферы LM13700 (выводы 8/9 и 7/10), резисторы эмиттера 10k к −12.
- **MODE-F** свитч: LP_out / bufA_out (BP). Опц. HP = in − LP (доп. сумматор).

## S6. ROUTE pre/post (перестановка core ↔ VCF)

```
            ┌─ S_a ─► CORE_in        CORE_out ─ S_c ─┐
 pre_in ────┤                                        ├──► post_out
            └─ S_b ─► VCF_in          VCF_out ─ S_d ─┘
ROUTE=post: pre_in→CORE→VCF→post_out   (S_a,  CORE_out→VCF_in,  VCF_out→post)
ROUTE=pre : pre_in→VCF →CORE→post_out
```
- 2× **DG419** (или 4053) кросс-коммутируют вход/выход блоков. Управление — GPIO MCU от панельного свитча ROUTE.
- Переключение **только под mute** (выходной VCA в 0, S8) — общий de-click FSM с MODE (A7): ramp-down 20-40мс → switch → ramp-up.

## S7. Tone (tilt) + Bass (shelf)

```
TILT (Tone):  in ─┬─ R(10k) ─ C(10n) ─┐         pivot ~700Гц
                  │                   ├─ wiper(Tone pot/VCA) ─► U(–) ─► tilt_out
                  └─ R(10k) ─ L?нет ──┘         (станд. Baxandall-tilt на 1 ОУ)
BASS shelf:   tilt_out ─► low-shelf (~120Гц) на ОУ, gain ±12дБ от BASS knob
```
- **Tone** — tilt на одном ОУ (NE5532/OPA1642): подъём низа/срез верха и наоборот вокруг ~700 Гц. CV-управление через OTA-VCA в плече (Tone-CV с пульта).
- **Bass** — независимый низкочастотный шельф ~120 Гц, ±12 дБ, knob (CV опц.). Возвращает тело после клипа.

## S8. MIX (dry/wet) + грязный OTA-VCA + mute

```
wet (tone/bass out) ─► OTA_W(+)  Iabc_W ◄─ V_mix
dry (clean tap)     ─► OTA_D(+)  Iabc_D ◄─ (Vmax − V_mix)     ; противофаза
OTA_W_out ─┐
OTA_D_out ─┴─Σ─► MIX_out ─► OTA_VCA(грязный, БЕЗ lin-диодов) ─► U_outbuf ─► AUDIO OUT
                              Iabc_VCA ◄─ Level-CV × ramp(mute/ARM)
```
- **MIX**: две OTA в противофазе (`Iabc_W ∝ MIX`, `Iabc_D ∝ 1−MIX`), суммирование на инвертирующем сумматоре. MIX-knob + MIX-CV → управляющие токи (S9).
- **Грязный выходной VCA**: LM13700 OTA **без** линеаризующих диодов → характерная нелинейность OTA на больших уровнях. Iabc = Level-CV, домноженный на ramp (mute/ARM/de-click).
- Выходной буфер OPA1642, посл. 1k, AC-couple 10µF, кламп.
- ARM-off / смена MODE/ROUTE → ramp Iabc_VCA→0 (мьют без щелчка).

## S9. CV-кондиционирование

### S9.1. ЦАП → CV (из MIDI, пульт)
- DAC8568 (16-bit, Vref 4.096) → ОУ-масштабатор на канал: усиление/смещение под **±5V** (DRIVE/BIAS/LEVEL/TONE/X/Y) и **0…+5V** (GATE). Схема: инв. сумматор с −Vref для биполярного смещения.
- RC-сглаживание 1k+100n (~1.6кГц) на выходе каждого канала (давит ступеньки обновления).

### S9.2. Нормализация + аттенювертер (CV-in)
```
CV_in jack (switched) ─┬─(нет кабеля)─ norm ◄ DAC-канал (с пульта)
                       │
                    attenuverter: вход на оба конца pot через инв/прям буфер,
                    wiper → Σ в управляющую цепь параметра. центр=0 (−1…+1)
```
- При вставке штекера нормаль рвётся → внешнее CV. Аттенювертер на TL07x: один инвертор (−1), pot между прямым и инверсным, wiper = −1…+1.

### S9.3. Экспо-конвертер для CUTOFF
- Для муз. шкалы фильтра: экспандер на согласованной паре транзисторов (**SSM2212 / MAT12**) + tempco-резистор 2кΩ (+3300ppm) → `Iabc ∝ exp(Vctrl)`. CUTOFF-knob + CUTOFF-CV → Vctrl. (DRIVE/HPF — линейные, экспандер не нужен.)

## S10. Сводка стартовых номиналов (макет)

| Узел | Ключевые номиналы | Подстройка |
|---|---|---|
| Вход. буфер | C1=1µF, Rin=100k, ×1 | — |
| INPUT DRIVE | OTA, Rabc=39k, Rload=22k, lin-диоды вкл | макс. драйв (R14) |
| PRE-HPF | C_hp=100n, OTA-VCR, Rabc=39k | диапазон среза |
| Core Vdd | +9V (LDO) | уровень клипа |
| Stage1 | Rd1=10k, Rs1=100, Rg1=1M, Cg1=100n | Vth донора |
| Stage2 | Rd2=22k, Rs2=47, anti-fizz Rlp/Clp | period-doubling (R2) |
| Серва ×2 | R=1M, C=1µF (τ=1с), Vref_q=4.5V | Iq покоя |
| VCF | C=1n×2, Rin=220k, Rfb=100k, экспандер | диапазон/резонанс (R16) |
| ROUTE/MODE | DG419 ×2-3, mute-ramp 20-40мс | de-click (R17) |
| Tone/Bass | tilt ~700Гц, shelf ~120Гц | вкус |
| MIX/VCA | 2×OTA mix, выход OTA без lin-диодов | грязь/чистота |
| CV scale | ±5V / 0-5V, RC 1k+100n | калибровка LUT |

*Все нелинейные узлы (ядро, фильтр-drive) фиксируются по звуку на макете — номиналы выше задают рабочую точку, а не финальный тембр.*
