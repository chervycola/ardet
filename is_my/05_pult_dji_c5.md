# Is My — пульт на доноре DJI C5 (RC-N1/RC231): цифровая обвязка

Донор зафиксирован: **DJI C5 (RC-N1, модель RC231)** — штатный пульт Mavic 3 / Air 2S / Mini 2.
Этот документ **замещает** часть B `02_technical.md` (B0/B1/B4/B5 в старом виде) и раздел
пульта в BOM. Принятые решения: связь **только USB-C** (модуль = USB-host), **без батареи**,
**без CV-выходов на пульте**, оба стика в работе, rate-режим для вертикалей.

Ревизия после этапа 0 (`07_review_and_plan.md`): полярности CV (D1), роли ручек модуля (D2),
две ветки USB-host (D6), heartbeat линка и питание порта по детекту CC.

---

## 1. Решения и следствия

| Решение | Следствие |
|---|---|
| Линк = USB-C, модуль — USB-host | TRS-MIDI убирается с обеих сторон; опто 6N138/H11L1 не нужен; пульт остаётся class-compliant USB-MIDI — втыкается и в комп/DAW без переделок |
| Питание пульта от VBUS модуля | **Вся секция B1 умирает**: нет LiPo, зарядки, boost, fuel-gauge, load-switch, автоотключения. Пульт ~50 мА от 5В |
| CV-out пульта убраны | Модуль и так дублирует X/Y/GATE на своей панели (A6.3). **Корпус DJI не сверлим — ноль механических доработок** |
| Оба стика активны | Левый = сатурация (DRIVE/BIAS), правый = фильтр (CUTOFF/RESO). LEVEL/TONE переезжают ручками на модуль |
| Rate-режим вертикалей | Пружины DJI не мешают: стик = скорость изменения, значение держится. Гимбалы не вскрываем |

## 2. Маппинг органов DJI C5

### 2.1. Оси (все — пружина в центр)

| Орган | Параметр | Семантика | MIDI |
|---|---|---|---|
| Левый стик Y | **DRIVE** | **rate**: отклонение = скорость изменения, отпустил — держится | CC#17/49 (14-bit, абс. значение после интегратора) |
| Левый стик X | **BIAS** | absolute-momentary: ± вокруг центра, пружина = возврат к симметрии клипа | CC#16/48 |
| Правый стик Y | **CUTOFF** | **rate**: «открыл и стоит» | CC#18/50 (новая пара) |
| Правый стик X | **RESO** | absolute-momentary: ± к базе, база задаётся ручкой RESO на модуле | CC#19/51 (новая пара) |

Логика жеста: **вертикали копят (latch), горизонтали живут только в руке**. Момент-оси
модулируют вокруг базы, выставленной на модуле (аттенюверторы/ручки) — тот же принцип
«пульт играет, модуль лепит голос». Семантика финализируется на живом It-1 (обновлённый R4).

Rate-параметры (прошивка): deadzone 5%, экспо-кривая, полный ход шкалы за ~1.2 с при полном
отклонении (подбор на It-1). Интегратор считает прошедшее время, а не вызовы. Накопленные
значения живут в RAM пульта: при подаче питания по кабелю вертикали стартуют с нуля,
горизонтали — с центра, и пульт сразу шлёт стартовый снапшот своего состояния.

Полярности на стороне модуля (решение D1): вертикали дают **0…+5 В** — у накапливающей оси
центра нет, она идёт от нуля; горизонтали дают **±5 В** вокруг нуля.

### 2.2. Дискретные органы

| Орган DJI | Функция Is My | MIDI |
|---|---|---|
| Слайдер режимов 3-поз (Cine/Normal/Sport) | **MODE** = SHAPER/RING/GATE — буквальное совпадение | CC#80 (0/64/127) |
| Кнопка RTH | **ARM** (toggle в прошивке) | CC#64 |
| Кнопка Fn | **LINK** (toggle) | CC#81 |
| Кнопка Shutter/Record | **GATE** (momentary) | Note C2 (36) |
| Gimbal dial (колёсико, подпружинен — проверить) | **сдвиг MIX**: идёт на нормаль входа MIX CV, ±5 В, середина = без сдвига | CC#20 (7-bit; если подпружинен — решить на It-1, momentary или rate) |
| Кнопка Power | сервис: удержание при подключении = калибровка; двойное = MIDI panic | — |
| 4 LED батареи | статус: USB-ok / activity / ARM / сервис (калибровка, долгий простой) | — |

LEVEL и TONE **уходят на панель модуля** физическими потенциометрами (чисто аналогово,
без MIDI/ЦАП) — у DJI просто нет свободных ручек, и это соответствует «остальное крутим
с модуля».

## 3. Электроника пульта (наша плата вместо родной)

Родная плата RC-N1 (SoC, OcuSync, аккумулятор-контроллер) удаляется. Аккумулятор
демонтируется (или остаётся мёртвым балластом для веса — решить при teardown по весу/балансу).

```
DJI C5 корпус
┌─────────────────────────────────────────────────┐
│  Гимбал L ──┐                       ┌── Гимбал R │
│   (4 аналог. оси, родные шлейфы)                 │
│             ▼                       ▼            │
│      ┌──────────────────────────────────┐        │
│      │  Наша плата: STM32G431 (LQFP48)  │        │
│      │  ADC×4(oversample) GPIO(кнопки)  │        │
│      │  USB FS device · +3.3 LDO        │        │
│      └───────────────┬──────────────────┘        │
│   слайдер/кнопки ────┘        LED×4              │
│                                                   │
│   USB-C (родной разъём порта) ── VBUS+D±+CC ─────┼──► кабель ──► модуль (host) / комп (DAW)
└─────────────────────────────────────────────────┘
```

- **MCU: STM32G431** (остаётся) — USB FS device, ADC с оверсэмплингом ×16, ~50 мА суммарно.
- **Питание**: VBUS 5В → MCP1700-3.3 (LDO, 250 мА хватает с запасом). Никакого заряда/boost.
- **USB-C**: CC-резисторы 5.1k (UFP). Если родной разъём RC-N1 на шлейфе — переиспользовать;
  если распаян на убитой плате — врезка mini-платы с гнездом в родное окно порта (без сверловки).
- **Гимбалы**: подключаются родными шлейфами. Тип сенсора — **проверить на teardown (R18)**:
  ожидаем Hall с аналоговым выходом (3 провода/ось: питание, GND, OUT → прямо в ADC) или
  резистивные (тоже ADC). Питание сенсоров от +3.3, замерить родное (возможно 2.8В — тогда
  отдельный LDO и опора ADC согласованно).
- **Кнопки/слайдер**: прозвонить родную распайку (часто резистивная лестница на один ADC-канал —
  тогда читаем лестницей; если дискретные — GPIO с подтяжками).
- **Gimbal dial**: аналоговый (потенциометр) → ADC; проверить самовозврат.
- **LED×4**: GPIO. Родные светодиоды переиспользуем, если на шлейфе/доступны.

## 4. Изменения на стороне модуля

### 4.1. USB-host

- **Ветка A:** **MAX3421E** (SPI, 3.3В) рядом с STM32G431 модуля — проверенный host-контроллер
  (стек USB Host Shield / USBH_MIDI как референс).
- **VBUS-питание пульта**: ключ с токовым лимитом **TPS2553** (500 мА) на +5.
- **Ветка B (решение D6):** RP2040 (Pico) со встроенным USB-host и стеком TinyUSB + `usb_midi_host` —
  без внешнего контроллера и кварца. Обе ветки собираются на It-2, остаётся та, что стабильнее.
  Пульт в любом случае остаётся на G431: ему нужен хороший ADC.
- **VBUS включается только по детекту устройства на линиях CC** (S11.2): Rp 36k к +3,3 В на CC1/CC2,
  обе линии на ADC. В чужой host или хаб модуль 5 В не подаёт.
- **+5 модуля — buck 12→5** (TPS54202/LMR51420) вместо LDO: шина кормит ещё и пульт. Сделано в S0.
- Разъём на панели: **USB-C** вместо «MIDI IN (TRS)». Опто-цепь MIDI удалена.

### 4.2. Каналы DAC8568 (совпадает с A6.3 и S9.1)

LEVEL/TONE стали аналоговыми ручками модуля → каналы C/D отданы фильтру, канал H — колёсику:

| Канал | Что | Диапазон | Куда |
|---|---|---|---|
| A | левый Y / **DRIVE** (rate) | 0…+5 В | нормаль DRIVE-in + CV-out Y |
| B | левый X / **BIAS** | ±5 В | нормаль BIAS-in + CV-out X |
| C | правый Y / **CUTOFF** (rate) | 0…+5 В | нормаль CUTOFF-in |
| D | правый X / **RESO** | ±5 В | нормаль RESO-in |
| E | GATE | 0 / +5 В | CV-out GATE |
| F | MUTE ramp | 0…4,096 В | второй каскад выходного VCA |
| G | Iq_ref серв | — | опора тока покоя ядра |
| H | **dial** | ±5 В | нормаль MIX-in |

- Без кабеля во входе пульт слышат пять параметров: DRIVE, BIAS, CUTOFF, RESO и MIX.
- **Роли ручек модуля (решение D2):** DRIVE и BIAS — аттенюверторы над жестом стика (глубина и знак);
  у CUTOFF, RESO, MIX, LEVEL, TONE и HPF ручка задаёт базу, а CV-вход суммируется с ней ×1.
  Правый стик поэтому играет *вокруг* положения ручек CUTOFF и RESO.
- CV OUT X/Y/GATE на панели: X — положение левого стика (±5 В), Y — накопленное значение DRIVE (0…+5 В).

### 4.3. Панель модуля

Сделано в `panel_module.svg`: ручки LEVEL и TONE в колонке MODULATION, гнездо **USB-C (PULT)** вместо
«MIDI IN (TRS)», ширина 20HP. Подпись ряда CV IN уточняет, что аттенюверторы — только DRIVE и BIAS,
вход MIX помечен как слушающий пульт.

## 5. Изменения midi_map.h и прошивок

- **Добавлено**: `CC_CUT` 14-bit = CC#18/50, `CC_RESO` 14-bit = CC#19/51, `CC_DIAL` = CC#20.
- **Депрекейт для пульта**: CC#7 (LEVEL), CC#74 (TONE) — пульт их больше не шлёт
  (дефайны остаются: модуль может принимать их от DAW по USB в будущем).
- Пульт: интегратор rate-режима для Y-осей (deadzone, экспо, скорость), momentary для X-осей;
  ARM/LINK — программные toggle (у ARM есть LED, у LINK нет).
- Пульт шлёт **Active Sensing (0xFE) каждые 250 мс**: стики могут молчать сколько угодно,
  а модуль отличает тишину от обрыва.
- Модуль: вместо UART-парсера — **USB-MIDI host поверх MAX3421E** (энумерация пульта,
  разбор USB-MIDI пакетов 4-байтовых → тот же `midi_byte()`; парсер и FSM не меняются).
- Потеря линка = USB disconnect либо тишина дольше 500 мс (второй эшелон). Модуль при этом держит
  значения осей и отпускает GATE.

## 7. Влияние на план прототипирования (04)

- **It-1**: вместо «Nucleo + любой джойстик» → Nucleo + **гимбалы из первого teardown RC-N1**
  (или второй C5 как испытательный). Добавляется тюнинг rate-режима (скорость/экспо/deadzone).
- **It-2**: вместо TRS-линка → **USB-host bring-up** двумя ветками (MAX3421E + Nucleo и Pico + TinyUSB):
  энумерация пульта, поток CC, детект CC перед подачей VBUS. Закрывает R19 и выбирает MCU модуля.
- **It-7**: радикально упрощается — секции питания больше нет; остаётся teardown, посадка
  платы, маппинг органов (R18/R20).
- Закупка It-0: **минус** LiPo/зарядка/boost/fuel-gauge/опто/TRS; **плюс** DJI C5 ×2
  (рабочий + испытательный), MAX3421E breakout, TPS2553, buck 12→5.
