# Is My — план прототипирования (итерации 0–8)

Рабочий документ первых итераций. Принцип: **каждая итерация даёт проверяемый результат** и закрывает конкретные риски из registry (`02_technical.md` §13). Порядок выстроен так, что цифровая часть (быстрая, дешёвая, без редких деталей) идёт первой и становится измерительным стендом для аналоговой.

Статусы: `[ ]` не начата · `[~]` в работе · `[x]` закрыта. Обновляем по факту.

## It-0. Стенд и закупка `[ ]`

**Цель:** всё для итераций 1–6 на столе, ничего не блокирует.

**Инструменты (минимум):**
- Осциллограф ≥2 канала (хватит любого DSO ≥25 МГц), мультиметр, лабораторный БП ±12В (или Eurorack-БП + удлинитель шины)
- Breadboard ×2-3 + перемычки; звуковая карта для записи результатов (line-in)
- MIDI-монитор на компе (MIDI-OX / ReceiveMIDI / DAW)

**Закупка — цифра (It-1…3, конфиг DJI C5 / USB — 05_pult_dji_c5.md):**
- 2× **Nucleo-G431KB** (или G431RB) — пульт и модуль; отладка без своей платы
- 2× **DJI C5 (RC-N1/RC231)** б/у — рабочий + испытательный на teardown (гимбалы, кнопки, шлейфы — R18/R20)
- **MAX3421E** breakout (USB Host Shield mini) — USB-host модуля (R19)
- **TPS2553** (VBUS current limit), **buck 12→5** (TPS54202/LMR51420 модуль или готовая плата)
- **DAC8568** (breakout/DIP-адаптер), **REF3040**
- Кабель USB-C↔USB-C ×2; кнопки/LED на макет
- ~~LiPo, зарядка, boost, fuel-gauge, опто, TRS-гнёзда~~ — **сняты** (питание от VBUS, TRS удалён)

**Закупка — аналог (It-4…6):**
- **BS170 / 2N7000** ×10 (суррогат донора на отладку), **LM13700** ×4, **OPA2188** ×1, **OPA1642/TL072** ×6, **LM311** ×2, **DG419** ×3, 1N4148/BAT54 россыпь
- **Фильтр и усилитель по схемам «Поливокса»** (S5, S8, R24): **К140УД12 / КР140УД1208** ×4 и **К118УД1Б** ×4 (по два на макет плюс запас), **TL071**, **TL072** ×2 (вычитатели VCA — именно TL072, не OPA1642), **2N3904**, **BC547**; для проверки замен — **LM4250** или **NTE888M** ×2 и **CA3046** ×2
- Пассив: E12 резисторы, плёнка 1µ/100n/22n/10n/1n, многооборотные подстроечники 50k и 100k ×4
- LDO +9В (L7809/LP2985-9), +5/+3.3 (по S0)

**Донорские ESC:** для итераций НЕ нужны до It-4b. Искать параллельно, вход. контроль по §12 (Vth/gfs/Rds(on) + фото/координаты в provenance).

**Критерий выхода:** все позиции в наличии; стенд собирает/питает breadboard от ±12.

## It-1. Пульт-MIDI на гимбалах DJI `[ ]`  → закрывает R4, R18 (часть), часть R7

**Цель:** Nucleo-G431 читает 4 оси гимбалов DJI + органы и шлёт валидный USB-MIDI.

**Сборка:** teardown испытательного C5 → гимбалы ×2 + слайдер + кнопки + dial на шлейфах к Nucleo. Прошивка `pult/main.c` (rate-режим уже реализован).

**Чек-лист:**
- [ ] **R18**: тип сенсоров гимбалов (Hall/pot), питание, распайка шлейфов задокументированы
- [ ] 4× 14-bit пары (CC#16/48, 17/49, 18/50, 19/51) в MIDI-мониторе, MSB строго перед LSB
- [ ] Оверсэмплинг: на неподвижном стике LSB-шум ≤ 2-3 кода 14-bit
- [ ] **Rate-режим (вертикали)**: тюнинг RATE_FULL_MS / deadzone / expo — «нагнетание» ощущается музыкально; значение стоит при отпускании (R4)
- [ ] Momentary (горизонтали): честный 0 в центре, пружина возвращает без хвоста
- [ ] Латентность жест→CC < 10 мс; поток ≤ ~200 пар/с на ось при «пилотаже» всех 4 осей
- [ ] Калибровка 4 осей (Power-жест) пишется во flash, переживает ребут
- [ ] ARM/LINK-toggle от кнопок RTH/Fn без даблов; MODE от слайдера; GATE от Shutter; dial → CC#20

**Критерий выхода:** DAW пишет автоматизацию со всех 4 осей, rate-кривые музыкальны, R4/R18 закрыты.

## It-2. USB-host линк `[ ]`  → закрывает R19 (бывший TRS-линк снят вместе с R1)

**Цель:** второй Nucleo (модуль) энумерирует пульт через MAX3421E и принимает поток.

**Сборка:** Nucleo-2 + MAX3421E breakout (SPI) + TPS2553 на VBUS → кабель USB-C → пульт из It-1. Стек: референс USB Host Shield / USBH_MIDI, разворачивание USB-MIDI пакетов → `bsp_midi_rx_pop()`.

**Чек-лист:**
- [ ] Энумерация пульта < 2 с после втыкания; VBUS-лимитер держит бросок
- [ ] 0 ошибок парсинга за 10 мин «пилотажа» всех осей (счётчик)
- [ ] Горячее втыкание/вытыкание USB — модуль не виснет, `bsp_midi_link_up()` отрабатывает, значения держатся
- [ ] Пульт от VBUS модуля: потребление замерить (бюджет ~50 мА)
- [ ] Тот же пульт в комп — виден как class-compliant MIDI, работает параллельная логика

**Критерий выхода:** линк стабилен, R19 закрыт.

## It-3. MIDI→CV (цифро-аналоговый мост) `[ ]`  → закрывает R5-исполнение

**Цель:** модульная сторона превращает MIDI в калиброванные CV.

**Сборка:** Nucleo-2 + DAC8568 + REF3040 + масштабаторы (S9.1) на ±5В (X/Y) и 0…+5 (GATE).

**Чек-лист:**
- [ ] Центр джойстика X → 0.00 В ±10 мВ на CV-out (после LUT-калибровки)
- [ ] Края хода → ±5.00 В ±20 мВ; монотонность по всему ходу (прогнать медленный свип, записать звуковухой/DVM)
- [ ] Ступеньки: на медленном свипе после RC 1k+100n нет слышимых «лесенок» (проверить CV на VCO любого модуля/синта)
- [ ] GATE: фронт < 1 мс, уровень 0/+5, де-клик ramp работает
- [ ] Латентность жест→CV < 15 мс сквозь весь тракт (стик→ADC→MIDI→TRS→парсер→ЦАП)

**Критерий выхода:** осциллограмма «жест → CV» чистая; калибровочный LUT-процесс отработан (важно для edition, §12).

## It-4a. MOSFET-ядро SHAPER на суррогатах `[ ]`  → закрывает R2, R14 (главный риск!)

**Цель:** двухкаскадный сатуратор + сервы работают и **звучат** на BS170/2N7000. Это ключевая итерация — если R14 не подтверждается, пересматриваем ядро до того, как трогать доноров.

**Сборка (порядок внутри итерации):**
1. Stage 1 + серва 1 (S4.1/S4.3). Сначала серва: подать питание без сигнала, убедиться что Iq встаёт в 0.45 мА и держится (греть транзистор феном/пальцем — Vdrain не уплывает > ±0.3 В).
2. Прогнать синус 100 Гц/1 кГц через stage 1: увидеть мягкую асимметрию на скопе, чётные гармоники (FFT звуковухи).
3. Stage 2 + серва 2, соединить каскады. Драйвить до жёсткого клипа.
4. INPUT DRIVE (S2) и pre-HPF (S3) перед ядром. BIAS-CV в суммирование затворов.

**Чек-лист:**
- [ ] Сервы: Iq в номинале на 5 разных экземплярах транзисторов без подстройки (разброс Vth эмулирует доноров)
- [ ] Серва не «дышит» на басу 30 Гц (τ=1с достаточна, низ не проседает)
- [ ] BIAS реально морфит чёт/нечёт: FFT при Bias по центру vs крайних — картина гармоник меняется
- [ ] DRIVE от чистого до жёсткого клипа без мёртвых зон
- [ ] pre-HPF: CCW жирный бас-клип / CW тонкий fuzz — слышимая разница (это перенесённое главное качество сатуратора)
- [ ] Period-doubling: найти зону саб-октавы, подобрать Cs12/ОС (R2), задокументировать номиналы
- [ ] **Вердикт R14**: плотность/компрессия достаточны без диодов? (записать A/B-примеры звука)

**Критерий выхода:** R14 закрыт (или принято решение о пересмотре), номиналы ядра зафиксированы в `03_schematics`.

## It-4b. Донорские ESC-MOSFET `[ ]`  → закрывает R8

**Цель:** ядро работает на реальном материале.

**Чек-лист:**
- [ ] Снять Vth/gfs с 5+ донорских транзисторов (кривая Id(Vgs) точечно), записать в таблицу допусков
- [ ] Каждый донор в сокет ядра: серва захватывает без подстройки → границы допуска R8 зафиксированы
- [ ] A/B суррогат vs донор — задокументировать разницу звучания (материал слышен?)

**Критерий выхода:** таблица допусков R8; критерии входного контроля для edition готовы.

## It-5. RING + GATE + FSM переключения `[ ]`  → закрывает R17 (частично)

**Цель:** три режима на одном ядре, переключение без щелчков.

**Сборка:** VCO+PWM (S4.5), лимитер+детектор (S4.6), DG419-мультиплексор (S4.4), мьют-VCA (пока простой OTA), FSM в Nucleo-2 (MODE по MIDI → ramp → switch → ramp).

**Чек-лист:**
- [ ] RING: несущая 200 Гц–10 кГц от DRIVE, боковые полосы на FFT, PWM-tick слышен на низкой несущей
- [ ] Свинг затвора 0/+9 достаточен: полное переключение на транзисторе с худшим Vth из It-4b
- [ ] GATE: порог от BIAS чёткий, гистерезис без дребезга, атака/релиз перкуссивные
- [ ] Переключение MODE под mute: запись переходов на звуковуху → нет щелчков > −60 дБ от сигнала
- [ ] 100 переключений подряд (скрипт) — ни одного залипания ключей/FSM

**Критерий выхода:** все 3 режима играют, переходы чистые.

## It-6. VCF + ROUTE + Tone/Bass/MIX/VCA `[ ]`  → закрывает R16, R17 (полностью), R24, R25

**Цель:** полный аудио-тракт модуля в сборе на макете. Фильтр и выходной усилитель — по заводским
схемам «Поливокса» (S5, S8), MOSFET-ядро из It-4/It-5 остаётся фузз-овердрайвом.

**Чек-лист:**
- [ ] VCF (S5): ядро на двух К140УД12 запускается без конденсаторов; снять зависимость среза от тока в узле управления (ориентир: 150 мкА ≈ 100 Гц, ≈ 6 мкА на октаву), настроить TR_F (нижняя граница) и TR_S (масштаб CV)
- [ ] Резонанс через OTA-демпфер: от спокойного до самовозбуждения; на самовозбуждении ядро упирается в рельсы — есть и звучит. Сравнить OTA без линеаризующих диодов и с ними: какой резонанс оставляем (R25)
- [ ] Уровни VCF: подобрать R_in и усиление на выходе под ±5 В; на нижних частотах среза проверить, что выходной усилитель не просаживает ядро (R25)
- [ ] Термодрейф среза: замерить уход при прогреве (ожидание ≈ 1,5 полутона/°C) → вердикт R16: принять как характер или компенсировать
- [ ] VCA (S8): свести баланс TR1/TR2 — щелчок mute-рампы ниже −60 дБ; LEVEL закрывается в тишину; подобрать R2 и усиление буфера под ±5 В (R25)
- [ ] VCA (S8): вычитатели на TL072 работают со входами у плюсовой шины (≈ +11,7 В) без искажений и защёлкивания; если нет — заменить на ОУ с rail-to-rail входом (R25)
- [ ] Замены (R24): К140УД12 против LM4250/NTE888M и К118УД1Б против сборки на CA3046 — записи A/B, вердикт по допустимости
- [ ] ROUTE pre/post меняет характер радикально (свип фильтра до клипа vs после) — под mute, без щелчков
- [ ] MIX: clean blend спасает низ на тяжёлой сатурации (A/B на бас-линии)
- [ ] Сквозной шум тракта в тишине (ARM on, вход заглушен) ≤ −70 дБ отн. номинала ±5В
- [ ] Потребление по ±12 замерить фактически vs §10 (обновить таблицу)

**Критерий выхода:** полный тракт записан (демо-сессия), R16/R17/R24/R25 закрыты, номиналы S5 и S8 зафиксированы, §10 актуализирован.

## It-7. Пульт: посадка в корпус DJI `[ ]`  → закрывает R20 (R10 снят: батареи нет)

**Цель:** боевой пульт в корпусе DJI C5, всё на родных органах, один USB-C.

**Чек-лист:**
- [ ] Наша плата (или Nucleo-обрезок на первом экземпляре) на посадочных местах родной платы (R20)
- [ ] Родной USB-C порт/окно переиспользованы; CC-резисторы UFP; питание чисто от VBUS
- [ ] Все шлейфы (гимбалы, слайдер, кнопки, dial, LED) на родных разъёмах — без резки корпуса
- [ ] Родная батарея удалена (или закреплена обесточенным балластом — по весу/балансу решить)
- [ ] Полный прогон: пульт → кабель 2 м → модуль; вес/эргономика в руках и на ремне

**Критерий выхода:** закрытый корпус DJI, снаружи только USB-C, R20 закрыт.

## It-8. Интеграция и пред-серия `[ ]`

- Сквозная сессия: пульт → модуль → система (шум, земля, EMC при касании корпуса)
- Финальные номиналы → ревизия `03_schematics` → разводка PCB (модуль 20HP + плата пульта)
- Прошивки из скелетов → релизные, LUT-калибровка как процедура сборки экземпляра
- Провенанс-процесс на первых 2-3 донорах end-to-end (§12)
