# Is My — план прототипирования (итерации 0–8)

Рабочий документ первых итераций. Принцип: **каждая итерация даёт проверяемый результат** и закрывает конкретные риски из registry (`02_technical.md` §13). Цифровая часть (быстрая, дешёвая, без редких деталей) становится измерительным стендом для аналоговой, но главный блокер — ядро на суррогатах (It-4a) — стартует параллельно с It-1, как только пришли транзисторы. Порядок этапов и сроки — `07_review_and_plan.md` §4.

Ревизия после этапа 0: чек-листы приведены к новым топологиям и решениям D1–D7.

Статусы: `[ ]` не начата · `[~]` в работе · `[x]` закрыта. Обновляем по факту.

## It-0. Стенд и закупка `[ ]`

**Цель:** всё для итераций 1–6 на столе, ничего не блокирует.

**Инструменты (минимум):**
- Осциллограф ≥2 канала (хватит любого DSO ≥25 МГц), мультиметр, лабораторный БП ±12В (или Eurorack-БП + удлинитель шины)
- Макетные платы и расходники — по списку закупки; звуковая карта для записи результатов (line-in)
- MIDI-монитор на компе (MIDI-OX / ReceiveMIDI / DAW)

**Закупка:** полный список с точными обозначениями, корпусами под макет, количеством и очерёдностью —
**`08_purchase_list.md`** (та же таблица для корзины — `08_purchase_list.csv`). Коротко:
- **Первым заказом** — ядро и пред-тракт, ключи и реле, пассив, макетная механика, две Nucleo и два пульта DJI:
  на этом стартуют It-4a и It-1.
- **Сразу начать искать** старые микросхемы для фильтра и усилителя (К140УД12 / КР140УД1208, К118УД1Б):
  нужны к It-6, но ищутся дольше всего.
- **Вторым заказом** — цифра для It-2 и It-3: Pico, плата MAX3421E, ключ VBUS, ЦАП с обвязкой.
- Три места, где легко купить не то: ЦАП нужен **DAC8568 грейда A**; ключи **DG333A в DIP сняты
  с производства** — берётся ADG333A; драйвер затворов — **TC4428**, не TC4426 и не TC4427.

**Донорские ESC:** для итераций НЕ нужны до It-4b. Искать параллельно, вход. контроль по §12 (Vth/gfs/Rds(on) + фото/координаты в provenance).

**Критерий выхода:** все позиции в наличии; стенд собирает/питает breadboard от ±12.

## It-1. Пульт-MIDI на гимбалах DJI `[ ]`  → закрывает R4, R18 (часть), часть R7

**Цель:** Nucleo-G431 читает 4 оси гимбалов DJI + органы и шлёт валидный USB-MIDI.

**Сборка:** teardown испытательного C5 → гимбалы ×2 + слайдер + кнопки + dial на шлейфах к Nucleo. Прошивка `pult/main.c` (rate-режим уже реализован).

**Чек-лист:**
- [ ] **R18**: тип сенсоров гимбалов (Hall/pot), питание, распайка шлейфов задокументированы
- [ ] 4× 14-bit пары (CC#16/48, 17/49, 18/50, 19/51) в MIDI-мониторе, MSB строго перед LSB
- [ ] Оверсэмплинг: на неподвижном стике LSB-шум ≤ 2-3 кода 14-bit
- [ ] **Rate-режим (вертикали)**: тюнинг RATE_FULL_MS / deadzone / expo — «нагнетание» ощущается музыкально; значение стоит при отпускании (R4)
- [ ] Momentary (горизонтали): честный 0 в центре, пружина возвращает без хвоста
- [ ] Латентность жест→CC < 10 мс; поток ≤ ~200 пар/с на ось при «пилотаже» всех 4 осей
- [ ] Калибровка 4 осей (Power-жест) пишется во flash, переживает ребут
- [ ] ARM/LINK-toggle от кнопок RTH/Fn без даблов; MODE от слайдера; GATE от Shutter; dial → CC#20 (подпружинен ли dial — записать, R18)
- [ ] Active Sensing (0xFE) в мониторе каждые 250 мс; при неподвижных стиках больше ничего не идёт
- [ ] Потребление пульта от 5 В замерить (бюджет 50–80 мА, §10)

**Критерий выхода:** DAW пишет автоматизацию со всех 4 осей, rate-кривые музыкальны, R4/R18 закрыты.

## It-2. USB-host линк `[ ]`  → закрывает R19 и выбирает MCU модуля (решение D6)

**Цель:** модульная сторона энумерирует пульт и принимает поток. Две ветки с одинаковыми критериями:
- **A:** Nucleo-2 + MAX3421E breakout (SPI), стек USB Host Shield / USBH_MIDI.
- **B:** Raspberry Pi Pico + TinyUSB host + `usb_midi_host`.

**Сборка (общая):** TPS2553 на VBUS, Rp 36k на CC1/CC2 к +3,3 В и те же линии на ADC, кабель USB-C → пульт из It-1. Стек разворачивает USB-MIDI пакеты → `bsp_midi_rx_pop()`; логика — `module/main.c` без изменений.

**Чек-лист (для каждой ветки):**
- [ ] Детект устройства на CC: с пультом на одной линии ≈ 0,41 В → VBUS включается; без кабеля и при соединении с компьютером VBUS не подаётся (E18)
- [ ] Энумерация пульта < 2 с после втыкания; VBUS-лимитер держит бросок
- [ ] 0 ошибок парсинга за 10 мин «пилотажа» всех осей (счётчик)
- [ ] Горячее втыкание/вытыкание — модуль не виснет, `bsp_midi_link_up()` отрабатывает, значения держатся, GATE отпускается
- [ ] Стики неподвижны 10 мин — линк не считается потерянным (Active Sensing доходит до парсера)
- [ ] Тот же пульт в комп — виден как class-compliant MIDI

**Критерий выхода:** линк стабилен, R19 закрыт, **ветка выбрана** — та, что заработала за меньшее число вечеров и стабильнее. MCU модуля зафиксирован в 02 §13 (R7).

## It-3. MIDI→CV (цифро-аналоговый мост) `[ ]`  → закрывает R5-исполнение

**Цель:** модульная сторона превращает MIDI в калиброванные CV с полярностями по решению D1.

**Сборка:** плата модуля из It-2 + DAC8568 (грейд A) + REF3040, оба от своего стабилизатора 78L05 + буфер 74AHCT125 на линиях SPI + масштабаторы (S9.1): ±5 В для каналов B, D, H; 0…+5 В для A, C, E.

**Чек-лист:**
- [ ] ЦАП отвечает на SPI через буфер уровней 74AHCT125 (напрямую от 3,3 В не подключать: порог единицы у него 3,5 В)
- [ ] При включении без пульта все выходы в нейтрали: 0 В на A, B, C, D, H; mute
- [ ] Горизонтали (BIAS, RESO) и dial: центр → 0.00 В ±10 мВ, края → ±5.00 В ±20 мВ (после LUT-калибровки)
- [ ] Вертикали (DRIVE, CUTOFF): 0 → 0.00 В, полная шкала → +5.00 В ±20 мВ; значение стоит после отпускания стика
- [ ] Монотонность по всему ходу (медленный свип, записать звуковухой/DVM)
- [ ] Ступеньки: на медленном свипе после RC 1k+100n нет слышимых «лесенок» (проверить CV на VCO любого модуля/синта)
- [ ] GATE: фронт < 1 мс (его формирует RC, ≈ 0,2 мс), уровень 0/+5
- [ ] Mute-рампа канала F на осциллографе: S-образная, 30 мс, без ступенек (E1)
- [ ] Латентность жест→CV < 15 мс сквозь весь тракт (стик → ADC → USB-MIDI → host → парсер → ЦАП)

**Критерий выхода:** осциллограмма «жест → CV» чистая; калибровочный LUT-процесс отработан (важно для edition, §12).

## It-4a. MOSFET-ядро SHAPER на суррогатах `[ ]`  → закрывает R2, R14, R21, R23; снимает R22 (главный риск!)

**Цель:** двухкаскадный сатуратор + сервы работают и **звучат** на BS170/2N7000. Это ключевая итерация — если R14 не подтверждается, пересматриваем ядро до того, как трогать доноров. **Стартует параллельно с It-1**, как только есть транзисторы: цифра ей не нужна.

**Сборка (порядок внутри итерации):**
1. **Снять Id(Vgs)** у пяти суррогатов точечно (R21): при токах покоя S4 транзистор сидит под порогом, передача экспоненциальная. Выбрать Iq, Rd, Vdd для обоих каскадов осознанно, записать.
2. Stage 1 + серва 1 (S4.1/S4.3). Сначала серва: подать питание без сигнала, убедиться что Iq встаёт в номинал и держится (греть транзистор феном/пальцем — Vdrain не уплывает > ±0.3 В).
3. Прогнать синус 100 Гц/1 кГц через stage 1: увидеть асимметрию на скопе, чётные гармоники (FFT звуковухи). Подобрать входной делитель (старт ÷4,9).
4. Stage 2 + серва 2, межкаскадный делитель (старт ÷22), буфер и anti-fizz. Драйвить до жёсткого клипа.
5. Пред-тракт перед ядром: pre-HPF (S3), затем INPUT DRIVE с сухим путём (S2). BIAS-CV в суммирование затворов.
6. **Отдельно: ячейка-ключ** (S4.4) на одном транзисторе через реле: узел 47 Ω, затвор 0/+9 В от TC4428.

**Чек-лист:**
- [ ] Кривые Id(Vgs) сняты, рабочая область и делители выбраны и записаны в `03_schematics` (R21)
- [ ] Сервы: Iq в номинале на 5 разных экземплярах транзисторов без подстройки (разброс Vth эмулирует доноров)
- [ ] Серва не «дышит» на басу 30 Гц (τ=1с достаточна, низ не проседает)
- [ ] «Дыхание» на клипе (E15): затухающий аккорд на максимуме DRIVE, послушать первую секунду — характер или помеха
- [ ] BIAS реально морфит чёт/нечёт: FFT при Bias по центру vs крайних — картина гармоник меняется
- [ ] DRIVE: на нуле — сигнал на границе клипа, не тишина; до жёсткого клипа без мёртвых зон; постоянка на выходе INPUT DRIVE сведена TR_off (R23)
- [ ] pre-HPF: CCW жирный бас-клип / CW тонкий fuzz — слышимая разница (это перенесённое главное качество сатуратора); срез 20 Гц…2 кГц
- [ ] Period-doubling: найти зону саб-октавы, подобрать Cs12/ОС (R2), задокументировать номиналы
- [ ] Ячейка-ключ: закрытый транзистор не искажает сигнал ±0,1 В на узле, открытый давит его не хуже 40 дБ; повторить на силовом MOSFET с большим зарядом затвора и послушать тик (R22)
- [ ] **Вердикт R14** (формулировка D7): клип на подпороговом MOSFET достаточно плотный без диодов? (записать A/B-примеры звука)

**Критерий выхода:** R14 закрыт (или принято решение о пересмотре), рабочая область выбрана по измеренным кривым, номиналы ядра зафиксированы в `03_schematics`.

## It-5. RING + GATE + FSM переключения `[ ]`  → закрывает R22, R17 (частично)

**Цель:** три режима на одних и тех же двух транзисторах, переключение без щелчков.

**Сборка:** две ячейки-ключа и сумматор, реле K1/K2 и DG333A (S4.4); VCO, ШИМ-компаратор и драйвер TC4428 (S4.5); лимитер на Q2, детектор и компаратор гейта (S4.6); мьют-VCA (пока простой OTA); FSM на плате модуля (MODE по MIDI → рампа → переключение → пауза → рампа).

**Чек-лист:**
- [ ] RING: несущая 200 Гц–10 кГц от DRIVE, боковые полосы на FFT; при скважности 50 % прямой сигнал подавлен, TR_null сводит остаток
- [ ] BIAS подмешивает прямой сигнал, глубина ШИМ (TR_pwm) добавляет самомодуляцию — оба слышны и управляемы
- [ ] Сравнить две физики RING на слух: переворот полярности на двух ключах и «класс D» (S4.5в) — записать A/B, выбрать (R22)
- [ ] Тик затворов на донорах из It-4b: слышен на низкой несущей, не забивает сигнал на высокой; подобрать сопротивление узла
- [ ] Громкость в RING не ходит за DRIVE (усиление INPUT DRIVE зафиксировано)
- [ ] GATE: лимитер на Q2 упирается в рельсы, порог от DRIVE; порог гейта от BIAS чёткий, гистерезис без дребезга; открытие ≈ 0,5 мс, закрытие 10–30 мс
- [ ] Гейт закрывается и открывается без хлопка по постоянке; если щёлкает — RC на затвор в этом режиме
- [ ] Сервы после возврата в SHAPER встают сразу (hold работает), без секунд повторного захвата
- [ ] Переключение MODE под mute: запись переходов на звуковуху → нет щелчков > −60 дБ от сигнала; паузы 10 мс хватает реле
- [ ] 100 переключений подряд (скрипт), в том числе запросы посреди рампы — ни одного залипания реле, ключей или FSM

**Критерий выхода:** все 3 режима играют, переходы чистые, физика RING выбрана.

## It-6. VCF + ROUTE + Tone/Bass/MIX/VCA `[ ]`  → закрывает R16, R17 (полностью), R24, R25

**Цель:** полный аудио-тракт модуля в сборе на макете. Фильтр и выходной усилитель — по заводским
схемам «Поливокса» (S5, S8), MOSFET-ядро из It-4/It-5 остаётся фузз-овердрайвом.

**Чек-лист:**
- [ ] VCF (S5): ядро на двух К140УД12 запускается без конденсаторов; снять зависимость среза от тока в узле управления (ориентир: 150 мкА ≈ 100 Гц, ≈ 6 мкА на октаву), настроить TR_F (нижняя граница) и TR_S (масштаб CV)
- [ ] Резонанс через OTA-демпфер: от спокойного до самовозбуждения; на самовозбуждении ядро упирается в рельсы — есть и звучит. Сравнить OTA без линеаризующих диодов и с ними: какой резонанс оставляем (R25)
- [ ] Уровни VCF: подобрать R_in и усиление на выходе под ±5 В; на нижних частотах среза проверить, что выходной усилитель не просаживает ядро (R25)
- [ ] Термодрейф среза: замерить уход при прогреве (ожидание ≈ 1,5 полутона/°C) → вердикт R16: принять как характер или компенсировать
- [ ] VCA (S8): свести баланс TR1/TR2 — щелчок mute-рампы ниже −60 дБ; LEVEL закрывается в тишину; подобрать R2 и усиление буфера под ±5 В (R25)
- [ ] VCA (S8): вычитатели на TL072 работают со входами у плюсовой шины (≈ +11,7 В) без искажений и защёлкивания; если нет — заменить на ОУ с rail-to-rail входом (R25)
- [ ] Замены (R24): К140УД12 против LM4250/NTE888M и К118УД1Б против сборки на CA3046 — записи A/B, вердикт по допустимости
- [ ] ROUTE pre/post меняет характер радикально (свип фильтра до клипа vs после) — под mute, без щелчков
- [ ] MIX: clean blend спасает низ на тяжёлой сатурации (A/B на бас-линии); на средних положениях ручки основной тон не проваливается — wet и dry в фазе (S8)
- [ ] Сквозной шум тракта в тишине (ARM on, вход заглушен) ≤ −70 дБ отн. номинала ±5В
- [ ] Потребление по ±12 замерить фактически vs §10, с пультом на VBUS и в режиме RING (оба реле включены) — обновить таблицу

**Критерий выхода:** полный тракт записан (демо-сессия), R16/R17/R24/R25 закрыты, номиналы S5 и S8 зафиксированы, §10 актуализирован.

## It-8. Интеграция и пред-серия `[ ]`

- Сквозная сессия: пульт → модуль → система (шум, земля, EMC при касании корпуса)
