# Is My — техническая часть

Инженерная спецификация модуля и пульта. Уровень проработки: функциональные узлы + ключевые цепи + выбор компонентов + распиновка + архитектура прошивки + раскладка панели + BOM. Достаточно, чтобы развести прототип; точные номиналы пассивов и финальная отладка — на стадии макета (см. §11, §12).

Опирается на концепт (`01_concept.md`). Все спорные решения вынесены в §13 (risk register).

## 0. Карта системы и разбиение на устройства

Два независимых устройства, связанных одним TRS-кабелем (MIDI Type A):

```
┌─────────────────────────┐      TRS MIDI      ┌──────────────────────────────┐
│  ПУЛЬТ (standalone)      │  ───────────────▶  │  МОДУЛЬ (Eurorack 3U, ~12HP) │
│  • джойстик 2 оси + push │                    │  • MIDI-in → MCU → DAC       │
│  • LEVEL/TONE knobs      │                    │  • MOSFET shaper core (3 реж)│
│  • ARM/MODE/LINK toggles │                    │  • video audifier            │
│  • foot-switch jack      │                    │  • CV bus + нормализация      │
│  • 3× CV out (X/Y/GATE)  │                    │  • 4× CV in (attenuverter)   │
│  • LiPo + USB-C charge   │                    │  • 3× CV out (X/Y/GATE)      │
│  • USB-MIDI              │                    │  • питание ±12V из шины      │
│  • MCU (STM32G431)       │                    │  • MCU (STM32G431)           │
└─────────────────────────┘                    └──────────────────────────────┘
```

Ключевое следствие архитектуры «связь = MIDI, не CV»: **модуль обязан иметь микроконтроллер и ЦАП**, иначе он не сможет превратить присланные по MIDI данные джойстика в управляющие напряжения для аналогового ядра. Пульт CV не передаёт по кабелю к модулю — он шлёт MIDI; модуль регенерирует CV локально. Собственные CV-выходы пульта (3×) — это отдельный тракт для управления *другими* модулями линейки напрямую, мимо MIDI.

**Выбор MCU для обоих устройств: STM32G431** (LQFP48/32). Причины: 12-bit ADC с аппаратным оверсэмплингом до 16 бит (критично для 14-bit джойстика и стабильных CV), USB FS device (USB-MIDI на пульте), 2× SPI/I²C для ЦАП, аппаратные таймеры для PWM-несущей RING-режима, дёшев и доступен. RP2040 рассматривался, но его ADC (12-bit, заметный шум, 3 свободных канала) проигрывает на аналоге — см. §13-R7.

# ЧАСТЬ A. МОДУЛЬ

## A1. Питание и шина

Вход: ±12V Eurorack (10-pin / 16-pin Doepfer, красная полоса = −12V).

Шины питания на плате:
- **+12V / −12V** — аналог (буферы, ядро, видео-аудификатор, аттенюверторы).
- **+5V** — цифровая (через LDO из +12V; рекомендую малошумящий LDO, напр. **TPS7A4901** или **LM2940**, с RC-фильтром на входе). Питает MCU rail и опторазвязку MIDI.
- **+3.3V** — MCU/ЦАП, из +5V через **MCP1700** / **AP2112**.
- **Опорное Vref +4.096V** (для ЦАП) — **REF3040** / **ADR4540**, отдельно отфильтрованное.

Развязка цифра↔аналог: ферритовые бусины между +5V/+3.3V цифровыми и аналоговыми землями; единая звезда земли в точке входного разъёма. ЦАП-выходы выходят в аналоговую область — там аналоговая земля.

Защита входа: последовательные диоды / P-MOSFET reverse-polarity, TVS на ±12V, предохранитель-полимер (PTC) по каждой шине.

Бюджет тока — см. §10.

## A2. Входной буфер (AUDIO IN)

- Разъём: 3.5mm Thonkiconn, моно (TS), нормированный (switched) — нормаль не используется для аудио, но контакт пригодится для индикации «вставлен ли кабель».
- Схема: неинвертирующий буфер на **TL072 / OPA1642** (FET-вход, низкий шум), Zin ≈ 100 кОм, усиление ×1. AC-связь на входе (большой плёночный конденсатор + резистор смещения к аналоговой земле). Клампинг-диоды (BAT54S) к ±12V (или к рельсам ОУ) на входе для защиты от перегруза.
- Модулярный уровень: рассчитываем на ±5V (10 Vpp) номинал, headroom до ±10V. Перед ядром — нормировочный аттенюатор, чтобы ввести сигнал в рабочую область MOSFET (см. A3.1).

## A2.5. Пред-core тракт — адаптация Godeater (INPUT DRIVE + variable HPF + clean tap)

Адаптация сатуратора **Animal Factory Godeater**. Решение: **вся нелинейность остаётся в MOSFET** (принцип §10) — от Godeater берём *структуру и контроли*, а не диодно/LED-клиппинг. Перенесённые качества:

**Полный сигнальный путь (SHAPER + Polivoks-фильтр, переключаемый pre/post):**
```
AUDIO IN → buffer → INPUT DRIVE → pre-HPF(var) → clean tap ─────────────────────────────┐
                                       │                                                 │
                                       ▼   ┌──── ROUTE switch (pre/post) ────┐            │
                                  [ MOSFET core (s1→s2) ] ⇄ [ POLIVOKS VCF ] │            │
                                       └──────────────┬──────────────────────┘            │
                                                      ▼                                   │
                                              TONE (tilt) → BASS (low shelf) ─────────────┤
                                                                                MIX (dry/wet) → DIRTY OTA-VCA → AUDIO OUT
```
ROUTE = pre: фильтр **до** сатурации (фильтр-свип определяет, что искажается). ROUTE = post: фильтр **после** (классика — режем грязь). Переключатель на панели, коммутация — под mute (A7).


Узлы пред-core:
- **INPUT DRIVE** — управляемый предусилитель (OTA/VCA) перед ядром. Сильно взаимодействует со степенью искажения (Godeater INPUT LEVEL): грузит порог захода MOSFET в нелинейность. Это и есть «Drive» из концепта; усиливаем его как главный драйвер сатурации.
- **pre-HPF (variable)** — *главная фишка Godeater*. ВЧ-фильтр **перед** MOSFET-каскадом, перестраиваемый ~20 Гц … ~1 кГц:
  - полностью CCW (срез 20 Гц) → весь низ влетает в транзистор → жирная басовая дисторшн;
  - выше (срез растёт) → низ срезан до клипа → тонкий «осиный» fuzz.
  - Реализация с CV: **OTA-HPF (LM13700)** 1–2 порядка с управлением частотой среза по сумме «панельный HPF-knob + HPF-CV». Альтернатива — variable-R на JFET/digipot, но OTA даёт плавный CV.
- **clean tap** — чистый отвод сигнала **после входного буфера** (до HPF/ядра), буферизуется и идёт на MIX (clean blend, A8). Сохраняет фундамент и транзиенты под тяжёлой сатурацией — критично для баса (Godeater CLEAN/Zeus dry-wet).

Пред-core (INPUT DRIVE, pre-HPF) и MIX/BASS — **глобальны** (действуют во всех трёх режимах ядра), а двухкаскадная топология (ниже) — конфигурация именно SHAPER; в RING/GATE аналоговый мультиплексор переключает ядро на свои топологии (A3.2/A3.3).

## A3. MOSFET shaper core — ядро

Сердце модуля. Используется **силовой N-канальный MOSFET из донорского ESC** (logic-level, low-Rds(on), типичный корпус DFN/SOT-23 для мелких ESC или DPAK для крупных). Конкретный тип каждого экземпляра документируется в provenance (§A3.6).

Один и тот же транзистор переключается между тремя топологиями аналоговыми ключами **DG419 / MAX4053 / 74HC4053** (расположение определяется при разводке; для аудио — выбирать ключи с малым зарядом инжекции и низким Ron, напр. **DG419L**). Логика выбора режима — от MCU (декодирует MODE из MIDI). Сигнальные ключи всегда коммутируются **только под mute** (см. A7), чтобы исключить щелчки.

Общая идея: транзистор остаётся силовым переключателем/нелинейным элементом во всех режимах — функциональная преемственность (принцип §10 концепта).

### A3.1. SHAPER — двухкаскадный MOSFET-сатуратор (Godeater-структура, чистый MOSFET)

Godeater злой за счёт **двух каскадов клиппинга подряд**. Воспроизводим структуру, но клиппит **сам ESC-MOSFET** (два каскада на транзисторах, диодов/LED нет — §10). Под SHAPER используются **два MOSFET** (оба из донорского ESC, A3.6): stage 1 — мягкое насыщение, stage 2 — жёсткий клип/компрессия.

**Stage 1 — мягкий транскондуктансный каскад:**
- Common-source, аудио на затвор через сумматор `Vgate = Vaudio·Drive + Vbias`.
- Работает у класса A, умеренный gain → мягкое квадратичное насыщение `Id ≈ k·(Vgs − Vth)²`.
- `Bias` смещает рабочую точку → асимметрия (чётные ↔ нечётные гармоники). **Bias = непрерывный аналог Godeater CLIP-переключателя** (симм. ↔ асимм. клип), только плавно.

**Stage 2 — жёсткий клип/компрессия:**
- Второй common-source с бóльшим gain, раскачивается **в отсечку и насыщение** → сток клиппит у Vdd/0 характеристикой самого транзистора (никаких диодов). Это «brutal» Godeater-компрессия чисто на материале.
- Симметрия клипа здесь тоже зависит от рабочей точки stage 2 (общая Bias-цепь + локальное смещение).
- На больших Drive связка двух каскадов с локальной ОС/ёмкостью входит в **period-doubling** (саб-октава) — желаемо; глубина — номиналами на макете (R2).

**Сквозное:**
- Между каскадами — межкаскадная связь (AC) и опц. мягкий LPF, чтобы укротить ВЧ-визг (можно вывести в Tone-направление).
- Нагрузка стоков — резистор/источник тока, `Vout = Vdd − Id·Rd` (инвертирующе, нелинейно).
- `Drive` (из пред-core, A2.5) задаёт, насколько жёстко влетаем в каскад 1 → глубина сатурации/компрессии (Godeater GAIN+INPUT LEVEL слиты в Drive).
- **Каждый каскад — со своей сервопетлёй термокомпенсации** (A3.4): дрейф двух транзисторов держится независимо. Дуальный low-offset ОУ (OPA2188).

`Level` (VCA gain из концепта) — отдельный **OTA/VCA-предусилитель** (LM13700 / THAT2180) по Level-CV, перед пред-core. Level и Drive независимы: Level — общий gain тракта, Drive — глубина захода в нелинейность.

### A3.2. RING — кольцевая модуляция через PWM

Концептуальная фишка: транзистор **буквально коммутирует** (как в дроне), а ШИМ-коммутация даёт боковые полосы.

Цепочка:
1. **Несущий генератор** — аналоговый треугольный VCO, частота 200 Гц … 10 кГц, управляется Drive-CV (Drive → частота несущей). Реализация: интегратор + компаратор (триангл/сквер) на **TL074**, или dedicated **LM13700** OTA-VCO для лог-чувства. Линейного диапазона хватает.
2. **ШИМ-компаратор** — **LM311 / TLV3501**: сравнивает аудиосигнал с треугольной несущей → на выходе ШИМ, **скважность которого следует за мгновенным уровнем аудио**.
3. Этот ШИМ управляет **затвором силового MOSFET**, который коммутирует опорный уровень (или сам аудиосигнал через второй ключ) → на выходе перемноженный спектр: несущая × аудио, боковые полосы, инхармоничность.
4. На низких частотах несущей слышен дискретный **PWM-tick** — «голос материала» (§3.2 концепта), сохраняем намеренно, не фильтруем агрессивно.
5. Восстановительный LPF после ключа — мягкий (1-й порядок), чтобы тик остался; глубину сглаживания можно вывести в Tone.

`Bias` в этом режиме сдвигает порог компаратора (смещает рабочую точку скважности → характер «металличности»).

### A3.3. GATE — hard limiter + noise gate

- **Верхний порог (hard limit/clip)** задаётся Drive: двусторонний ограничитель на диодах/MOSFET-ключе, отсекающий вершины → жёсткий лимит.
- **Нижний порог (noise gate)** задаётся Bias: компаратор детектора огибающей (выпрямитель + RC) против Bias-порога → если сигнал ниже порога, **MOSFET-ключ закрывает тракт** (опять буквальное переключение). Атака быстрая, релиз короткий → «режет хвосты», акцент на транзиентах (§3.2).
- Детектор огибающей: прецизионный выпрямитель на ОУ + RC + компаратор **LM311**, гистерезис для устранения дребезга у порога.

### A3.4. Термокомпенсация дрейфа

Силовые MOSFET имеют большой разброс и температурный дрейф порога `Vth` (≈ −2…−6 мВ/°C) и крутизны. Без компенсации рабочая точка SHAPER уплывает → меняется тембр и DC на выходе.

Решение — **сервопетля удержания тока покоя, по одной на каждый MOSFET-каскад** (SHAPER = 2 каскада, A3.1):
- Ток стока (или истока) каждого каскада измеряется по падению на малом резисторе истока `Rs`.
- ОУ-интегратор (**OPA2188**, дуальный low-offset — обе сервы в одном корпусе) сравнивает это падение с опорой `Iq_ref` и подстраивает **DC-смещение затвора** каскада так, чтобы ток покоя держался константой.
- Постоянная времени сервы — большая (≈ 0.5…1 с), чтобы петля компенсировала тепловой и долговременный дрейф, но **не реагировала на аудио и не съедала низ**. HPF в аудиотракте после ядра защищает от остаточного DC.
- Сигнал Bias от пользователя суммируется **поверх** сервы (серва держит среднее, пользователь модулирует вокруг).

Это даёт «работоспособность в спецификации при уникальности звучания» (§6.3 концепта): серва гарантирует, что любой донорский MOSFET попадёт в рабочую зону, но тонкий характер каждого транзистора сохраняется.

### A3.5. Tone + Bass (пост-ядро)

- **Tone** — наклон спектра: **state-variable tilt-EQ** (одновременно поднимает низ/срезает верх и наоборот вокруг ~700 Гц) на одном ОУ. Управление Tone-CV через OTA для плавности. Покрывает Godeater «tone direction» (наклон в обе стороны от пивота).
- **Bass** (Godeater-адаптация) — отдельный **низкочастотный шельф** пост-ядро (~100–150 Гц), вернуть/убрать тело после сатурации. Простой shelving на ОУ, панельный knob (CV опционально). Дополняет Tone, не дублирует: Tone крутит баланс верх/низ, Bass — абсолютный уровень низа.

### A3.6. Привязка к донорскому MOSFET

- Под транзистор — **панелька/сокет или короткие выводные площадки**, чтобы каждый экземпляр edition получал свой ESC-MOSFET, а сервопетля адаптировалась к его параметрам.
- При входном контроле документируется: тип/маркировка (если читается), измеренные `Vth`, `gfs`, `Rds(on)` — в provenance certificate.
- Допуски, при которых серва ещё держит: `Vth` в диапазоне (определяется на макете, ориентир 1…4 В для logic-level). MOSFET вне диапазона — отбраковка/другой слот.
- **SHAPER теперь двухкаскадный → два сокета под ESC-MOSFET** (A3.1). По возможности оба транзистора — с одной донорской платы (общий провенанс экземпляра); серва компенсирует их разброс независимо.

### A3a. Polivoks-фильтр (резонансный VCF + ROUTE pre/post)

Резонансный фильтр в стиле **Поливокс** — добавляет агрессивный, хрипящий резонанс и собственный дисторшн, ложится на MOSFET-сатурацию. Оригинал на КР140УД1208; реализуем на **LM13700** (две OTA).

**Топология:**
- 2-полюсный **мультимод**, переключаемый **LP / BP** (панельный свитч MODE-F). HP при желании — вычитанием LP из входа (опц. третье положение).
- Две OTA как voltage-controlled resistor в R/C-цепи, каждая ступень буферизована (буферы LM13700 на борту).
- **RESONANCE** — через OTA-петлю отрицательной ОС; частоты у среза не инвертируются в петле → складываются и усиливаются → резонансный пик, на максимуме — **самовозбуждение**.
- **Filter Drive (фирменная грязь Поливокса):** на высоком резонансе петля **клиппит об рельсы питания** → радикальный дисторшн. Сохраняем намеренно — это и есть «звук лучше/злее».

**Управление:**
- **CUTOFF** — частота среза. Экспоненциальный CV (OTA `gm ∝ I_abc`), knob + CV-in. Диапазон ~20 Гц … ~16 кГц.
- **RESONANCE** — knob + CV-in (опц.). До самовозбуждения.
- **MODE-F** — панельный свитч LP/BP (2-поз; 3-поз с HP — опц.).

**ROUTE pre/post (панельный свитч):**
- Меняет порядок **MOSFET-core ⇄ VCF** (A2.5). Реализация — аналоговые ключи (DG419/MAX4053) кросс-коммутацией, **под mute** (расширяем FSM A7: ROUTE-свитч → GPIO MCU → ramp-down → переключение ключей → ramp-up).
- `pre`: фильтр-свип формирует спектр **до** клипа (что искажаем). `post`: режем грязь **после** (классика).

**Термостабильность:** OTA-фильтр имеет температурный дрейф `gm` → дрейф cutoff. Для арт-объекта допустимо (часть характера), но если нужна стабильность — tempco-резистор в цепи `I_abc` или термокомпенсированный экспандер. Помечено R16.

### A3b. Выходной усилитель — грязный Polivoks OTA-VCA

- Финальный «усилок» — **OTA-VCA в стиле Поливокс** (LM13700), слегка грязноватый/характерный, а не прозрачный. Добавляет брутальности на выходе.
- Совмещает функции: **makeup-gain + мьют-VCA** (A7/ARM). Управляющий ток OTA → 0 = мьют (de-click при смене MODE/ROUTE и ARM-off).
- Level (из пульта) задаёт общий gain через этот VCA.
- После VCA — выходной буфер (TL072/OPA1642), посл. резистор ~1 кОм, AC-связь, защита.

### A3.7. Параметры — сводка (где живут после Godeater + Polivoks)

| Параметр | Что делает | Орган | CV | Источник |
|---|---|---|---|---|
| LEVEL | общий VCA gain тракта | пульт | CV-in (норм. на пульт) | джойстик/ручка пульта |
| DRIVE | глубина захода в нелинейность (Godeater GAIN+INPUT LEVEL) | пульт | CV-in (норм.) | джойстик Y |
| BIAS | симметрия клипа, чёт/нечёт (Godeater CLIP, непрерывно) | пульт | CV-in (норм.) | джойстик X |
| TONE | tilt верх/низ | пульт | CV-in (норм.) | ручка пульта |
| **HPF** | пред-клип ВЧ: бас-дисторшн ↔ тонкий fuzz (гл. фишка Godeater) | **модуль (knob)** | **CV-in** | модуль/внешн. |
| **MIX** | dry/wet clean blend (Godeater CLEAN/Zeus) | **модуль (knob)** | **CV-in** | модуль/внешн. |
| **BASS** | пост-ядро НЧ-шельф | **модуль (knob)** | опц. | модуль |
| **CUTOFF** | частота среза Polivoks-VCF | **модуль (knob)** | **CV-in** | модуль/внешн. |
| **RESONANCE** | резонанс → самовозбуждение/Filter Drive | **модуль (knob)** | CV-in (опц.) | модуль |
| **MODE-F** | LP / BP фильтра | **модуль (свитч)** | — | модуль |
| **ROUTE** | фильтр pre/post относительно сатурации | **модуль (свитч)** | — | модуль |

DRIVE/BIAS/LEVEL/TONE — «играющие», живут на пульте (нормализованы на CV-входы модуля, §A5). HPF/MIX/BASS/CUTOFF/RESONANCE + свитчи MODE-F/ROUTE — «формующие/voicing», живут на модуле. Роль сохранена: пульт играет, модуль лепит голос.

## A4. Video audifier

- Вход: **RCA или 3.5mm**, композит PAL/NTSC, 1 Vpp / 75 Ω.
- Терминатор 75 Ω, AC-связь, защитный кламп.
- Буфер: видеоОУ или обычный ОУ с достаточной полосой на входе (полоса композита ~5 МГц), затем **жёсткий LPF ~15 кГц** (Sallen-Key 2-3 порядка) — отсекает цветовую поднесущую (4.43 МГц PAL / 3.58 МГц NTSC) и большую часть ВЧ-яркости. Остаются строчная развёртка (15.625 кГц PAL — на склоне фильтра, частично) и кадровая (50/60 Гц) + содержимое кадра → характерный «дроновый» бузз и зависимость тембра от картинки.
- Нормировка уровня (трим-потенциометр или VCA) до модулярного уровня.
- Подмешивается **до MOSFET-ядра** в сумматор (A2 → A3), уровень микса — **внутренний трим** (не вынесен на панель — R13).
- При потере сигнала (нет sync) — характерный glitch; намеренно не подавляем.

**Статус видео-пути: под пересмотром (R13).** Тракт проектируется в первую очередь как звуковой; необходимость video audifier пока не подтверждена. На панели крутилки VIDEO нет; VIDEO IN оставлен как опциональный джек (помечен «?»). Если видео из архитектуры уйдёт — джек и весь узел A4 удаляются, освобождая место и ток.

## A5. CV bus, нормализация, аттенюверторы

Четыре CV-входа на панели: **DRIVE, BIAS, LEVEL, TONE**. Каждый:
- Разъём **switched** 3.5mm (Thonkiconn): нормаль-контакт замкнут, когда штекер не вставлен.
- На нормаль-контакт подаётся **CV от ЦАП модуля** (регенерированный из MIDI):
  - DRIVE-in нормаль ← ЦАП «Joystick Y»
  - BIAS-in нормаль ← ЦАП «Joystick X»
  - LEVEL-in нормаль ← ЦАП «LEVEL knob»
  - TONE-in нормаль ← ЦАП «TONE knob»
- При вставке внешнего кабеля нормаль рвётся → внешнее CV перехватывает управление (как в §3.4).
- **Аттенювертер** на каждый вход: ОУ с потенциометром, дающим коэффициент от −1 до +1 (инвертирование + ослабление). Топология: входной сигнал на оба конца потенциометра через инвертор/прямой, движок → вход сумматора. Центр = 0.
- Выход аттенювертера суммируется в управляющую цепь соответствующего параметра ядра.

**Аттенюверторы несут роль befaco-Range/Offset, перенесённую с пульта (B0).** Пульт отдаёт сырой биполярный жест (центр джойстика = 0 V), а **глубину и инверсию модуляции каждого параметра задают здесь**, на принимающем модуле. Это и есть «настройка модуляции на модуле»:
- **Range** = коэффициент аттенювертера (0…±1) — насколько сильно жест влияет на параметр.
- **Offset / центр параметра** — задаётся базовой рабочей точкой параметра (для BIAS — сервопетлёй §A3.4 + базовым смещением; калибруется LUT §C3). Если нужен явный per-axis offset — добавить опц. потенциометр смещения в сумматор параметра (открыто, §A9/R6).
- Биполярный CV джойстика (центр=0) ложится естественно: аттенювертер в центре = нет модуляции, отклонение стика в обе стороны = ± вокруг рабочей точки.

Замечание по нормализации + аттенювертер: классический паттерн — аттенювертер действует и на нормаль, и на внешний сигнал. Для предсказуемости в режиме «без кабеля» закладываем, что при движке аттенювертера в максимум нормализованный CV проходит ×1 (нужен подбор масштаба ЦАП под полный диапазон параметра — калибруется в прошивке, §B-firmware).

## A6. MIDI-in, MCU, ЦАП, CV-выходы модуля

### A6.1. MIDI вход

- Разъём: **TRS 3.5mm, MIDI Type A**.
- Опторазвязка по стандарту MIDI: **6N138 / H11L1 / PC900** на приёмнике (хоть земли в Eurorack общие, опто защищает от земляных петель при подключении пульта с собственным питанием). Резисторы по спецификации MIDI-TRS (current loop).
- Распиновка Type A: **Tip = «hot» (sink), Ring = +3.3V source (через 220 Ω), Sleeve = shield/GND**. (Type A — принятый MMA стандарт; пульт-выход той же распиновки, см. B4.)
- Выход опто → UART RX MCU, 31250 бод.

### A6.2. MCU (STM32G431)

Функции на модуле:
- Парсинг MIDI (running status, 14-bit CC pairs, Note On/Off).
- Преобразование значений в коды ЦАП (с калибровочными таблицами на параметр).
- Драйв ЦАП по SPI.
- Управление логикой MODE → аналоговые ключи (через GPIO) с **mute/crossfade FSM** (A7).
- ARM-логика (глобальный gate enable) → разрешение/запрет выходного VCA.
- Драйв индикаторов модуля (если есть на панели) и приём состояния «кабель вставлен» (для нормализации-индикации).

### A6.3. ЦАП и каналы

**Октальный 16-bit ЦАП DAC8568 / AD5668** (SPI, внутренний/внешний Vref). Каналы:

| Канал | Назначение | Куда идёт |
|------|-----------|-----------|
| A | Joystick Y / DRIVE | нормаль DRIVE-in **и** CV-out «Y» |
| B | Joystick X / BIAS  | нормаль BIAS-in **и** CV-out «X» |
| C | LEVEL knob         | нормаль LEVEL-in |
| D | TONE knob          | нормаль TONE-in |
| E | GATE               | CV-out «GATE» **и** внутренняя gate-логика |
| F | (резерв / internal mod) | — |
| G | Tone servo / bias trim | внутр. |
| H | (резерв) | — |

CV-out X/Y/GATE дублируют джойстик/ножник (§3.4): один и тот же канал ЦАП кормит и нормаль параметра, и выходной джек — поэтому «Y out» физически = тот же CV, что управляет DRIVE. Это ровно поведение из концепта.

Постобработка ЦАП: ОУ-масштабатор каждого канала под системный стандарт (R5): **CV-out X/Y → ±5V биполяр (центр джойстика = 0V), GATE → 0…+5V**. RC-сглаживание (срез ~1-2 кГц) для подавления ступенек обновления ЦАП.

### A6.4. CV-выходы (X / Y / GATE)

- 3× Thonkiconn TS.
- GATE-out: 0/+5V (или +10V) логический gate, фронт от Note On (joystick press / foot switch).
- X/Y-out: непрерывное CV из 14-bit MIDI → 16-bit ЦАП → масштабатор. Разрешение с запасом перекрывает 14 бит → нет ступенчатости (§4.3 концепта).
- Выходы с защитой (последовательный резистор 1 кОм + клампы) — стандарт Eurorack.

## A7. Переключение режимов без щелчков (mute/crossfade FSM)

Конечный автомат в MCU при смене MODE:
1. Принят новый MODE (CC#80).
2. **Ramp-down** выходного VCA (или мьют-VCA на выходе ядра) за ~20-40 мс → тишина.
3. Переключение аналоговых ключей топологии (DG419) в новый режим — в момент тишины, щелчок не слышен.
4. Сброс/преднастройка узлов нового режима (напр. сервопетли SHAPER, фазы VCO для RING).
5. **Ramp-up** VCA за ~20-40 мс.

Суммарно 50-100 мс (§3.2 концепта). Ramp генерится ШИМ→RC / ЦАП на управляющий ток выходного OTA-VCA (A3b). Кривая — экспонента/raised-cosine.

**Тот же FSM обслуживает ROUTE-свитч (pre/post, A3a):** смена порядка core⇄фильтр — тоже под mute, чтобы без щелчка.

ARM (CC#64): выходной OTA-VCA используется как глобальный gate enable — ARM off → ток управления в ноль (с тем же ramp).

## A8. MIX (clean blend) + грязный OTA-VCA + выход (AUDIO OUT)

- **MIX (dry/wet, Godeater CLEAN/Zeus)** — кроссфейд между **clean tap** (A2.5, чистый после входного буфера) и обработанным выходом (сатурация ⇄ фильтр → Tone → Bass). Два OTA/VCA в противофазе от MIX-knob (+ MIX-CV) → сумматор. Сохраняет фундамент/транзиенты. Глобален.
- **Грязный Polivoks OTA-VCA** (A3b) после MIX — финальный «усилок» + мьют-VCA: управляется FSM (A7) и ARM (de-click при смене MODE/ROUTE и gate enable), Level задаёт gain.
- Выходной буфер на **TL072 / OPA1642**, низкий выходной импеданс, посл. резистор ~1 кОм (стандарт Eurorack), AC-связь, защита.
- Разъём 3.5mm TS.

# ЧАСТЬ B. ПУЛЬТ

## B0. Базовое решение: пульт = донорская дрон-аппаратура

Корпус и органы — **репурпозинг реальной RC/дрон-аппаратуры управления** (прямое семиотическое замыкание §4.1, R3 закрыт). Не проектируем механику с нуля — потрошим донора и ставим свою плату.

- Из донора **родную RF/MCU-плату удаляем**, оставляем: гимбалы, тумблеры/переключатели, потенциометры/триммеры, отсек питания, корпус.
- Ставим **свою плату STM32G431**, которая читает сохранённые органы и отдаёт MIDI (TRS + USB) + опц. CV-out.
- **Джойстик берём с готового гимбала донора** — самоцентрирование решается выбором гимбала, а не доработкой пружин (см. B2).
- Распайка органов донора под наши функции (ARM/MODE/LINK/LEVEL/TONE) — по факту, что есть на конкретном доноре; маппинг гибкий в прошивке.

Следствие: **Range/Offset на пульте НЕ делаем** — пульт отдаёт сырой биполярный жест, а глубину/масштаб/инверсию модуляции крутят **на принимающем модуле** (аттенюверторы CV-ins, §A5). От Befaco-архитектуры берём только биполярную разводку оси (B2).

## B1. Питание и автономность

- **LiPo 1S, 3.7V**, ёмкость под ≥8 ч: оценка потребления (см. §10) → ~**2000-2500 мАч** (1S) с запасом. Финал — после замера прототипа.
- **Зарядка USB-C**: контроллер заряда 1S Li-ion **MCP73831 / TP4056** (с защитой DW01+FS8205 или интегрированный **BQ24075** с power-path, чтобы работать во время зарядки). 5V/up to 2A со стандартного USB-C (без PD; CC-резисторы 5.1 кОм для корректного обнаружения как UFP).
- **Boost до системного rail**: 1S → +5V boost (**TPS61023 / MT3608**) для USB-логики и сенсоров, далее LDO +3.3V (MCU, ЦАП). Для CV-out ±-rail (если CV биполярный) — небольшой **charge-pump/inverter** (TPS60403) или DC-DC до +12/−12 (либо CV-out пульта делаем униполярным 0…+5/+8V — решается единым стандартом линейки, §13-R5).
- **Топливомер**: **MAX17048 / BQ27xxx** (I²C, точный SoC) → индикатор заряда (4 LED или OLED-полоска, §B3).
- **Автоотключение >30 мин простоя**: MCU отслеживает активность (движение джойстика/нажатия), по таймауту — load-switch (**TPS22918** / P-MOSFET) обесточивает rail, MCU уходит в standby/shutdown. Пробуждение — кнопка питания / нажатие джойстика (wake на EXTI).
- Кнопка питания (мягкая, через load-switch).

## B2. MCU, ADC, джойстик

- **MCU: STM32G431** (USB FS, 12-bit ADC × несколько каналов с аппаратным оверсэмплингом).

### B2.1. Джойстик: гимбал донора, Befaco-разводка, гибридное самоцентрирование

- **Источник — родной гимбал донорской аппаратуры** (B0). Сенсор — что стоит у донора: резистивные потенциометры (бюджетные пульты) или Hall (AS5600 / 49E-класс в качественных). Аналоговый фронт-энд адаптируется под факт: pot → делитель/ADC, Hall-pot → ADC, AS5600 → I²C.
- **Самоцентрирование — гибрид дрон-стиля: X(BIAS) центрируется пружиной, Y(DRIVE) свободен (фрикцион/трещотка).** Это **ровно «газовый» гимбал стандартной Mode-2 аппаратуры**: вертикаль = throttle (без пружины, держит позицию) → DRIVE, горизонталь = rudder (пружина в центр) → BIAS. **Механику не дорабатываем** — берём throttle-гимбал донора как есть (Mode-2 → левый стик; Mode-1 → правый).
- **Befaco-разводка биполярной оси**: потенциометр оси запитан между **+Vref и −Vref**, движок даёт биполярное напряжение, **центр = 0 V**. Из этого:
  - **раздвоение сигнала**: буфер (TL072/OPA2188) → (а) level-shift в 0…3.3 V → ADC → 14-bit MIDI; (б) масштабатор → ±5 V CV-out (B5).
  - Один жест → и MIDI на модуль Is My, и аналоговый CV на остальную линейку.
  - **Range/Offset на пульте отсутствуют** (B0): аттенюверсия — на принимающем модуле (§A5). Befaco-аналог Range/Offset переехал на приёмник.
- **14-bit для осей X/Y (обязательно §4.3)**: STM32 ADC 12-bit + **аппаратный оверсэмплинг ×16 → 16 бит** effective → чистые 14 бит после фильтрации. Опрос осей ≥ 1 кГц.
  - Если гимбал на AS5600 (I²C, 12-bit) — оверсэмплинг программный + сглаживание; 12 «железных» бит + усреднение → достаточно для 14-bit без слышимой ступенчатости.
  - Резистивный pot донора: следить за шумом движка → EMA-сглаживание + deadzone, иначе сыпет лишний MIDI.
- **LEVEL / TONE**: потенциометры/триммеры донора → ADC, 7-bit MIDI (оверсэмплинг + антидребезг по гистерезису).
- Калибровка: запись min/max/center каждой оси в flash при сервисном жесте; deadzone вокруг центра (важно для центрирующейся X); опциональная гамма-кривая.
  - Y(DRIVE) свободна → центр не нужен, мапим весь физический ход в 0…14-bit (throttle-логика). X(BIAS) центрируется → центр=mid-scale, ход в обе стороны от центра.

## B3. Органы управления

| Орган | Тип | Подключение | MIDI |
|------|-----|-------------|------|
| ARM | тумблер 2-поз | GPIO + debounce | CC#64 0/127 |
| MODE | тумблер 3-поз (ON-OFF-ON) | 2× GPIO | CC#80 0/64/127 |
| LINK | тумблер 2-поз | GPIO | CC#81 0/127 |
| LEVEL | потенциометр | ADC | CC#7 (7-bit) |
| TONE | потенциометр | ADC | CC#74 (7-bit) |
| Joystick X | Hall/ADC | ADC/I²C | CC#16+48 (14-bit) |
| Joystick Y | Hall/ADC | ADC/I²C | CC#17+49 (14-bit) |
| Joystick press | тактовая кнопка | GPIO + debounce | Note C2 On/Off |
| Foot switch | внешний TS-джек | GPIO + debounce + pull-up | Note C#2 On/Off |
| ARM LED | зелёный | GPIO | зеркалит ARM |
| Activity LED | амбер | GPIO/PWM | моргает по MIDI-трафику/нажатиям |
| Battery ind. | 4 LED или OLED | GPIO / I²C | от MAX17048 |

- **LINK** (связь осей): при LINK on прошивка связывает X и Y (например, синхронное движение — одна ось управляет обеими, или зеркалит) — точная семантика «независимо/синхронно» уточняется (§13-R4).
- Антидребезг тумблеров/кнопок — программный (10-20 мс) или RC + Шмитт.
- Foot-switch джек — TS, нормально-разомкнут/замкнут (поддержать оба типа педалей: автоопределение полярности при включении).

## B4. MIDI out (TRS Type A) + USB-MIDI

- **TRS MIDI OUT**: UART TX (31250 бод) → буфер по стандарту MIDI-TRS Type A: **Tip = signal через 220 Ω, Ring = +3.3V через 220 Ω, Sleeve = GND/shield**. Драйв через буфер (можно с 3.3V rail; ток-петля на приёмнике опто). Защита TVS на джеке.
- **USB-MIDI**: STM32G431 USB FS, класс **USB MIDI 1.0** (или MIDI 2.0/USB-MIDI 2.0, если целимся в будущее — но 1.0 совместим со всем). Тот же поток сообщений идёт и в TRS, и в USB (или выбор по настройке). Пульт виден как class-compliant MIDI-контроллер без драйверов.
- USB-C разъём: D+/D− на USB-PHY MCU, CC-резисторы, VBUS → charger (B1).

## B5. CV out пульта (X / Y / GATE)

Пульт умеет управлять другими модулями линейки напрямую (§3.4, §7 концепта), мимо MIDI:
- Маленький **ЦАП на пульте** (квадро 12-16 bit, напр. **MCP4728** I²C 12-bit или **DAC8554** SPI) → 3 канала: X, Y, GATE.
- Масштабатор под системный CV-стандарт линейки: **X/Y → ±5 V биполяр (центр джойстика = 0 V), GATE → 0…+5 V** (R5).
- Для биполярного rail от 1S LiPo нужен отрицательный источник: **charge-pump инвертор** (TPS60403/ICL7660) или малый DC-DC. (R10.)
- 3× джек 3.5mm TS — **добавляются в корпус донора** (сверловка), на доступной кромке.
- CV генерятся **параллельно MIDI** из тех же сырых данных джойстика/ножника, локально на пульте — независимо от того, подключён ли модуль Is My. **Без Range/Offset** (B0): сырой биполярный жест; подстройка глубины — на приёмном модуле.

## B6. Механика пульта

**Решение: донор** (R3 закрыт). Корпус, гимбалы, органы — от реальной RC/дрон-аппаратуры (B0).
- Габарит/эргономика определяются донором; ориентир ~180×100×40 мм.
- Throttle-гимбал (Mode-2 левый / Mode-1 правый) → джойстик DRIVE/BIAS с нужным самоцентрированием (B2.1), без доработки.
- Родные органы донора мапятся под ARM/MODE/LINK/LEVEL/TONE (что доступно физически); недостающее добавляется минимально.
- В корпус добавляются: **USB-C** (заряд + USB-MIDI), **TRS MIDI OUT**, **foot-switch jack**, **3× CV-out** — сверловкой по доступным кромкам.
- Наша плата STM32G431 крепится на место удалённой RF-платы донора.
- Сохранить родные индикаторы донора, если есть, под ARM/activity/battery (иначе добавить LED/OLED).

# ЧАСТЬ C. ПРОШИВКА

Общий стек: **STM32 HAL/LL + бэр-метал C** (или Zephyr, если хотим переносимость; для простоты — bare-metal/HAL). Один репозиторий, две прошивки (`pult/`, `module/`), общий заголовок с MIDI-маппингом (`midi_map.h`) — единственный источник истины по CC/нотам.

## C1. MIDI mapping (канонический, из §4.3 концепта)

Канал по умолчанию 1 (переключаемый, хранить в flash).

| Источник | MIDI | Разрешение | Примечание |
|---------|------|-----------|-----------|
| Joystick X | CC#16 (MSB) + CC#48 (LSB) | 14-bit | MSB первым, затем LSB; модуль собирает пару |
| Joystick Y | CC#17 (MSB) + CC#49 (LSB) | 14-bit | |
| LEVEL knob | CC#7 | 7-bit | |
| TONE knob | CC#74 | 7-bit | |
| ARM | CC#64 | 0/127 | toggle-состояние тумблера |
| MODE | CC#80 | 0/64/127 | SHAPER/RING/GATE |
| LINK | CC#81 | 0/127 | |
| Joystick press | Note On/Off | нота C2 (36) | |
| Foot switch | Note On/Off | нота C#2 (37) | |

14-bit паттерн: всегда слать MSB (CC#16/17) **перед** LSB (CC#48/49); приёмник применяет значение по приходу LSB (или по таймауту, если LSB не пришёл — fallback на MSB·128).

## C2. Прошивка пульта

Цикл (например, основной loop + таймерные ISR):

```
init: clocks, USB-MIDI, UART-MIDI(31250), ADC(oversample), I²C(fuel gauge, joystick),
      load calibration from flash, power-on ramp.

ISR 1 кГц (axis sampling):
  read X, Y (ADC oversample → 14-bit; или AS5600)
  apply calibration (min/max/center), deadzone, optional gamma
  if LINK on: apply link transform(X,Y)
  if changed > threshold (anti-jitter):
     emit 14-bit CC pair (X: CC16+CC48 ; Y: CC17+CC49) to UART + USB

poll ~100-200 Гц (knobs/switches):
  read LEVEL, TONE → 7-bit, hysteresis → CC#7 / CC#74 on change
  debounce ARM/MODE/LINK → CC#64 / CC#80 / CC#81 on change
  debounce joystick-press / foot-switch → Note On/Off (C2 / C#2)

power mgmt:
  update activity timer on any input change
  if idle > 30 min: graceful shutdown (load-switch off)
  read MAX17048 SoC → update battery indicator
  on low battery: warn (LED blink), then safe shutdown

LED:
  ARM LED mirrors ARM state
  activity LED pulses on outgoing MIDI / input motion
```

Особенности:
- **Anti-jitter** на осях: порог изменения + сглаживание (EMA), иначе шум ADC сыплет лишний MIDI-трафик.
- **Rate-limit** 14-bit потока: не чаще, чем UART прожуёт (31250 бод ≈ ~1 KB/с ≈ ~300 трёхбайтных сообщений/с; пара CC = 6 байт → ограничить осевой апдейт ~150-200 Гц при движении, что субъективно мгновенно).
- USB и TRS шлют одинаковый поток (или маршрутизация настройкой).
- Калибровочный режим: спец-жест (например, удержание joystick-press при включении) → запись min/max осей.

## C3. Прошивка модуля

```
init: clocks, UART-MIDI RX(31250, opto), SPI DAC8568, GPIO(mode switches, mute),
      load CV calibration tables, set safe state (muted), Vref settle.

MIDI parser (RX ISR + ring buffer):
  handle running status
  CC#16/48, CC#17/49 → assemble 14-bit X/Y
  CC#7, CC#74 → LEVEL, TONE
  CC#64 → ARM
  CC#80 → MODE (triggers crossfade FSM)
  CC#81 → LINK (affects how X/Y map, if module-side link semantics)
  Note C2/C#2 On/Off → GATE

control loop (~2-5 кГц):
  map 14-bit X/Y, 7-bit LEVEL/TONE → DAC codes via calibration LUT
  DAC A=Y/DRIVE, B=X/BIAS, C=LEVEL, D=TONE, E=GATE
  GATE channel: Note On → gate high, Note Off → gate low (with short de-click ramp)

mode FSM (on MODE change):
  ramp mute VCA down (20-40 ms)
  switch analog mux (DG419) to new topology
  reset new-mode nodes (servo, VCO phase)
  ramp mute VCA up (20-40 ms)

ARM:
  ARM off → hold mute VCA at 0 (ramped)
  ARM on  → release to current level

MIDI timeout / link loss:
  if no MIDI > N ms: hold last values (don't jump), optionally indicate
```

Особенности:
- **Калибровочные LUT** на каждый параметр: компенсируют нелинейность тракта и подгоняют диапазон ЦАП под рабочую область конкретного донорского MOSFET (заполняются при сборке экземпляра — связь с уникальностью edition §6.3).
- Сервопетля SHAPER (§A3.4) — **аналоговая** (не в прошивке), MCU только выставляет опору тока покоя через ЦАП-канал G.
- De-click на GATE-фронтах: короткий ramp ЦАП-канала, чтоб резкий gate не щёлкал.
- Безопасное состояние при старте: muted, пока MIDI не пришёл.

## C4. Общий заголовок `midi_map.h`

Один файл с `#define` всех CC/нот/каналов, подключается обеими прошивками — гарантирует, что пульт и модуль никогда не разъедутся по маппингу.

# §11. План макетирования (порядок сборки прототипа)

1. **Пульт-MIDI первым** (нет аналога, быстрый результат): STM32 + джойстик + тумблеры → MIDI out по USB. Проверить 14-bit, отзывчивость, отсутствие джиттера на реальном софте/DAW.
2. **TRS Type A** линк пульт→модуль-заглушка (MCU только парсит и шлёт в монитор) — проверить опто, распиновку, бод.
3. **Модуль MIDI→CV**: STM32 + DAC8568 → CV-out, нормализация, аттенюверторы. Проверить диапазоны, сглаживание, отсутствие ступенек на 14-bit.
4. **MOSFET-ядро SHAPER** на макете с *обычным* MOSFET → отладить транскондуктанс, сервопетлю термокомпенсации, диапазон Drive/Bias. **Потом** подставить донорский ESC-MOSFET, оттарировать LUT.
5. **RING (PWM)** и **GATE** топологии + аналоговые ключи + mute/crossfade FSM. Отладить отсутствие щелчков при смене MODE.
6. **Video audifier** — отдельно, проверить LPF/уровень/glitch на реальном композите.
7. **Питание пульта** (заряд/boost/fuel gauge/autoshutdown) — последним, после подтверждения потребления.
8. Интеграция, EMC, шум, финальные номиналы, панель.

# §12. Связь с edition (§6 концепта)

- Сокет под донорский MOSFET + входной контроль `Vth/gfs/Rds(on)` → в provenance certificate.
- Калибровочный LUT на экземпляр → «работоспособность в спецификации при уникальном звуке».
- Серийная прошивка одинаковая; различие — только в калибровочных таблицах и физическом MOSFET.
