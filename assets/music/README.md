# Музыка мира — правила эфира (v2)

Без кроссфейдов. Правила автора:
1. **Трек не обрывается** сменой локации — доигрывает до конца,
   затем начинается трек текущей локации.
2. **Посещение локации открывает её трек** — навсегда (localStorage);
   открытый можно включить с радио из любого места.
3. **Радио** (бумажный ярлык внизу справа) — список открытых треков;
   выбор включается сразу; по окончании — снова эфир локации.
4. Пока файла нет — тихая процедурная заглушка (90 с и «конец»).

Файлы кладутся сюда, имя = id локации:

| файл | локация |
|---|---|
| `title.mp3` | заставка (есть) |
| `townlet.mp3` `bridge.mp3` `edge.mp3` | городок · за мостом · край |
| `axial_south.mp3` | осевое·юг |
| `settlement.mp3` `street.mp3` `highway.mp3` `forest.mp3` `toxic.mp3` `quarter.mp3` | зоны ardet.fun |

Формат — любой браузерный (mp3/ogg/m4a); маппинг и громкость —
`prototype/shared/ardet-audio.js: TRACKS, VOL` (копия для сайта —
`src/audio/ardet-tracks.js`, в бандле `build/index.html` — инлайн).

**Деплой ardet.fun**: рядом с index.html должны лежать
`assets/music/*` и `assets/icons/*` (пути от корня сайта).
