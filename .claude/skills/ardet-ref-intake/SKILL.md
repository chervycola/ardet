# Приём референса → клетка → промт

1. **Посмотри картинку** (Read). Определи: сюжет, свет, эпоху-кольцо
   и сторону-азимут (`src/content/world_weave.js` → EPOCHS/SIDES).
2. **Палитро-маппинг**: какие цвета референса ложатся в 6 красок
   канона; чужие цвета — кандидат в «цветовое исключение эпохи»
   (одно на эпоху) или подлежат подтяжке.
3. **Роль**: сцена-walkable / событие / интерьер / объект / вставка
   (таблица — `src/assets/EPOCH_SCENES.md`).
4. **Артерии**: где в кадре дорога/река/линия неба входят и выходят
   (кромки по третям). Если артерий нет — кадр не сцена, а событие.
5. **Запиши в опись**: `world_weave.js` → KNOWN клетки (status,
   refs[]); обнови счётчик прогресса.
6. **Если нужен промт** по мотивам: собери по формуле
   `WORLD_WEAVE.md §4` — [эпоха]+[сторона/час]+[артерии]+стиль-блок;
   пасхалки клетки из `EASTER_LAYOUT.md` с пометкой [П] — в промт.
7. Пасхалки, если видны на референсе, сверь с фондом
   (`EASTER_FUND.md`) и включи в раскладку.

Не переименовывай файлы пользователя; новые генерации —
`weave/E{эпоха}_{сторона}_{n}.jpg` (см. HANDOFF_HIGGSFIELD).
