# Терминал · мёртвые ссылки (черновик на утверждение)
`help`, `whois` и `/secrets` обещают то, чего нет. Досье — справки канцелярии по камертону:
сухо, одна петля, примечание (если есть) не острит. Опираются на уже сказанное героями.

## whois jester / шут
```
> whois ШУТ
>
> должность: шут. единственная
> штатная единица, которой
> разрешено шутить
> основание: разрешение
> выдано в шутку
> местонахождение: у костра
> особые отметки: пропускает
> к кольцу тех, кто отвечает
> игрой на игру
```

## whois sol

```
> whois SOL INVICTUS
>
> «непобедимое солнце». культ
> утверждён в 274 г.
> статус: горит. выбор
> не предоставлялся
> заход: не зафиксирован
```

## whois archivist / архивариус
```
> whois АРХИВАРИУС
>
> должность: занята
> занимающий: не установлен
> по одним записям — Старец.
> по другим — ты

```
