# Переплавка · пачка 1 · диалоги (черновик на утверждение)
Принцип: минимальная хирургия — срезать хвост после пуанта, одна петля на реплику, голос
персонажа сохраняется. jester_home[0] — неприкосновенна, не трогаем.

## Старец
**[2]** (хвост-красивость) — срезать последние две строки:
> Мы — наблюдение. Фиксация. / Текущий том журнала — / девятьсот сорок первый. / Страниц в нём — как в первом. / Записей — меньше.

**[4]** (пафос «старше твоей страны») — вместо хвоста одна петля:
> Меня звали по-разному. / Коэлет. Архивариус. / Проповедник. Собиратель. // Нет ничего нового / под солнцем. / Это я сказал давно. / С тех пор нового / и не было. Я проверял.

**[5]** (лекция о мицелии) — втрое короче, концовка та же:
> «Мох сгорит в огне». / Сгорит то, что на стенах. / Сеть под землёй — нет: / огонь туда не доходит. // В Чернобыле, в реакторе, / нашли гриб, который / растёт к излучению. // Огонь — его еда. / Радиация — его еда. / Ты — тоже. / Просто медленнее.

**[6]** (список-лекция) — без перечня:
> Мох помнит не как ты. / Ты помнишь сюжет. / Мох помнит химию. // Он не знает твоего имени. / Он знает твой состав.

**[8]** (две петли + хвост) — срезать «Это тоже юга. Самая длинная.»:
> Мох победит. / И обнаружит, что / побеждать некого. / Наследство по описи: / азот, фосфор, зола.

## Шут
**[2]** (открытка «огонь и правда») — эталон 6а, утверждён:
> Я тут единственный, / кому разрешено шутить. / Разрешение мне выдали / в шутку.

**[4]** (объясняет шутку) — короче:
> Кот не говорит. / Это его лучший анекдот. / Я так не умею.

**[5]** (хвост про словарь шутов) — срезать хвост и «Настя маленькая»:
> Копали фундамент / будущего. Вырыли яму. / В яму положили Настю. / Будущее — нигде. // Это не моя строчка. / Но я её знаю.

**[8]** (выход из роли, мета-пафос) — эталон 6б, утверждён:
> Шутку про конец света / знаешь? Я тоже. / Короткая.

## Лунный
**[2]** (пророчество про звёзды) — остановиться на петле канцелярии:
> Я держу нити. / По описи их шестьдесят тысяч, / твоя учтена. / Оборванные / не списываются.

**[3]** (датасетная метафора) — без объяснения песка:
> Чёрный песок сыплется / из моей руки. / За ночь набирается две горсти. / Песок ещё тёплый.

## Горящая мусорка
**[2]** (лозунг-диагноз) — заново, одна петля:
> Меня трижды тушили. / Каждый раз — акт. / Акты сгорели. / Тушить перестали: / без акта нельзя.

**[4]** (манифест) — заново:
> Меня внесли в каталог / выставки. Раздел — / «горение». Экспонат — один. / Каталог сгорел первым.
