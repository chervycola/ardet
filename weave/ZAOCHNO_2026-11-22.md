# Заочно
статус: черновик помощника 22.11, автором не принят; в игру не влит. Голоса — по `weave/STYLE_2026-11-22.md`.

Путник, машинист, терминал. Семь сцен.

**Завязка.** Машинисту некому передать смену. Терминалу нечем отправить поезд. Путник ходит между ними и находит способ, при котором все остаются на месте, а поезд уходит.

Что взято из игры как есть: ржавый поезд на боку, машинист не оборачивается, пар из трубы («Откуда — машинист не проверял. Вдруг остановится»), жена сошла в Бологое двенадцать расписаний назад, «Я сижу. Это разные вещи», «Мне некому передать смену», стоп-кран с целой пломбой и стрелкой под полом, трава у колёс не растёт, строка журнала «передача смены состоялась. заочно.»

---

## 1. Пар

У ржавого поезда. Машинист в кабине, спиной.

```
путник:   поезд на боку. а из трубы пар.
терминал: котёл холодный.
          с позапрошлой эпохи.
путник:   а пар?
терминал: пар в описи не числится.
путник:   но он идёт.
терминал: значит, идёт без описи.
путник:   откуда?
терминал: машинист не проверял.
путник:   а ты?
терминал: я не машинист.
```

```
машинист: Пар белый. Это хорошо.
          Белый — значит, вода.
          Чёрный — уголь дрянь.
          А нет пара — приехали.

          У меня белый.
          Откуда — не смотрел.
          Она двенадцать расписаний так дышит,
          а я ей в трубу заглядывать буду?
```

## 2. Заявка

Путник ходит от кабины к вехе и обратно.

```
путник:   ему нужно расписание. на Бологое.
терминал: расписание выдаётся
          готовому составу.
путник:   состав лежит на боку.
терминал: «лежит» — не графа.
          есть «готов» и «не готов».
путник:   тогда не готов.
терминал: тогда расписания нет.
путник:   а если будет расписание —
          он встанет?
терминал: нет. но будет лежать
          по расписанию.
```

```
путник:   он говорит: состав готов,
          когда есть расписание.
терминал: это он верно говорит.
путник:   так кто первый?
терминал: первым обычно ходит тот,
          кто между.
путник:   я уже ходил. дважды.
терминал: трижды. я веду.
```

## 3. Стоп-кран

Путник забирается в кабину и тянет красную ручку. Под полом щёлкает стрелка. Машинист смотрит на ручку и снова вперёд. (Эта сцена в игре уже есть.)

```
терминал: стрелка четырнадцать переведена.
          кем?
путник:   мной. там была ручка.
терминал: пломба?
путник:   была цела.
терминал: теперь это надо считать.
путник:   долго?
терминал: ...
путник:   у поезда пар гуще пошёл.
терминал: ...
путник:   ты считаешь — а там пар.
терминал: тёплый воздух надо
          куда-то девать.
          труба была свободна.
```

Путник проверяет.

```
путник:   сколько в пустоши песка?
терминал: считаю.
путник:   ...пыхнул.
терминал: ты кого проверяешь?
          меня или песок?
путник:   поезд.
терминал: поезд в порядке.
          он у меня на балансе.
```

## 4. Не говори

```
путник:   он думает, это котёл.
терминал: он не проверял.
путник:   сказать ему?
терминал: скажи.
          пар от этого не изменится.
путник:   а он?
терминал: сейчас он записан «на посту».
          как записать его после —
          такой графы нет.
путник:   ...
терминал: я бы не открывал графу.
```

## 5. Заочно

```
путник:   ему надо в Бологое.
          поезд не пойдёт. никогда.
терминал: не пойдёт.
путник:   и что делать?
терминал: есть графа «заочно».
путник:   это как?
терминал: дело сделано,
          а никто не ходил.
путник:   так можно?
терминал: так делается почти всё.
путник:   ...оформляй.
терминал: отправление — заочно.
          следование — заочно.
          машинист — на месте.
          как и положено в пути.
```

## 6. Бологое

У кабины.

```
путник:   по бумагам ты выехал.
машинист: ...
          Двенадцать расписаний сидел.
          На тринадцатом выехал. Сидя.

          Ну. Я бы и так сидел.

          ...И как там?
```

Путник там не был. Но спросил живой, и отвечать живому.

```
путник:   перрон. низкий, в две доски.
          фонарь горит, хотя светло.
          скамейка крашеная. липнет.
          буфет закрыт,
          а чайник на окне тёплый.
машинист: Чайник — это она.
          Она всегда так. Уйдёт,
          а чайник тёплый.

          Значит, недавно.
```

```
терминал: ты там не был.
путник:   не был.
терминал: чайник вносить?
путник:   вноси.
терминал: со слов?
путник:   со слов.
терминал: внёс. «чайник. тёплый. 1 шт.»
```

## 7. Смена

```
машинист: Раз выехал — кто-то ведёт.
          Не я. Я сижу.

          Кто пар даёт, тот и ведёт.
          Я не проверял.
          Не проверял — не значит не знал.

          Смену сдал.
          Теперь я пассажир.
          Зашёл, правда, не с той стороны.
```

Он снимает фуражку и вешает на красную ручку. Сидит, как сидел.

```
путник:   он сдал смену.
терминал: в журнале:
          «передача смены состоялась.
          заочно.»
путник:   значит, ты теперь машинист.
терминал: я считаю. поезд идёт.
          это разные вещи.
путник:   куда идёт?
терминал: в Бологое.
путник:   когда будет?
терминал: прибытие — по готовности.
путник:   ...
          у колёс трава пошла.
терминал: трава в описи не числится.
путник:   но идёт.
терминал: значит, идёт без описи.
```

## Как это живёт в игре

- **Семь приходов.** Сцена открывается, когда сыграна предыдущая; между ними можно ходить куда угодно.
- **Пар отвечает на счёт.** Каждый раз, когда путник отправляет терминалу вопрос с любой вехи, у ржавого поезда гуще идёт пар. Игрок может заметить связь задолго до третьей сцены.
- **Машинист остаётся в кабине.** Фигуры ждут вернувшегося, поэтому он не исчезает. Меняются две вещи: фуражка висит на красной ручке, у колёс растёт трава.
- **Строка журнала** «передача смены состоялась. заочно.» получает своё место: после седьмой сцены.
- **Три голоса.** Терминал сухой. Машинист живой, ему можно ярко. Путник говорит коротко и один раз говорит ярко: в шестой сцене, когда описывает Бологое, которого не видел.
