# Заочно
статус: ПРИНЯТО АВТОРОМ 22.11 («заочно тоже брать»), редакция 2 — после разбора панели (`weave/STORY_PANEL_2026-11-22.md`, раздел 5). **Влито 25.11** (слово автора «погнали»): канал «странник — терминал», `src/world/dispatch.js`, тексты — `src/content/dispatch_scenes.js` дословно; см. `weave/DISPATCH_2026-11-25.md`. Голоса — по `weave/STYLE_2026-11-22.md`.

Странник, машинист, терминал. Шесть сцен.

**Завязка.** Машинисту нужно расписание, которого не дают лежащему составу. Странник ходит между ним и терминалом и находит способ отправить поезд, не трогая его.

Что взято из игры как есть: ржавый поезд (вагоны на боку, паровоз носом в землю), машинист не оборачивается, пар из трубы («Откуда — машинист не проверял. Вдруг остановится»), жена сошла в Бологое двенадцать расписаний назад, «Я сижу. Это разные вещи», стоп-кран с целой пломбой и стрелкой под полом, третий осмотр поезда («Трава у колёс подступила на палец»).

Что изменено против первой редакции: пар остаётся без разгадки; о том, говорить ли машинисту правду, никто вслух не рассуждает; машинист сидит, как сидел, фуражка на голове; смену «сдаёт» только бумага, и он об этом не знает; у терминала одна графа — «заочно».

---

## 1. Пар

У ржавого поезда. Машинист в кабине, спиной.

```
странник: вагоны на боку. а из трубы пар.
терминал: пар в расписании не стоит.
странник: но он идёт.
терминал: значит, идёт без расписания.
странник: откуда?
терминал: машинист не проверял.
странник: а ты?
терминал: я не машинист.
```

```
машинист: Пар белый. Это хорошо.
          Белый — значит, вода.
          Чёрный — уголь дрянь.
          А нет пара — приехали.
          ...
          У меня белый.
          Откуда — не смотрел.
          Она двенадцать расписаний так дышит,
          а я ей в трубу заглядывать буду?
```

## 2. Заявка

Странник ходит от кабины к вехе и обратно.

```
странник: ему нужно расписание. на бологое.
терминал: расписание выдаётся
          готовому составу.
странник: вагоны лежат.
терминал: «лежит» не бывает.
          бывает «готов» и «не готов».
странник: тогда не готов.
терминал: тогда расписания нет.
странник: а если будет расписание —
          он встанет?
терминал: нет. но будет лежать
          по расписанию.
```

```
странник: он говорит: состав готов,
          когда есть расписание.
терминал: это он верно говорит.
странник: так кто первый?
          я уже ходил. дважды.
терминал: трижды. я веду.
```

## 3. Стоп-кран

Странник забирается в кабину и тянет красную ручку. Под полом щёлкает стрелка. Пар идёт, как шёл. (Эта сцена в игре уже есть.)

```
терминал: стрелка четырнадцать переведена.
          кем?
странник: мной. там была ручка.
терминал: пломба?
странник: была цела.
терминал: теперь это надо считать.
странник: долго?
терминал: ...
```

## 4. Заочно

У вехи. Терминал досчитал.

```
странник: ему надо в бологое.
          поезд не пойдёт. никогда.
терминал: не пойдёт.
странник: а отправить, не трогая?
терминал: заочно.
странник: это как?
терминал: дело сделано,
          а никто не ходил.
странник: так можно?
терминал: графа есть.
странник: ...оформляй.
терминал: отправление — заочно.
          следование — заочно.
          машинист — на месте.
          как и положено в пути.
```

## 5. Бологое

У кабины.

```
странник: по бумагам ты выехал.
машинист: ...
          Двенадцать расписаний сидел.
          На тринадцатом выехал. Сидя.
          ...
          Ну. Я бы и так сидел.
          ...
          И как там?
```

Странник там не был.

```
странник: перрон. низкий, в две доски.
          фонарь горит, хотя светло.
          скамейка крашеная. липнет.
          буфет закрыт,
          а чайник на окне тёплый.
машинист: Чайник — это она.
          Она всегда так. Уйдёт,
          а чайник тёплый.
```

```
терминал: ты там не был.
странник: не был.
терминал: чайник вносить?
странник: вноси.
терминал: со слов?
странник: со слов.
терминал: внёс. «чайник. тёплый. 1 шт.»
```

## 6. Смена

У кабины.

```
машинист: Раз выехал — кто-то ведёт.
          Не я. Я сижу.
```

Сидит, как сидел. Потом у вехи.

```
странник: у колёс трава подступила.
          на палец.
терминал: трава в расписании не стоит.
странник: но идёт.
терминал: значит, идёт без расписания.
странник: он говорит: кто-то ведёт.
          не он.
терминал: в журнале:
          «передача смены состоялась.
          заочно.»
```

---

## Как это живёт в игре

- **Шесть приходов.** Сцена открывается, когда сыграна предыдущая; между ними можно ходить куда угодно.
- **Машинист остаётся в кабине.** Он не оборачивается, фуражка на голове, пар идёт, как шёл. Его реплики в игре остаются правдой.
- **Трава** — не новая вещь: это третий осмотр поезда, он в игре уже есть.
- **Новое в мире одно:** строка в журнале терминала «передача смены состоялась. заочно.» Она появляется после шестой сцены. Раньше её предлагали ставить после первого падения; по слову автора 22.11 она уходит сюда.
