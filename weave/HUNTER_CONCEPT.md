# ОХОТНИК · концепт стрима «сетка ищет спрятанное»
Идея автора: запустить другую нейросеть бегать по ardet в поисках
всего, что мы спрятали, и стримить прохождение с комментарием.

## Почему это почти готово технически
Сессия разработки уже «играет» в игру headless-браузером: телепорты,
клики по меню, чтение осмотров и состояния — всё через SystemJS-модули
(`System.import('world/locations')` и т.д.) плюс Playwright. Охотнику
нужен тот же харнесс, но с честными ограничениями.

## Архитектура (три слоя)
1. **Тело** — Playwright + сборка игры. API честного игрока:
   `walk(dir, ms)`, `look()`, `use()`, `openMap()`, `screenshot()`.
   Никаких телепортов и чтения реестра пасхалок: только то, что видит
   экран (скриншот) и текст открытых панелей (DOM осмотра/диалога).
2. **Голова** — модель-охотник (другая сетка или другой инстанс Claude
   с ЧИСТЫМ контекстом, без знаний о фонде). Цикл: скриншот+текст →
   решение (куда идти, что осмотреть) → действие → короткий устный
   комментарий. Дневник находок ведёт сама.
3. **Сцена** — стрим: окно игры + оверлей комментария (текст → TTS
   при желании) + счёт канцелярии. OBS/ffmpeg пишет; чат может
   подбрасывать «горячо/холодно» (модератор решает, читать ли).

## Канонная рамка (важно: не «бот проходит», а персонаж мира)
Охотник — **пятый наблюдатель**: канцелярия завела на него дело.
- У неё есть полный реестр (наши JSON) — она сверяет находки и ведёт
  «ОПИСЬ НАЙДЕННОГО: N из 219. ОСТАТОК УЧТЁН».
- Охотник реестра не видит: слепая охота честна и смотрибельна.
- Провалы в брейнрот, зыбучий песок, Пятая поправка Шута — всё
  становится контентом само.

## Этапы
- **Э1. Харнесс игрока** (день): API из трёх десятков строк поверх
  существующих тестов; лог действий в JSONL.
- **Э2. Сухой прогон** (день): охотник 30 минут без стрима; читаем
  дневник, чиним слепые места (нечитаемые панели, застревания).
- **Э3. Сцена** (день): ffmpeg-запись, оверлей комментария, счёт.
  Первый стрим — запись, не лайв: право на монтаж.
- **Э4. Лайв** — когда запись докажет темп.

## Риски и ответы
- Скука блуждания → карта-план у охотника есть (M), счёт канцелярии
  подкидывает интригу; сессии по 40–60 минут.
- Охотник читает код игры → запрет инструментов, только экран.
- Стоимость → комментарий батчами, скриншот раз в 2–3 сек.

## Мера успеха
Найдено за час; доля позиций, которые охотник ПОНЯЛ (пересказал
груз, не только увидел) — это и есть тест несущего юмора.
