## Мир (открытый диск) — src/world/disc.js
- Городок в центре (TOWN), вокруг 9 колец эпох (RING_W=200), за девятым —
  кольцо огня (FIRE_W), за ним стихии краёв (edges.js): юг песок, восток мусор,
  север лёд (трещины экрана, разряд телефона), запад токсичное озеро. Все роняют
  в брейнрот; падения милосердны (возврат к костру).
- Вне времени — только CORE (круг вокруг костра, место пробуждения). Остальной
  городок «тронут временем»: эпохи локаций в ERA_HINT (world_frame.js).
- Земля рисуется аналитически по вьюпорту (render/ground.js) — мир любого размера
  без запечённого полотна; запечён только городок (3000×1800), блит со сдвигом
  SHIFT_X/SHIFT_Y. Границы колец рваные (warpedDist, шум+дизеринг), таблички
  кластерами «сцен» (sidePoint), тропы вьются. Данные городка сдвигаются на чтении.
- Носители мемов: EGG_SIGNS/EGG_LORE/EGG_TERM/EGG_INSCRIPTIONS/EGG_NODES
  в src/content/eggs_transfer.js; таблички улицы в ulitsa_db.js; фонд — src/assets/EASTER_FUND.md.
- Карта-опись (артефакт, пересобирается из живой сборки): последняя версия
  https://claude.ai/artifact/GerSZCutN5QuNRuxJs24K7 (скрипт сборки — в scratchpad,
  но scratchpad НЕ переживает сессию; при нужде пересобрать из build через playwright).

## Канон (skills/ardet-canon/SKILL.md) — ключевое
- Мир смешон, потому что не знает об этом; канцелярия — верующий, пишет всерьёз.
- Проверка казённой строки; шутку не объяснять, объект не называть; пасхалка — не кнопка.
- МОРАЛЬ режем (пересказ показанного), ВЫВОД-ОТСЫЛКУ охраняем (открывает второй
  слой: произведение, историю слова). Правки автора (ardet-edits.json) — последняя
  редакция, аудит/ножницы их НЕ трогают.
- Актуалочка/факты: только задокументированное (суды, урегулирования, офиц. отчёты,
  признанное самими). Живые люди — по роли/инициалу (д-р Ф.). Конспирология: не вся
  ошибается одинаково (C8, табак, этил-бензин годами звали паранойей); не путать
  «не подтверждено» с «ложно». Детские темы в шутку не подавать. Про биоугрозы —
  без рецептов/пошагово.
