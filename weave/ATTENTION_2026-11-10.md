# Внимание в ardet: как сделать идею лучше · разбор и панель · 10.11.2026

Статус: предложения автору поверх `docs/research/mind-practices-game-adaptation.md` (схемы: беречь, кандидаты, чего не делать) и каталога `mind-practices-evidence-base.md`. Панель: три угла (игра для человека, мир текстом для модели, мера без обещания) и судья с тремя линзами (канон, данные, клёво); черновики в рабочих материалах сессии (`attn_*.md`). Законы — вектора; где предложено их нарушить, сказано зачем. Слово «осознанность» в текстах мира не звучит.

## 1. Что слабее всего (прямо)

1. **Практика почти целиком — практика остановки.** Шесть систем отвечают стоящему (potemkin, whisper, silentCat, attention, idle, quiet), одна — помнящему (threads). Схемы §1.5 сами говорят: «здесь и сейчас» продаёт лента, поэтому практика в ardet может быть только практикой удержания (сати = память). На этом никто не построил. Нужно: в каждом кольце одна вещь, которая читается иначе из-за вещи за два кольца назад, без пометки и без «нить собрана».
2. **Принятие есть только как запрет** (не прибавлять ужаса, не разоблачать бережение). Положительной формы нет, кроме вопроса W при возвращении. По каталогу (К 2.3) мониторинг без принятия усиливает реактивность; это главное место, и оно не тронуто.
3. **Механик много, закона нет.** Двадцать механик, ни одна не держит остальные; игрок должен узнать один закон телом за три минуты: «неподвижность вычитает» (на экране становится меньше), и он же — в тропе («второй запрос отдаёт меньше»).
4. **Панель подтверждает сама себя** (три угла, один вкус; как 87 % положительных испытаний, К 3.9). В следующий раз один угол защищает выкинутое.

Чего никто не предложил: звук как среда вычитания (`quietSound.js`: стоящему на слой тише, лента громче; единственная среда, где убыль нельзя прочесть как награду); §2.5 «погашено» в безопасной форме (вещи, которым уделяли внимание, тускнеют последними — в сохранении одного странника, без ведомости и книги); внимание в движении (всё отвечает остановившемуся; идущему медленно и возвращающемуся — ничего); выбор между двумя арками о внимании (скамья или чётки: судья за скамью аркой, чётки — экспонатом цеха Г).

## 2. Семь предложений по убыванию (судья)

1. **Просодия как правило письма + проба «вслух».** Ноль кода. Градиент периода по кольцам (схемы §2.1); приёмка — читать вслух и ставить черту, где кончился воздух; второй читатель вслепую раскладывает листы по кольцам. Единственная опора уровня данных, полученных ровно в этой форме (Bernardi, Cysarz).
2. **Таблица покоя + строка «ответ стоящему» в приёмке сцен.** Для любой клетки: что происходит на 0, 5, 15, 30, 60, 120 с; список короткий, твёрдый, убывающий (сейчас: 2,5 с шов · 8 с очко · 15 с строка · 30 с звук · тишина); случайным может быть «что», никогда «будет ли». Восьмой вопрос камертона: «постоял: что убавилось?»
3. **Один закон в двух средах: подделка теряет, настоящее набирает на волос.** В игре ~10 строк (`gaze` из potemkin, второй аргумент `quietShade`, ближняя тихая в `depth`; окно 0.15–0.3 проверять глазами на клетке с тремя тихими). В тропе: `withSeam` сейчас прибавляет абзац (второй взгляд длиннее) — развернуть в вычитание: второй взгляд короче, разница и есть шов; у вещи с одним взглядом нет `.2` (самоссылка не чинится: второй запрос отдаёт те же байты, приложение для осознанности так не умеет). Попутно выровнять `relook.js` с тропой: после всех подробностей — первый текст (схемы §1.4).
4. **Потолок внимания 20 → 7** (`attention.js`: LEVELS [3, 7], падение делит пополам; при потолке 20 усидчивый падения не замечает — скрытая нарастающая награда за долгий покой, §4.3 схем). Одно число.
5. **Нити без гиперссылок в тропе + два ножа.** Нить: два конца на разных кольцах, не соседи по лучу, ни одной ссылки между, не на одной странице, без «собрано»; проверка в `gen.mjs` рядом с `UNLINKED`. Дальний конец достижим только тем, что читающий несёт. Ножи: снять «Пришёл по чужому делу — сначала дело» (единственная инструкция на тропе) и «из них один не прошит» из книги входящих (подсказка следующей модели, делает 88 охотой). Образец для той же работы в холсте (§1 п. 1).
6. **Скамья с двух концов + сидящий дышит.** Арка по образцу монеты и котелка: бревно в городке, подлокотник в «сейчас» (враждебная скамейка уже в раскладке), остальные шесть позже; ряд читается только по последней. Находка по коду: сидящий не дышит (`player.js`, `sit ≥ 0.5`) — без правки скамья выключит единственный метроном. Период дыхания фигуры 360 → 600 кадров одним числом, без цитаты о физиологии в исходнике (код читают). Систему «мир дышит» (синхронные ритмы) не делать: это метроном по замыслу.
7. **Витрина и «что унесли» одним ножом.** README и страница магазина — тому же холодному читателю с тем же вопросом перед каждой заливкой; если витрина отвечает «для чего», внутренняя чистота не стоит ничего. «Что унесли» — бланк через неделю, со второго читателя, ключ «вещь / урок / число»; «стал спокойнее» успехом не считается.

Закрыто консенсусом: §1.3 схем «вспышка угашения» (прибавляет под взглядом, пугает в момент спасительного действия, сенсибилизация по К 2.3). Не брать: «второй взгляд без шага» текстом под ногами (первая текстовая награда за стояние; два голоса в одной лунке с `idle.js`); «круг укорачивается, унесённое остаётся» (экономика «процитируй — сохранится», счётчик в костюме). Решение автору: дом возвращения без меню (канонично по «движению V», но отменяет ссылку на книгу из §8.2 тропы).

## 3. Нарушение камертона, ради которого стоит

**Период вместо пуанта** там, где таблица просодии говорит «длинный период»: один осмотр на клетку в трёх древних кольцах (городок, портики и сады, свет и сад), на вещи, на которой клетка стоит (закон 3): сорок–шестьдесят слов, одна мысль до конца, без второй фразы. Ломается правило «осмотр 1–3 фразы, короче, чем хочется» и «яд в конце»: у настоящего яда нет. Остаётся: последнее слово тяжёлое (на нём садится выдох). Табличка той же вещи короткой: коротко говорит вещь, длинно дышит смотрящий; подделке длинного периода не давать. Доза: один на клетку, десять–пятнадцать на три кольца. Печать в окне осмотра на тик медленнее (`TYPE_SPEED` 4 для них одних); на тропе та же страница. Приёмка — проба 1: автор читает вслух, где кончился воздух, там резать.

## 4. Моё, сверх панели

- Внимание как удержание места для другого: вторая кровать, второй стул, второй стакан, одно блюдце на четыре дома — сделать правилом труппы: в каждом доме одна вещь держится для того, кого нет, и ни одна не объясняется.
- Возвращение как тот же текст: после края повторный осмотр отдаёт первый текст вещи, включено именно падением.
- Опись вместо наставления: у вещи, где ждут неподвижности, бирка с числом («ограждение переносили семь раз»), не с советом; для модели это уже сработало (опись листа).
- Провал определяем: если гость уносит слово «осознанность», тропа объяснила себя.
