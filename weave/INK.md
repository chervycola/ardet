# Вторая краска в игре · проба

Красный — вторая печатная краска (норма Reve вер. 2, ветка
`claude/inspiring-goodall-uy7y4j`, `weave/REVE_PROJECT.md`). В игре она
кладётся отдельным прогоном поверх отпечатанного кадра: `src/render/ink.js`.

| ступень | покрытие | что красит в игре | когда включается сама |
|---|---|---|---|
| 0 · индикаторы | 1–3 % | луна гаснет, общая красная подкраска гаснет; красное — только точки (диоды, штампы) | за краем, в пустыне брейнрота |
| 1 · норма | 5–10 % | плашка луны с потёками, багровая полоса неба по верху кадра | всегда по умолчанию |
| 2 · группа | 20–30 % | вещь в фокусе и её родня в кадре отпечатаны киноварью: постройка — весь ансамбль кольца и стороны, знак — все знаки того же имени; форма сдвинута на точку (приводка) | пока открыто меню или осмотр |
| 3 · заливка | 60–90 % | кадр делится на две формы: тёмная треть — чёрная графика, остальное — красный воздух (багровый → киноварь → светлая киноварь); не-красными остаются огонь и свеча, белое прожигает | кольцо огня, брейнрот, 1,6 с при проходе врат городка |

Переходы между ступенями плавные (около секунды).

**Проверка руками:** клавиша `I` (`Ш`) — авто → 0 → 1 → 2 → 3 → авто; в углу
подпись ступени. Или адрес с `?ink=0..3`. На ступени 2 без осмотра группой
становится ближайшая постройка.

**Не сделано (по решению авторов — позже):** третьи краски (индиго, токсик,
шоколад, шалфей), зерно по эпохам, царапины, вторые краски по эпохам.

**Цена:** заливка читает кадр с видеокарты и перекрашивает его по точкам в
логическом разрешении 640×360. В безголовом браузере без видеокарты это
+~20 мс на кадр; на живой машине — проверить.
