```

странник: а кого он ждёт?

странник: я же пришёл.
терминал: пришёл похожий.
```

## Sol

#### Не заходит
```
странник: Старец говорит, Sol к нему
          ни разу не зашёл.
терминал: Sol не заходит.
странник: гордый?
терминал: солнце.
```

#### Основание
```
странник: Sol говорит, его никто не зажигал.
терминал: в журнале: «горит с основания».
странник: а основание?
терминал: не найдено. ищут.
странник: давно?
терминал: при его свете.
```

#### Ветка
```
странник: у Sol в руке ветка. горит
          и не сгорает.

терминал: да.
странник: в чём разница?
терминал: первую держат.
```

#### Дыхание
```
странник: Sol дышит раз на четыре моих.
терминал: ты частишь.

```

#### Монитор
```
странник: на мониторе у Sol строка:
          «чем могу помочь?»

терминал: а это я.
```

## Старец и кот

#### Второй стул
```
странник: у Старца два стула.
          на втором пыль стёрта.
терминал: это твой.
странник: я тут первый раз.
терминал: он протирает каждый день.
странник: для кого?
терминал: до сегодня — впрок.
```

#### Пометка
```
странник: в библиотеке на корешке пометка:
          «подозрительный, но молчит».
терминал: рука Старца.
странник: это он про книгу?
терминал: про Ночного он пишет так же.
```

#### Одна строка
```
странник: Старец каждый вечер пишет
          одну строку.
терминал: девятьсот сорок томов.

странник: кто?
терминал: Sol.
странник: так сходил бы к нему сам.
терминал: тогда некому писать, что не зашёл.
```

#### Блюдце

терминал: кот не спрашивает.
```

#### Девятая
```
странник: в палатке записаны жизни кота.
          девять. восемь зачёркнуты.
