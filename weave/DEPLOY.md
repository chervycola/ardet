# Деплой ardet.art

Игра — статический сайт: одна страница со всем кодом внутри плюс папка
`assets/` с картинами, музыкой и значками. Сервер ничего не считает; сеть
странников ходит в Supabase прямо из страницы (публичный ключ уже в сборке,
weave/NET.md).

## Собрать

```
npm run site          # = node build.js && node site.js
```

Появится папка `site/` (в git не идёт) — ровно то, что лежит в корне хостинга:

```
site/
  index.html          игра (на телефоне сама включает касания)
  mobile.html         то же с флагом телефона — по желанию
  assets/icons/       значки вкладки и экрана «Домой»
  assets/logo/        эмблема
  assets/music/       title.mp3 (≈24 МБ) и другие треки, когда появятся
  assets/portraits/   портреты протокола беседы (jester, sol, nocturnal…)
  assets/places/      картины мест — вклейки в окно осмотра (weave/PLACES.md), когда появятся
  assets/scenes/      entry.webp — заглавная
```

## Залить

Содержимое `site/` — в корень сайта ardet.art (через панель хостинга или
FTP/SFTP), с сохранением путей: `index.html` рядом с папкой `assets/`.
Права на файлы — 644, на папки — 755 (site.js ставит 644 сам).
Если музыка не менялась, `assets/music/` можно не перезаливать — она самая
тяжёлая.

## Проверить

1. https://ardet.art/ — на заставке оттиск версии (короткий хеш коммита
   и дата); он же в консоли: `[оттиск] …`. Старый оттиск — кеш: Ctrl+F5.
2. Войти, подойти к Шуту у костра, «говорить» — слева от протокола
   портрет. То же у Sol Invictus и Лунного.
3. DevTools → Network: `assets/portraits/jester.png`, `sol.png`,
   `nocturnal.png`, `assets/scenes/entry.webp` — 200. 404 на прочих
   портретах (elder, dumpster, machinist, archivist, cat, moss),
   `scenes/ending.png` и `assets/ui/dlg-protocol-*.png` — норма: картин
   ещё нет, игра прячет рамку.

## Как картины находятся

`src/assets/loader.js` ищет каждый файл по очереди: `window.ARDET_ASSET_BASE`
(если задан) → `assets/…` рядом со страницей → `../assets/…` (локальная
сборка `build/index.html` берёт картины из корня репозитория). Новая
картина = файл по пути из `src/assets/manifest.js`; код трогать не нужно.
Музыка — так же, база `assets/music/`.

## ardet.fun

Отдельный хостинг, глушит JS политикой CSP — игра там не запустится.
Нужен 301-редирект с ardet.fun на ardet.art (в панели того хостинга).

## Вес

Портреты пришли PNG 1024×1280 по 2,2–2,8 МБ; заглавная предзагружает все
сразу (≈7,7 МБ). Рамка на экране — 168×210 точек (на телефоне 72×90),
с запасом на плотный экран хватает 672×840. Пробный пережим в WebP:
1024×1280 q90 — 360–575 КБ на картину, 672×840 q88 — 150–230 КБ.
Решение за автором; если да — сменить расширения в manifest.js.
