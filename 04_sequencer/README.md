# Генеративный Eurorack-секвенсор (physical sample scanning)

Отдельный проект (не входит в 9-модульную серию SYSTEM SUICIDE, но концептуально родственен): сменный физический образец — кристаллический нарост, пористый материал — сканируется сенсорной матрицей; из геометрии детерминированно извлекаются метрики → CV/pitch/gate. «Застывшее вычисление», physical lookup table. Та же пластина → та же музыка.
