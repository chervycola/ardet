# ДИСКРЕТ · Визуальный брендинг

Пакет для форума о музыкальных технологиях [diskret.space](http://diskret.space/).
Задача — единый визуальный код для анонсов участников: кладём одну сетку поверх
любого фото (девайс, синт, педаль, прибор), и весь поток читается как **один прибор,
а не случайный сток**.

Слоган системы: **«Не растворяется. Переключается.»**
Тех-заключение: *это не графика о технологии — это графика, работающая как технология.*

## Что внутри

```
branding/
├── preview.html          — галерея-пич: 4 рамки + правила системы (открыть в браузере)
├── frames/
│   ├── frame-D-forum.svg    — D «Карточка форума»  (рекомендую · чистый плакатный стиль)
│   ├── frame-B-plashka.svg  — B «Плашка»           (универсальная · фото на весь кадр)
│   ├── frame-A-pribor.svg   — A «Прибор»           (осциллограф · максимум разметки)
│   └── frame-C-signal.svg   — C «Сигнал / Порог»   (растр + пунктир · с характером)
└── README.md
```

Все рамки — **SVG 1080×1350** (4:5, портрет для соцсетей). Открываются в
Figma / Illustrator / Inkscape и прямо в браузере.

## Четыре рамки — когда какую

| | Рамка | Когда брать |
|---|---|---|
| **D** | Карточка форума | Основа ленты. Чистый стиль плакатов форума: воздух, жирный гротеск-имя, красный точечно. Ближе всего к текущему бренду. |
| **B** | Плашка | Самая универсальная. Фото на весь кадр + чёрная плашка с именем. Читается на любом снимке. |
| **A** | Прибор | Флагманы и хедлайнеры. Фото «на экране осциллографа», максимум технической разметки. |
| **C** | Сигнал / Порог | Когда нужен характер. Фото в пунктирном «поле наблюдения», растр как структура, порог-волна, тег СИГНАЛ. |

## Как собрать карточку участника

1. **Фото.** В шаблоне замените путь в `<image href="PHOTO.jpg">`. Снимок
   кадрируется по слоту автоматически (`preserveAspectRatio="… slice"`) —
   заранее ресайзить не нужно.
2. **Текст.** Отредактируйте узлы с пометкой `EDIT`: имя, роль, индекс участника
   (красный `№` / `ID`), дата и место.
3. **Экспорт.** Ренденр в PNG/JPG под нужный носитель (сторис 1080×1350,
   пост — можно обрезать до 1080×1080).

Быстрый рендер из терминала без редактора:

```bash
# любой headless-браузер по SVG → PNG
chromium --headless --screenshot=out.png --window-size=1080,1350 frame-D-forum.svg
```

## Визуальная система (шпаргалка)

**Цвет**
- Ч/Б — режим по умолчанию.
- Один акцент на макет — **сигнальный красный `#E30613`**.
- Альтернативы (разводить дни / сцены / форматы, но не два акцента разом):
  тёмный зелёный `#1E7A46`, холодный синий `#0057B7`, жёлтый `#FFD400`.

**Типографика**
- Имя — жирный гротеск (Helvetica / Arial Bold).
- Номера и метки приборных рамок — узкий гротеск (Arial Narrow).
- Подписи, роли, координаты, техданные — моноширинный (Courier / SF Mono).

**Логотип** — пиксельная «Д» + вордмарк ДИСКРЕТ. Знак вынесен в переиспользуемый
SVG-символ `#logoD`; если появится официальный вектор — замените его во всех
рамках одним движением.

**Тег форума** — `НАУЧНО-ТЕХНИЧЕСКИЙ ФОРУМ ТВОРЧЕСКОГО ПРИБОРОСТРОЕНИЯ`.

### Допустимо
штриховка · контур · плашка · пороговое изображение · технический растр / точки ·
пиксельная декомпозиция · повторяющийся модуль · разрыв линии · реперные кресты ·
шкалы · координаты.

### Недопустимо
градиенты · мягкие полутона · glow / дымка · размытие · плавные прозрачности ·
атмосферные фоны · абстрактные волны без структуры · настроение вместо связи.

> Фото «шумит» или мягкое? Прогоните через порог (threshold) или растр — так любой
> пёстрый снимок ложится в систему. Мягкие/дымчатые кадры без контраста не берём.
