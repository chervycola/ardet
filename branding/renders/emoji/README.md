белая обводка — чтобы знаки читались и на тёмной теме. PNG 100×100 с
прозрачным фоном (формат кастом-эмодзи Telegram), рядом SVG-исходники.

## Как собрать пак

1. В Telegram открыть **@Stickers** → команда `/newemojipack`.
2. Выбрать **Static emoji**, задать название пака.
3. Отправлять PNG из этой папки **файлами** (без сжатия), после каждого —
   назначить эмодзи-замену из таблицы выше.
4. `/publish` → короткое имя, например `discret_emoji` →
   пак будет доступен по ссылке `t.me/addemoji/discret_emoji`.

## Ограничения Telegram

- Ставить кастом-эмодзи в сообщения могут только пользователи Premium.
- Канал может использовать один свой пак в постах после прокачки бустами
  (уровень зависит от текущих правил Telegram) — тогда эмодзи форума
  видны всем подписчикам в постах канала.
- Реакции кастом-эмодзи в канале тоже открываются бустами.
