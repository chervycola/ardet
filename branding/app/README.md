# ДИСКРЕТ · Telegram Mini App

Один самодостаточный файл — **`index.html`** (данные и фото вшиты, ~0.5 МБ).
Работает как Mini App внутри Telegram и как обычная веб-страница (фолбэк).

## Экраны
- **Девайсы** — карточки прибор-первым: фото, №, название прибора, автор, теги. Тап → детальная карточка.
- **Расписание** — таймлайн по времени (черновик), тап → девайс.
- **Форум** — дата/место + **хроника анонсов** (прогресс-бар: сколько постов вышло / близость к дате), манифест.
- **Меню** (кнопка ▦ в шапке):
  - **О нас** — манифест, принципы, ссылка на сайт.
  - **Обратная связь** — Telegram / почта + поле сообщения (в Telegram уходит боту через `sendData`, в браузере открывает чат).
  - **Лотерея** — розыгрыш среди купивших билет: ввод номера билета → заявка (сохраняется локально + `sendData` боту). Прототип: финальную сверку делают организаторы.
  - **Тема** — переключатель светлая ⇄ тёмная. По умолчанию светлая (стиль карточек); тёмная — приборная. При старте подхватывает тему Telegram.

## Данные (правятся вверху `<script>` в `index.html`)
- `P` — массив девайсов (название, автор, формат, роль, спек, сцена, время, теги, blurb).
  Неизвестные авторы — `— уточняется —` + тег `автор TBD`, замените.
- `EVENT` — дата/место/прогресс хроники.
- `CONTACT` — Telegram/сайт/почта (сейчас заглушки: `@diskret_space`, `diskret.space`, `hello@diskret.space`).
- `LOTTERY` — приз и дата розыгрыша.
- `PHOTOS` — превью приборов (base64). Пересобрать из `branding/photos/` скриптом ресайза.

## Как включить в Telegram
1. **Захостить `index.html` по HTTPS** (Netlify / Vercel / Cloudflare Pages — drag-and-drop одного файла; или GitHub Pages, если сделать публичным).
2. **@BotFather** → `/newbot`, затем:
   - `/setmenubutton` — кнопка меню у поля ввода с URL приложения, **или**
   - `/newapp` — Mini App со ссылкой `t.me/бот/апп` (можно кидать в канал).
3. Обратная связь и лотерея используют `WebApp.sendData` — чтобы принимать заявки,
   бот должен слушать `web_app_data` (данные приходят JSON: `{type:"feedback"|"lottery", …}`).
   Приложение при этом открывают через **кнопку клавиатуры** бота (не inline).

> SDK: `<script src="https://telegram.org/js/telegram-web-app.js">`. Вне Telegram не обязателен — фолбэк.
