# ДИСКРЕТ · Telegram Mini App

Мини-приложение для форума: смотреть участников, их приборы, расписание и хронику.
Один самодостаточный файл — `index.html` (данные и фото вшиты, ~0.5 МБ).

## Что внутри
- **Участники** — карточки: фото прибора, №, имя, прибор, теги. Тап → детальная карточка.
- **Расписание** — таймлайн по времени (сейчас черновик), тап → участник.
- **Форум** — дата/место, **хроника анонсов** (прогресс-бар: сколько постов вышло / близость к дате), манифест.
- Тема — тёмная «приборная» (ДИСКРЕТ: Ч/Б + сигнальный красный, пиксельная «Д», гротеск + моно).
- Интеграция **Telegram WebApp SDK**: `expand()`, цвет шапки, `BackButton`, хаптика, тема.
  Вне Telegram работает как обычная веб-страница (фолбэк) — можно открыть в браузере.

## Данные
Правятся в `index.html`, массив `P` (участники) и объект `EVENT` (дата/место/прогресс).
Имена/время у неизвестных авторов помечены `— уточняется —` и тегом `автор TBD` — замените.
Фото — в объекте `PHOTOS` (base64). Пересобрать превью из `branding/photos/` можно скриптом
ресайза (см. историю сборки) или вклеить свои data-URL.

## Как включить в Telegram

1. **Захостить `index.html` по HTTPS.** Варианты:
   - Netlify / Vercel / Cloudflare Pages (drag-and-drop одного файла) — проще всего.
   - GitHub Pages — если сделать репозиторий/страницу публичной.
2. **@BotFather** → создать бота (`/newbot`), затем один из способов:
   - **Кнопка меню:** `/setmenubutton` → выбрать бота → вставить URL приложения → задать текст кнопки
     (например «УЧАСТНИКИ»). Кнопка появится у поля ввода в чате с ботом.
   - **Mini App:** `/newapp` → выбрать бота → задать имя, короткое описание, иконку, URL.
     Получите ссылку вида `t.me/имя_бота/имя_аппа` — её можно кидать в канал/чат.
3. Открыть у бота — приложение развернётся на весь экран, подхватит тему и системную кнопку «назад».

> SDK подключается строкой `<script src="https://telegram.org/js/telegram-web-app.js">`.
> В обычном браузере этот скрипт не обязателен — приложение переключается в фолбэк-режим.

## Дальше можно
- Расписание по дням/сценам, фильтры и поиск по тегам.
- Автоподсчёт хроники (пост N из M → ширина заливки).
- Кнопка «поделиться участником», deep-link на конкретную карточку.
- Синхронизация данных из внешнего JSON (чтобы не править HTML).
