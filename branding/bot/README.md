# ДИСКРЕТ · Telegram-бот

Лёгкий бот на **вебхуке** (PHP). Не требует постоянного процесса — Telegram шлёт
запрос на `bot.php`, файл отвечает. Отлично живёт на шаред-хостинге (reg.ru и т.п.),
рядом с сайтом.

## Что делает
- `/start` — приветствие + кнопки: **Открыть ДИСКРЕТ**, Лента, Расписание, Девайсы, О форуме, Сайт, Канал.
- `/app`, `/posts`, `/schedule`, `/devices`, `/site`, `/contact`, `/help` — быстрые действия.
- Кнопки-вкладки открывают приложение **сразу на нужном экране** (через `?k=t_posts` и т.п.).
- QR-код со стойки (`d_archeon`, `c_efemi`, `a_polina`) — если прислать боту, даёт кнопку «открыть карточку».
- Принимает данные из приложения (обратная связь / конкурс) и пересылает вам в личку.

## Установка (10 минут)
1. **Токен.** У @BotFather возьмите токен бота (он у вас уже есть, раз приложение установлено).
2. **config.** Скопируйте `config.example.php` → `config.php`, впишите:
   - `BOT_TOKEN` — токен;
   - `APP_URL` — ссылка на приложение (та же, что в кнопке-меню), напр. `https://diskret.space/app/`;
   - `SITE_URL`, `CHANNEL_URL` — сайт и канал;
   - `ADMIN_CHAT_ID` — ваш численный id (узнать: напишите @userinfobot). Можно `0`, тогда заявки не пересылаются;
   - `SETUP_SECRET` — любая строка-пароль для настройки.
3. **Залейте** `bot.php` и `config.php` на хостинг по https, например в `https://diskret.space/bot.php`.
   > `config.php` не коммитится в git (там токен) — он есть только на сервере. См. `.gitignore`.
4. **Один раз** откройте в браузере:
   `https://diskret.space/bot.php?setup=ВАШ_SETUP_SECRET`
   Это зарегистрирует вебхук, список команд и кнопку-меню. Увидите JSON с `"ok":true` — готово.
5. Напишите боту `/start` — он ответит меню.

## Обновить/переустановить
- Поменяли ссылки в `config.php` — снова откройте `…/bot.php?setup=СЕКРЕТ`.
- Сбросить вебхук: `https://api.telegram.org/bot<ТОКЕН>/deleteWebhook`.
- Проверить статус: `https://api.telegram.org/bot<ТОКЕН>/getWebhookInfo`.

## Про обратную связь и конкурс
Данные из приложения приходят боту только когда приложение открыто через **кнопку с web_app**
(наши кнопки в `/start` — как раз такие). Бот пересылает их на `ADMIN_CHAT_ID` и отвечает
пользователю подтверждением. Если `ADMIN_CHAT_ID = 0` — просто подтверждает, никуда не пересылая.

## Требования хостинга
- PHP 7.4+ с `curl` (на reg.ru есть по умолчанию).
- HTTPS с валидным сертификатом (Telegram требует).
