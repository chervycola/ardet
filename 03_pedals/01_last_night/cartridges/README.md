# cartridges/ — картриджи Last Night

Техкарты изготовления сменных пластин для Last Night. По [Decision 11](../../00_series/decisions/11_cartridge_architecture_lock.md) картридж — пассивная пластина. В него входят материал, покрытие, рамка 110×65×30 мм, 4 магнита и ключ от неправильной установки. Разъёмов и электроники в картридже нет: эксайтер, пьезо и соленоид стоят в модуле. Формат общий с [Last Day](../../02_last_day/).

Подробный каталог (размеры по материалам, трудоёмкость, поставщики, общий workflow, инструмент, маркировка) — в [00_README.md](00_README.md).

## Статус

- Готовы техкарты v2 для **кости** (кортикальный слой бедренной кости, 100×35×2,5 мм; смена сырья пока внесена только баннером в начале техкарты) и **нефрита** (100×45×2,0 мм).
- Техкарты `01_wood`, `02_stone`, `03_metal`, `04_glass` и `06_assembly` числятся в каталоге как TODO. Файлов пока нет ни в одной ветке.
- Все `.docx` здесь старше своих `.md`: в них старые размеры (100×40×4 мм) и старое сырьё для кости (лопатка). Канон — `.md`.
