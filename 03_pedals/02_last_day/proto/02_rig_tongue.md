# Rig #2 — Tongue-резонатор testbed

**Категория**: A (экзистенциальный риск для MID-секции EQ)
**Вопрос**: даёт ли защемлённая пластинка с подвижным каподастром музыкально управляемый резонанс (диапазон, Q, повторяемость, контролируемый self-osc)?
**Если no-go**: MID-секция откатывается к обычному LC-контуру (Pultec-style, как LOW/HIGH) — модуль теряет ключевую фишку, но живёт.

## Сборка

```
   зажим-основание       каподастр (подвижный)
        ║                     ║
   ╔════╬═════════════════════╬══════════════╗
   ║    ▓▓▓━━━━━━━━━━━━━━━━━━━▓━━━━━━━━━━━━━ ║   ← пластина 70×10×0.5
   ╚════╬═════════════════════╬══════════════╝
        ▲                              ▲
   пьезо-drive                    пьезо-sense
   (у защемления,                 (у свободного конца,
    приклеен цианакрилатом)        приклеен)
```

- Drive-пьезо у защемлённого конца (максимум передачи момента).
- Sense-пьезо у свободного конца (максимум амплитуды).
- Кабель sense короткий, экранированный → OPA1642.
- Стенд на тяжёлом основании (тиски, стальная плита) — иначе меряем резонанс стола.

## Процедура

### Тест 1 — Свободный резонанс (без каподастра)
Свип 100Гц–8кГц через drive, амплитуда на sense → REW. Найти f₀ и Q полной длины (расчёт для стали 70×10×0.5: ~1.3кГц при 40мм эффективной длины; полная длина даст ниже). Записать фактическую кривую.

### Тест 2 — Закон f(L)
Каподастр на позициях эффективной длины 20 / 30 / 40 / 50 / 60 мм. Для каждой: f₀, Q. Проверить f ∝ 1/L² — построить график. **Это будущая шкала на rail.**

### Тест 3 — Q vs прижим
На фиксированной позиции (40мм) менять силу прижима каподастра: слабый (палец) / средний / жёсткий (струбцина). Q для каждого. Заявлено 20→200 — проверить реальный диапазон.

### Тест 4 — Повторяемость
Поставить каподастр на 40мм → замер f₀ → снять → поставить снова «на глаз по шкале» → замер. 10 повторов. Разброс в центах. **> ±50 центов = нужен detent/шкала лучше; > ±200 центов = manual clamp v1 под вопросом.**

### Тест 5 — Self-oscillation
Sense → gain (регулируемый, ×10–×1000) → drive. Поднимать gain до самовозбуждения:
- Контролируемо ли нарастает (или взрыв)?
- Диодный limiter (1N4148 пара anti-parallel) на sense-выходе — держит ли амплитуду playable?
- Глушится ли снижением gain без «хвоста»?

### Тест 6 — Материалы вслепую
Сталь vs латунь на одинаковой геометрии: записать одинаковую фразу через оба, слепое сравнение. **Если разница не слышна — концепт сменных пластин под вопросом** (маловероятно, но проверить честно).

### Тест 7 — Проходной сигнал (мини-интеграция)
Собрать parallel-топологию из обсуждения EQ: dry + (drive→tongue→sense→gain) → сумматор. Гитара/синт на вход. Слушать как EQ: работает ли MID BOOST музыкально, а не как «свист».

## Go / No-go

| Критерий | Go | Борьба | No-go |
|---|---|---|---|
| Диапазон f по каподастру | ≥ 3 октавы | 2–3 | < 2 октав |
| Q-управление прижимом | ≥ 5× | 2–5× | не управляется |
| Повторяемость позиции | ≤ ±50 центов | ±50–200 | > ±200 |
| Self-osc | контролируемый + limiter держит | капризный | разрушительный |
| Материалы | различимы вслепую | различимы по приборам | неразличимы |
