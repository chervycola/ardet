# tutorial/ — иллюстрированный туториал Last Day

[last_day_tutorial.html](last_day_tutorial.html) — «LAST DAY — от макета до финала». Это один HTML-документ на 11 листов: путь от настольного макета до финальной педали. В нём разобраны физика масляного диска, bench-риги и критерии go / no-go, панель управления, рецепты звука и место Last Day в системе. Это лучшая точка входа для первого знакомства с модулем: чтение занимает около 15 минут.

## Как открыть

Откройте файл в любом браузере. Он самодостаточный: CSS и SVG-схемы встроены, скриптов и внешних зависимостей нет, сеть не нужна. Светлая и тёмная тема переключаются по системной настройке.
