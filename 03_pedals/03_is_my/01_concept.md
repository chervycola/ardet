# Is My — концепт и архитектура

Модуль линейки **System Suicide** (Ardet). Слот 8, между **Last Day** (oil delay) и **Last Night** (reverb).

Это рабочий концепт-документ для дальнейших итераций по схемотехнике, прошивке, конструкции и документации. Схемотехнические решения сюда сознательно **не включены** — они прорабатываются отдельно после фиксации архитектуры.

---

## 1. Краткое описание

VCA-сатуратор-шейпер с тремя режимами работы (SHAPER / RING / GATE) на основе MOSFET-каскада из ESC FPV-дрона. Управляется выносным пилотным пультом по MIDI через TRS-кабель. Пульт несёт двухосевой джойстик, ручки, тумблеры и ножной gate-вход; имеет собственный аккумулятор и зарядку через USB-C.

Edition: 13 экземпляров с документированным провенансом (фото платы до разборки, координаты, дата находки).

## 2. Поэтика и место в системе

System Suicide — линейка из девяти модулей, реализующая поэтическую строку. Каждый модуль работает с конкретным природным или техногенным материалом: свет, кровь, кость, стекло, маятник, переключение, масло, **And My**, ночь.

Семь модулей системы построены на идее «электроника обслуживает физику»: природный материал (древесина, кость, жидкости, оптика) встроен в сигнальный путь и определяет звук. Этот модуль работает в той же логике, но материал — **силовая электроника, прошедшая боевое применение**. Принцип сохранён: материал делает то же, что делал раньше (силовое переключение), просто среда сменилась с электромеханической на звуковую.

Модуль занимает место исполнителя в строке — точку, где между прошлым (повторы делея) и его растворением (реверб) возникает физическое присутствие играющего. Все остальные модули неподвижны в стойке. Этот — единственный с физическим интерфейсом, который ведут руками. Пилотный пульт несёт эту функцию буквально: тот же тип контроллера, через который пилот управлял дроном, теперь управляет звуком.

## 3. Сигнальная архитектура

### 3.1. Сигнальный путь

```
AUDIO IN → input buffer → MOSFET shaper core → output buffer → AUDIO OUT
                              ↑
VIDEO IN → video audifier ────┘
                              ↑
              CV bus (внутренняя шина управления)
                              ↑
              MIDI input ← пульт по TRS
              CV inputs (4×, нормализованы на пульт)
```

### 3.2. Ядро: MOSFET shaper core

MOSFET-каскад работает в одном из трёх режимов, переключаемых тумблером MODE на пульте:

- **SHAPER** — VCA с управляемым насыщением. Drive раздувает уровень в нелинейность, Bias смещает рабочую точку (чётные ↔ нечётные гармоники). На высоких Drive — period-doubling chaos, естественная sub-octave.
- **RING** — ring modulator через PWM. Внутренний несущий генератор (200 Гц – 10 кГц, частота от Drive) модулируется аудиосигналом по duty cycle. На выходе боковые полосы, металлический инхармоничный тембр. На низких частотах несущей — слышимый PWM-tick (голос материала).
- **GATE** — комбинированный hard limiter + noise gate. Drive задаёт верхний порог, Bias — нижний. Перкуссивный режим: акцентирует транзиенты, режет хвосты.

Переключение режимов требует mute или crossfade ~50–100 мс для подавления щелчков.

Параметры ядра:
- **Level** (VCA gain)
- **Drive** (глубина насыщения / частота PWM / верхний порог)
- **Bias** (асимметрия искажений / параметры режима)
- **Tone** (наклон спектра после ядра)

### 3.3. Параллельный путь: video audifier

Композитный видеосигнал (PAL/NTSC) с внешнего входа подаётся через буфер в звуковой тракт как параллельный источник. Сигнал предварительно фильтруется (LPF ~15 кГц для отсечения поднесущей цвета), нормируется по уровню и подмешивается в основной путь до MOSFET-ядра.

Это даёт характерную «дроновость» звуку: glitching при потере сигнала, тембр зависит от содержимого кадра. Внешний источник — любая аналоговая камера, видеоплеер или RX-приёмник. На борту модуля камеры **нет** (отдельный картридж рассматривается в будущих итерациях).

### 3.4. CV bus и нормализация

Четыре CV-входа на лицевой панели модуля:
- DRIVE CV
- BIAS CV
- LEVEL CV
- TONE CV

Каждый — с аттенювертером. **Нормализованы на сигналы с пульта**: при отсутствии кабеля управление приходит от джойстика/ручек пульта, при вставке — внешнее CV перехватывает.

CV-выходы (passthrough от пульта на лицевую панель модуля):
- X / Y / GATE — три выхода, дублирующие соответствующие сигналы джойстика и ножника. Это позволяет управлять параметрами других модулей системы тем же физическим жестом, что и параметрами этого модуля.

## 4. Пилотный пульт

### 4.1. Концепция

Внешний контроллер, физически отдельный от модуля. Связь — один TRS-кабель, MIDI Type A. Питание — внутренний LiPo-аккумулятор, зарядка через USB-C.

USB-C дополнительно работает как USB-MIDI устройство: пульт подключается к компьютеру и используется как контроллер DAW или другого софта без участия модуля.

При снятии корпуса с реальной аппаратуры управления дроном — это становится прямым семиотическим замыканием. При использовании generic-корпуса — остаётся «просто пультом».

### 4.2. Раскладка органов управления

**Верхний ряд — статика, левая рука, тумблеры:**
- **ARM** (двухпозиционный) — глобальный gate enable модуля
- **MODE** (трёхпозиционный) — SHAPER / RING / GATE
- **LINK** (двухпозиционный) — связь осей джойстика (независимо / синхронно)

**Левая зона — ручки, левая рука:**
- **LEVEL** (поворотная)
- **TONE** (поворотная)
- LED-индикатор ARM (зелёный)
- LED-индикатор активности (амбер, реагирует на сигнал)

**Правая зона — джойстик, правая рука:**
- Двухосевой Hall-effect или резистивный джойстик
- Y-ось → DRIVE (вертикальное движение = «нагнетание»)
- X-ось → BIAS (горизонтальное = «крен»)
- Нажатие сверху → GATE trigger

**Нижняя кромка — джеки:**
- Foot switch (TS, 6.3мм или 3.5мм) — резервный gate-вход
- TRS MIDI OUT — связь с модулем
- CV OUT × 3 (3.5мм TS) — X, Y, GATE для управления другими модулями системы

**На корпусе:**
- USB-C — зарядка и USB-MIDI
- Индикатор заряда аккумулятора

### 4.3. MIDI mapping

Канал по умолчанию — 1 (переключаемый).

Управление параметрами модуля:
- **Joystick X** → CC#16 (14-bit: CC#16 MSB + CC#48 LSB)
- **Joystick Y** → CC#17 (14-bit: CC#17 MSB + CC#49 LSB)
- **LEVEL knob** → CC#7 (7-bit достаточно)
- **TONE knob** → CC#74 (7-bit)
- **ARM** → CC#64 (toggle, 0/127)
- **MODE** → CC#80 (0 / 64 / 127)
- **LINK** → CC#81 (0/127)
- **Joystick press** → Note On/Off, нота C2
- **Foot switch** → Note On/Off, нота C#2

14-bit для основных осей джойстика обязательно: 7-bit (128 шагов) даёт слышимую ступенчатость на drive и фильтре.

### 4.4. Питание и автономность

- Аккумулятор LiPo, ёмкость подбирается из расчёта ≥8 часов работы
- Зарядка USB-C (PD не требуется, базовый 5V/2A)
- Индикатор заряда (4 LED или OLED-полоска)
- Автоотключение при простое >30 мин

## 5. Форм-фактор

### 5.1. Модуль в стойке

- Eurorack 3U
- Ширина: ~10HP (точно определяется после раскладки лицевой панели)
- Глубина: стандартная
- Питание: ±12V из шины Eurorack

### 5.2. Пульт

- Standalone, в собственном корпусе
- Ориентировочно ~180×100×40мм (уточняется по выбору джойстика)
- Корпус — открытый вопрос: аппаратура управления дроном (если найдётся доступный донор) или generic-корпус с фрезеровкой

### 5.3. Кабель пульт ↔ модуль

- TRS 3.5мм, MIDI Type A
- Один провод — для совместимости с любым стандартным MIDI-окружением
- Длина — 1.5–2 метра (для перформативной свободы)

## 6. Edition

### 6.1. Объём

13 экземпляров. Каждый пронумерован. Выпуск ограниченный.

### 6.2. Провенанс

Каждый модуль имеет документированное происхождение силовой электроники:
- Фотография платы ESC до разборки
- Координаты (или регион) находки
- Дата
- Тип/модель платы (если идентифицируется)

Документация выпускается как отдельный артефакт — provenance certificate, идущий в комплекте с модулем.

### 6.3. Уникальность экземпляров

В силу разброса параметров MOSFET'ов разных ESC, теплового износа и общего состояния плат, **каждый экземпляр звучит чуть иначе**. Это не баг, а свойство edition. Документация не обещает идентичности между экземплярами; обещает работоспособность в спецификации.

## 7. Совместимость с системой

Модуль интегрируется с другими модулями System Suicide через:

- **Аудиосигнал** — стандартный модулярный уровень, любые подключения
- **CV outs от пульта** — управление параметрами Be Careful (cutoff), Last Day (time), Last Night (decay/freeze) тем же жестом джойстика
- **CV ins на лицевой панели** — управление параметрами модуля от LFO Fuck Abandoned Sleep, переключений Is My, и других источников

Пульт также может работать как универсальный перформативный контроллер для всей линейки — через CV outs от пульта на любые другие модули системы.

## 8. Сценарии использования

### 8.1. Студия

Модуль в стойке, пульт на столе. Рука постоянно на джойстике. CV outs пульта расходятся по системе как физический миксер модуляции. Запись автоматизации в DAW идёт по USB-MIDI с пульта без отдельного контроллера.

### 8.2. Лайв

Пульт в руках или на ремне. Стойка работает фоновой архитектурой. Ножник под левой ногой держит ARM. Жест физически входит в перформанс — звук появляется только при взаимодействии с пультом.

### 8.3. Гибридные конфигурации

Пульт может управлять любым другим модулем линейки через CV outs, не только этим. Этот модуль может работать без пульта (управление с лицевой панели и внешних CV) — но тогда теряется основной перформативный слой.

## 9. Открытые вопросы для следующих итераций

- Конкретная схемотехника MOSFET-каскада с компенсацией теплового дрейфа
- Топология переключения режимов без щелчков (mute или crossfade)
- Выбор контроллера для прошивки пульта (STM32 / RP2040 / иной)
- Выбор корпуса пульта — донор или generic
- Раскладка лицевой панели модуля в стойке (точное расположение джеков)
- Дизайн provenance certificate
- Выбор поставщика плат ESC для серии (с документируемым провенансом)
- Регуляторные вопросы при экспорте edition (таможенная декларация, описание как art object)

## 10. Принципы, которые держим при разработке

- **Функциональная преемственность важнее семиотики.** Материал должен работать в той же функции, в какой работал раньше. ESC был силовым переключателем — остаётся силовым переключателем.
- **Edition не объясняет себя в маркетинге.** Документация честная, но ненавязчивая. Объект говорит сам.
- **Качество звука первично.** Если модуль не работает как инструмент — никакая концепция этого не вытащит.
- **Совместимость с системой.** Модуль — часть линейки, не отдельный объект. Архитектура должна работать в общем потоке.
