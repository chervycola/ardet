# 03 — Оптический канал: камера, освещение, геометрия

Канал обслуживает и полупрозрачные, и непрозрачные образцы (D3a) тремя
режимами освещения: **TRANS** (просвет, §1–§2), **REFLECT-D** и
**REFLECT-4** (отражение, §3а). Камера и геометрия общие.

## 1. Схема просвета TRANS (contact imaging через объектив)

```
   ┌──────────────────────┐
   │  LED-панель 12 В      │  ← постоянный ток или ШИМ ≥ 20 кГц
   ├──────────────────────┤
   │  диффузор (молочный   │
   │  акрил 3 мм, зазор 5мм)│
   ├──────────────────────┤
   │  ПЛАСТИНА (образец)    │  ← слот с регистрацией (04)
   ├─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─┤
   │  воздушный зазор       │   рабочая дистанция ~30–50 мм
   │  (тубус, мат. чёрный)  │
   ├──────────────────────┤
   │  КАМЕРА OV7670 (M12)   │  ← фокус подстройкой резьбы объектива
   └──────────────────────┘
```

Строго «лензлесс»-контакт не используем: на дистанции контакта без объектива
изображение размывается. Штатный M12-объектив камеры фокусируется на
30–50 мм подкруткой резьбы; поле 25×25 мм заполняет большую часть кадра.
Нам нужно всего 32×32 — требования к резкости и дисторсии низкие.

## 2. Камера

- **OV7670 без FIFO** (DCMI на STM32 читает сам) или **OV2640** (JPEG не
  используем, только raw YUV). Берём Y-канал как grayscale.
- Режим QVGA 320×240. ROI 25 мм ≈ 200×200 px кадра → блок 6×6 px на один
  пиксель карты 32×32: усреднение 36 сэмплов на пиксель — хороший запас SNR.
- **Все авторежимы камеры выключить**: AEC, AGC, AWB — фиксированные
  экспозиция/усиление, задаются при юстировке и хранятся в конфиге.
  Это часть требования детерминизма и абсолютной шкалы (D6, D7).

## 3. Подсветка

- Белая LED-панель за диффузором; питание от стабильного источника тока.
  Если ШИМ-диммирование — частота ≥ 20 кГц (иначе полосы от rolling shutter).
- Равномерность «сырой» подсветки не критична: flat-field её вычитает.
  Критична **стабильность во времени** → токовый драйвер, прогрев 2–3 мин
  до калибровки, контроль: пиксель-«свидетель» вне окна образца (участок
  карты, где всегда пустое стекло рамки) — по нему детектируется дрейф
  яркости и температуры без вмешательства в шкалу.
- Тубус между пластиной и камерой изнутри матово-чёрный; стенд закрыт от
  комнатного света (фанерный/печатный кожух).

## 3а. Режимы отражённого света (непрозрачные образцы, D3a)

Фронтальное освещение размещается вокруг объектива, со стороны камеры:

```
        ПЛАСТИНА (непрозрачный образец лицом к камере)
   ─────┬───────────────────────┬─────
        │      тубус            │
   N ►──┤                       ├──◄ S     4 группы «скользящих» LED
        │    W ►─┐       ┌─◄ E  │          под углом 10–20° к плоскости
        │        │       │      │          + диффузное кольцо у объектива
        │      ┌─┴───────┴─┐    │
        │      │  КАМЕРА    │   │
        └──────┴───────────┴────┘
```

**REFLECT-D — карта альбедо.** Все 4 группы + кольцо одновременно, свет
максимально ровный. Карта = отражательная способность поверхности.
Подходит для образцов с контрастом цвета/плотности, без выраженного рельефа.

**REFLECT-4 — карта рельефа.** Ключевой режим для пемзы/камня/наростов.
4 кадра подряд, в каждом горит одна группа (N, E, S, W): косой свет
рисует тени пропорционально рельефу. Свод в один кадр:

    relief[i] = ( max4(i) − min4(i) )  →  нормировка фикс-константой

Разность max−min по четырём направлениям выделяет именно рельеф (тени),
подавляет альбедо и — главное — **нейтральна к направлению света**: иначе
однобокие тени ломали бы метрику поворотной симметрии R. Дополнительно
доступна albedo-оценка avg4 (среднее 4 кадров) — прошивка хранит обе,
маппинг может брать любую (параметр пресета).

Детерминизм: порядок N→E→S→W фиксирован, токи групп калибруются один раз
(эталон — матовая серая пластина GREY, 04 §6). 4 кадра при 10 fps = 0.4 с на
полный своп карты — для статичного образца несущественно.

**Выбор режима** — свойство пластины: бит в ID пластины (04 §5) или
команда CLI `mode trans|refd|ref4`. Смена режима = смена активного набора
калибровок.

## 4. Калибровка (процедура)

Отдельный набор калибровок **на каждый режим освещения** (TRANS,
REFLECT-D, и по одному на каждую группу REFLECT-4):

1. Тёмный кадр: всё освещение выкл → dark[i] (усреднить 16 кадров).
2. Опорный кадр: TRANS — пластина BLANK (два чистых стекла);
   REFLECT-* — пластина GREY (04 §6) → white[i] (усреднить 16 кадров).
3. gain[i] = K / (white[i] − dark[i]), K — фиксированная константа шкалы.
4. Сохранить dark/gain/экспозицию во flash (по режимам). Рабочий кадр:
   map[i] = clamp((raw[i] − dark[i]) · gain[i]).
5. Перекалибровка — только по команде пользователя, никогда автоматически.

## 5. Опция: скрещенные поляризаторы (для кристаллов)

Два листа плёночного поляризатора: один между диффузором и пластиной,
второй между пластиной и камерой, скрещены на 90°. Пустое поле — чёрное;
двулучепреломляющие кристаллы (медный купорос, сахароза, сегнетова соль)
вспыхивают на чёрном фоне — контраст структуры вырастает радикально.
NaCl кубический, эффекта не даёт. Механика: второй поляризатор на
поворотном кольце → угол скрещивания становится ещё одним художественным
параметром. В BOM заложено, в бринг-апе — эксперимент E3 (08).

## 6. Юстировка ROI

Печатная мира (шахматка 25×25 мм на плёнке) вставляется как пластина;
по USB-просмотрщику выставляются границы ROI и фокус; ROI сохраняется.
Повторяется только при механическом вмешательстве в тракт.

## 7. Известные риски канала

| Риск | Смягчение |
|---|---|
| Дрейф яркости LED со временем/температурой | токовый драйвер, пиксель-свидетель, прогрев |
| Rolling shutter × ШИМ | постоянный ток или ШИМ ≥ 20 кГц |
| Виньетирование/дисторсия объектива | съедается flat-field и низким разрешением 32×32 |
| Комнатная засветка | кожух; контроль: тёмный кадр при вставленной пластине |
| Толстые образцы вне глубины резкости | принять мягкость как эстетику; предел толщины в 04 |
