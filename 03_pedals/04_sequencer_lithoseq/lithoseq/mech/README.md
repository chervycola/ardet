# mech — механика стенда

`plate.scad` — параметрическая модель рамки пластины и слота (04-PLATE-SPEC).
Все размеры — в шапке файла, единый источник правды.

Рендер STL (OpenSCAD локально; в CI-окружении его нет):

```
openscad -o plate_frame.stl -D 'part="frame"' plate.scad
openscad -o slot_base.stl   -D 'part="slot"'  plate.scad
```

Заметки к печати и сборке:
- Рамка: PETG/SLA, окно и карман стёкол — проверить посадку полустекла
  26×38×1 мм с допуском +0.5, при необходимости подстроить `glass_*`.
- Регистрация: печатные штифты в слоте — для первых проб; для ресурса
  заменить на стальные штифты 2 мм (в модели — параметр `pin_d`,
  отверстия под запрессовку вместо печатных цилиндров).
- Повторяемость вставки проверяется тестом T1.5 (10 циклов, |Δ| ≤ 2 LSB
  средний) — до этого теста механику не считать готовой.
- ID-код рамки задаётся параметром: `-D 'part="frame"' -D id_code=5`.
- Кожух тубуса и держатель камеры/подсветки — после выбора конкретных
  модулей (фаза 1-железо), когда известны габариты.
