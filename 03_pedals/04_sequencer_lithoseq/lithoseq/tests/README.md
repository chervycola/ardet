# tests — тесты ядра и MIDI-слоя

Запуск из папки [`lithoseq/`](../README.md): `make test`. Ожидаемый вывод —
`all tests passed` и `all midi tests passed`. Тесты опираются на
синтетические кадры из [`../app/patterns.c`](../app/patterns.c), поэтому
полностью детерминированы.

| Файл | Что проверяет |
|---|---|
| [`test_core.c`](test_core.c) | Метрология метрик по мотивам T-M1 (08-TEST-PLAN): D растёт с плотностью точек, S на шахматке намного выше, чем на пустом кадре, R высокий у колец и низкий у случайных точек, R не меняется при повороте карты на 90° (допуск 0.05, по образцу T1.4b). Траектории: каждый цикл обходит каждую клетку ровно один раз. Квантайзер: ноты в диапазоне и в шкале. На пустом кадре нет ни одного gate. Пресеты Reveal и Compose дают разные потоки, каждый детерминирован. Эквализация питча D11. Полный тракт дважды даёт идентичный результат (D7) |
| [`test_midi.c`](test_midi.c) | MIDI-поток валиден, note on/off парные; поток детерминирован; структура SMF корректна |

Статус: проходят с gcc 13.3 и clang 18 (проверено при сборке репо в копии
папки, в том числе с `-fsanitize=address,undefined`).

Происхождение: `origin/claude/eurorack-sequencer-design-3wu8wb`, снапшот `72671ad` (2026-07-18), код последний раз менялся в `c256be3` (2026-07-07). Файлы перенесены байт-в-байт; этот README добавлен при сборке репо.
