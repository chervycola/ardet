# hal — интерфейс железа

[`hal.h`](hal.h) — граница между приложением и железом стенда: группы
света (TRANS, кольцо, четыре косые группы N/E/S/W), режимы съёмки TRANS /
REFLECT-D / REFLECT-4 (D3a), блокирующий захват QVGA-кадра, `hal_scan`
(для REFLECT-4 сам снимает четыре кадра и сводит max−min), выходы USB-MIDI
и хранение конфига во flash. Ядро [`../core/`](../core/README.md) эти
функции не вызывает, их вызывает только приложение.

| Файл | Что это |
|---|---|
| [`hal.h`](hal.h) | Объявления HAL. Реализаций здесь нет |

Где реализации:

- STM32 (Nucleo-H743ZI2 + OV7670) — [`../fw-stm32/hal_impl.c`](../fw-stm32/hal_impl.c).
  Комментарий в `hal.h` ещё называет путь `hal/stm32/`: так планировалось
  до появления `fw-stm32/`, код оставлен без правок.
- ПК-симулятор [`../app/`](../app/README.md) HAL не использует: кадр
  подставляется из синтетики или PGM.

Статус: интерфейс стабилен на уровне скелета, реализация для STM32 на
железе не проверялась (бринг-ап T1.1–T1.5 впереди).
