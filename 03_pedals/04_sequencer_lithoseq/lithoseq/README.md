# LITHOSEQ — прошивка и инструменты

Генеративный секвенсор: физический образец → карта 32×32 → метрики →
CV/MIDI-паттерн. Документация: [`../docs/`](../docs/README.md); обзор
папки педали — [`../README.md`](../README.md).

## Структура

```
core/    ядро (чистый C, без HAL, фикс-пойнт, без RNG) — компилируется на ПК
hal/     интерфейс железа (hal.h); реализация для STM32 — fw-stm32/hal_impl.c
app/     ПК-симулятор: синтетические кадры → ядро → CSV + бинарный протокол;
         MIDI-слой и экспорт Standard MIDI File (--mid)
fw-stm32/ скелет прошивки стенда (Nucleo-H743ZI2 + OV7670), см. fw-stm32/README.md
mech/    OpenSCAD-модель рамки пластины и слота, см. mech/README.md
tools/   viewer.py (просмотр карты/событий), genpatterns.py (PGM-паттерны)
tests/   тесты ядра: метрология метрик (T-M1), детерминизм, покрытие траекторий;
         тесты MIDI-слоя и структуры SMF
```

## Сборка и запуск (ПК)

```
make test                      # собрать и прогнать тесты ядра и MIDI-слоя
make sim                       # собрать симулятор
./build/lithoseq_sim rings --traj spiral_in --preset reveal \
    --ticks 512 --csv out.csv --bin out.bin --mid out.mid
python3 tools/viewer.py out.bin --out out.png   # картинка: карта+плейхед+ноты
```

Паттерны симулятора: `blank`, `checker`, `rings`, `dots5`, `dots15`,
`dots40`, либо путь к PGM (P5, 320×240) — например, из `tools/genpatterns.py`
или, позже, дамп реальной камеры.

## Правила ядра (см. 05-FIRMWARE-SPEC)

- core не знает про железо: вход — кадр/карта и тики, выход — события.
- только целочисленная арифметика; никакого RNG и времени.
- та же карта + те же настройки → побайтово тот же поток событий.
