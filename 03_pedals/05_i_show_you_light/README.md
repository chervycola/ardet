# I Show You Light (ISYL) — модуль 1 серии SYSTEM SUICIDE

R&D-папка модуля. I Show You Light — оптический tonewheel-осциллятор с кварцованным строем. Лазерные лучи проходят через вращающийся диск с прорезями и зеркало на мембране и попадают на фотодиоды. Звук получается прямо из света: без DSP, без wavetable. Цифровая электроника есть только в сервопетле мотора (строй, 1V/oct, глайд), в аудиотракт она не заходит.

Модуль стоит первым в цепи серии и служит источником света для оптической шины ([Decision 15](../00_series/decisions/15_optical_bus_hybrid.md)).

## Как собрать прошивку

Скетч рассчитан на Raspberry Pi Pico (RP2040) с ядром Earle Philhower (arduino-pico).

1. Arduino IDE: добавить в Boards Manager ядро `Raspberry Pi Pico/RP2040` (Earle Philhower), плата — Raspberry Pi Pico. Через `arduino-cli` FQBN — `rp2040:rp2040:rpipico`.
2. Library Manager: `Simple FOC` (>= 2.3.x) и `Adafruit ADS1X15`.
3. Arduino требует, чтобы скетч лежал в папке с тем же именем. Скопируйте `firmware/i_show_you_light_servo.ino` в отдельную папку `i_show_you_light_servo/` (IDE при открытии предложит сделать это сама).
4. Режим стенда задаётся `#define USE_POT_CV`: `true` — питч от потенциометра на GP26, `false` — настоящий вход 1V/oct через ADS1115.
5. Монитор порта — 115200 бод. PID тюнится командами Commander (`M…`).

Распиновка — `ISYL_PROJECT.md` §3.2 и шапка скетча. Порядок оживления (энкодер → открытая петля → `initFOC` → тюнинг PID → проверка лока по диапазону) — §3.4. Перед поднятием `VOLTAGE_LIMIT` и `RPM_MAX` прочитайте `REVIEW_v1.1_numbers.md` §3 и §5.

Лазер 650 нм ≤ 5 мВт — класс 3R. Юстировать в защитных очках, в луч через оптику не смотреть (`ISYL_PROJECT.md` §6.11, Decision 15, раздел «Безопасность»).
