# 04 — Пластина образца: механика и регистрация

## 1. Концепция

Пластина — «пластинка»: носитель, который вставляется, играет одно и то же,
вынимается, подписывается, коллекционируется. Отсюда два жёстких требования:
повторяемость установки (D9) и живучесть образца при хранении.

## 2. Конструкция сэндвича

```
  рамка (печать SLA/PETG или фанера лазером), внешний габарит 40×50 мм
  ┌────────────────────────────┐
  │  ручка-язычок    метка ▲    │ ← направление вставки, зона подписи
  │  ┌──────────────────────┐  │
  │  │ стекло 26×38×1 мм     │  │ ← половина предметного стекла 26×76
  │  │   [образец]           │  │
  │  │ стекло 26×38×1 мм     │  │ ← покровное, опционально (сыпучие/хрупкие)
  │  └──────────────────────┘  │
  │  окно 25×25 мм              │
  └────────────────────────────┘
```

- Стёкла — стандартные предметные микроскопные 26×76×1 мм, разрезанные
  пополам: дёшево, оптически пригодно, 26 мм ≈ наше окно 25 мм.
- Образец выращивается/закрепляется прямо на стекле (соль и купорос растут
  на стекле сами; пористые — клеятся УФ-клеем по краю).
- Второе стекло сверху — по необходимости; рамка допускает толщину
  образца **до 4 мм** (глубина резкости и слот, 03 §7).

## 3. Регистрация (кинематика)

Три точки в слоте стенда: два штифта Ø2 мм в паз+отверстие на рамке
(классическая пара «отверстие + овальный паз») + плоскость упора по Z
подпружиненным прижимом. Поворотная и линейная повторяемость < 0.2 мм —
четверть пикселя карты. Вставка возможна единственной ориентацией
(асимметричный скос угла рамки).

## 4. Dual-ready (задел под ёмкостный канал, D2)

По двум противоположным кромкам рамки — свободная зона 4 мм под будущие
контактные площадки (гребёнка электродов на плёнке/PCB, ложащаяся под
образец). В v1 зона пустует, но габарит слота и рамки её уже учитывает,
чтобы пластины v1 остались совместимы с модулем фазы 5.

## 5. Идентификация пластины (опция, дёшево)

По нижней кромке рамки внутри поля зрения камеры — до 4 отверстий/меток:
4-битный ID, читается теми же пикселями кадра вне окна образца. Прошивка
может привязывать к ID сохранённые настройки (пресет, траекторию) —
«пластинка со своей программой». Реализация — фаза 2+, в рамку закладываем
сразу.

## 6. Эталонные пластины

- **BLANK** — два чистых стекла: flat-field (03 §4).
- **MIRA** — печатная шахматка на плёнке: юстировка ROI и фокуса.
- **PATTERN-SET** — плёнки: радиальная мира, концентрические кольца,
  случайные точки 3 плотностей: метрологическая проверка метрик (08).
Хранятся в чехле, считаются частью стенда, не арт-корпуса.

## 7. Хранение и подпись

Зона подписи на язычке (номер, материал, дата выращивания). Коробка-слоттер
на 12 пластин. Гигроскопичные образцы (соль!) — с покровным стеклом и
герметизацией кромки, иначе структура «поплывёт» от влажности — вместе
с паттерном. Если «плывущий» образец станет художественным приёмом —
это режим «живого» образца (F3), но по умолчанию образцы консервируются.
