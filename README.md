# SS — SYSTEM SUICIDE

Серия модулей физического синтеза **SYSTEM SUICIDE** и её спутники: маркетинг-сайт и генеративный секвенсор.

## Карта ветки

| Директория | Что | Живая ветка разработки |
|------------|-----|------------------------|
| **`synth/`** | 9-модульная серия: канон-бриф, спеки Last Night/Last Day, decisions 00–13, аудит, прототипирование, sourcing | эта ветка (canonical) |
| **`synth/is_my/`** | Модуль Is My: MOSFET-shaper + пилотный пульт DJI C5 — концепт, схемотехника, прошивки, панели | `claude/jolly-gates-KxAP2` |
| **`site/`** | Маркетинг-сайт system-suicide (Vite + React + TS, bilingual) | `System-suicide` |
| **`sequencer/`** | Генеративный Eurorack-секвенсор (сканирование физического образца → CV/gate). Отдельный проект, не входит в 9-модульную серию | `claude/eurorack-sequencer-design-3wu8wb` |

## Быстрый старт

**Synth-доки**: `synth/README.md` (карта документации) → `synth/SYSTEM_SUICIDE.md` (канон-бриф серии). Иллюстрированный гид: `synth/docs/` (PDF/DOCX через pandoc — `./build.sh`).

**Сайт**: `cd site && npm install && npm run dev`. Известные расхождения данных с каноном — `site/PROVENANCE.md`.

**Секвенсор**: `sequencer/DESIGN-OPINION.md` → `00-ROADMAP.md`.

## Синхронизация

Директории с «живой веткой» — снапшоты: активная разработка продолжается там, сюда периодически подтягивается состояние. Прежде чем редактировать `site/`, `synth/is_my/`, `sequencer/` здесь — проверь, не уехала ли живая ветка вперёд.

Соседние проекты монорепо — на ветках **Ardet** (игра) и **Баклажания** (legal).
