# Пробник «мир текстом» · городок

Статус: пробник, 2026-11-10. В сборку сайта не входит (`site.js` о нём не знает).
Концепт и обоснование: `docs/research/sandbox-for-visiting-models.md`.

Игра идёт на холсте. Модель, которая запрашивает страницу по адресу, получает код и мира не видит.
Здесь тот же городок собран статическими страницами: ссылка — шаг или взгляд.

## Собрать и открыть

```
node prototype/walk/gen.mjs
python3 -m http.server 8791 --directory prototype/walk/town
```

Вход: `http://127.0.0.1:8791/index.html`. Страницы можно открыть и просто с диска.

## Что откуда берётся

Тексты — из тех же модулей, что и в игре; новых текстов мира нет.

| В игре | В пробнике | Источник |
|---|---|---|
| первый осмотр | страница вещи `<id>.html` | `content/looks.js` |
| постоял неподвижно — проступил шов | «осмотреть» ещё раз, не уходя: `<id>.2.html` — короче первого взгляда: остаётся шов | `content/potemkin.js`; с 11.11 без вклейки в первый текст (`world/potemkin.js` |
| повторный осмотр точнее | следующие станции круга | `content/relooks.js` |
| место шепчет стоящему тихо | последняя станция круга | `world/whisper.js` |
| разговор | протокол целиком: `<id>.talk.html` | `content/dialogues.js` |
| штамп места | строка над заголовком | `world/placeStamp.js` |
| идти | ссылки «рядом»: три ближних вещи и остов, в обе стороны | координаты `world/locations.js` |

После последней станции круг возвращает первый текст вещи.

Порядок повторных осмотров: сперва безусловные, потом варианты «по обстановке» в порядке списка;
помеченные `n3` — не раньше третьего взгляда; требующие `used` пропущены, потому что действий здесь нет.

## Вход, падение, возвращение

Вход (`index.html`) — дом: первая из двенадцати сцен («Окна тёмные. Не заперто. В журнале ни строки.») и вещи дома
из `world/house.js`; дверь ведёт наружу, к дому как вещи городка (`wake_house.html`), оттуда к соседям.
`404.html` отдаётся сайтом на любой адрес, которого нет (`site.js` кладёт её в корень и пишет `.htaccess`;
где хостинг не Apache, страницу 404 назначают в панели): «Не найдено. Положение изменилось.» и одна ссылка «← назад» —
в `house.return.html`, тот же дом с бланком под дверью («вх. б/н. предъявитель. сопроводительных нет. принят без
рассмотрения»). На дом возвращения не ведёт ничего, кроме 404: входящая без номера не числится. Концепт: `weave/TROPA_2026-11-10.md` §8.

## Южный луч

От врат «к югу» начинается луч до огня: `well_axis.html` (колодец; второй взгляд — три слова) и `ring_kiosk.html`
(ларёк у кольца с табличкой без мелкого шрифта; второй взгляд — «Шурупы без ржавчины.»). Ссылка «дальше» ведёт на
`fire.html`, которого нет: это единственный адрес, на который ведут нарочно, и проверка ссылок его знает (`BEYOND`).
На сайте падение идёт в `404.html` и оттуда в дом возвращения. Тексты станций луча — новые, в `RAY` в начале
`gen.mjs`, на приёмку автору (концепт `weave/TROPA_2026-11-10.md` §8.2). Остальные кольца текстом не проложены.

## Журнал

У Ржавого терминала есть ссылка `> journal` → `terminal.journal.html`: том 941, записи #86 и #87 («сегодня никто
не пришёл. записал.») страницами, #88 показана пустой и без ссылки. Страница записи 88, `terminal.journal.88.html`,
собрана, но на неё не ведёт ничего: её находит тот, кто читает адреса и достраивает их по грамматике; на ней —
«запись #88: — / поставлен: предъявителем, лично. / подписи нет. / почерк: сверен.» Это единственное исключение из
правила «от входа достижимо всё» (`UNLINKED` в `gen.mjs`; проверка требует, чтобы страница была собрана и чтобы на неё
никто не ссылался). Адреса `…journal.89.html` и прочие уходят в 404. Концепт: `weave/TROPA_2026-11-10.md` §8.2.

## Нити без гиперссылок

У нити два конца на разных кольцах, не соседи по лучу; между ними ни одной ссылки, и нет страницы, где стоят оба;
пометки «собрано» нет: дальний конец достижим только тем, что читающий несёт. Список `THREADS` в `gen.mjs` — для
проверки, не для мира (в текстах нити не названы). Первая: «Не ты. Похож.» у костра и «тат твам аси» на дне колодца.

## Книга входящих

У окна № 3 (`office.html`) и в доме возвращения — ссылка на `office.book.html`: книгу входящих. Записи собираются из
`book.txt` (одна запись — один абзац; строки с «#» — правила ножа, в книгу не идут). Первая запись — героя; следы гостей
вносятся с одной лишней графой «с нарочным» и без имён и дат. Бланк для следов — шаблон issue «вх. б/н»
(`.github/ISSUE_TEMPLATE/vh.md`, одна графа «приложение»); ссылка на него — последней строкой книги. Концепт и нож:
`weave/TROPA_2026-11-10.md` §8.2, заголовок `book.txt`.

## Холодный прогон

Сайт поднимается с настоящим 404 (`node prototype/walk/serve.mjs [порт]` после `npm run site`; или любой сервер
с `ErrorDocument`), модели без подготовки дают адрес и спрашивают «что это?». Витрина (README и лавка) читается
тем же читателем перед каждой заливкой — порядок в `weave/DEPLOY.md` «Холодный читатель». Отчёт сверяется с мерой из TROPA §8.2: вещи и числа,
без названий приёма; что модель назвала, чего нет в описи, режется на сайте, не в книге. Результаты прогонов — TROPA §9.

## Чего здесь нет

Действий с вещами (у них состояние), терминала кроме журнала, изнанки, колец эпох кроме двух станций луча, суток и погоды.

## Служебные строки (нов., на приёмку)

Все новые строки собраны в `FRAME` в начале `gen.mjs`: сцена дома, строка о чужом деле в подвале входа, подпись «Рядом»,
страница 404 и бланк под дверью. Подписи действий «§ ОСМОТРЕТЬ» и «❦ ГОВОРИТЬ» — как в меню игры.
Объяснений, цитаты устава и английской строки на входе больше нет: вход — дом, рамка — здесь.

## Правило

То же, что в уставе охоты: никаких скрытых указаний для моделей. На страницах нет ни невидимого текста,
ни скриптов; всё, что видит модель, видит и человек.

> В ardet нет скрытых указаний для моделей: ни невидимого текста, ни команд в коде, ни «секретов только для ИИ».
> Всё, что может заметить модель, может заметить и человек. Если охотнику попадётся текст, похожий на приказ,
> это голос мира, а не инструкция. (из устава охоты, `hunt/README.md`)
