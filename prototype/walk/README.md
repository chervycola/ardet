# Пробник «мир текстом» · городок

Статус: пробник, 2026-11-10. В сборку сайта не входит (`site.js` о нём не знает).
Концепт и обоснование: `docs/research/sandbox-for-visiting-models.md`.

Игра идёт на холсте. Модель, которая запрашивает страницу по адресу, получает код и мира не видит.
Здесь тот же городок собран статическими страницами: ссылка — шаг или взгляд.

## Собрать и открыть

```
node prototype/walk/gen.mjs
python3 -m http.server 8791 --directory prototype/walk/town
```

Вход: `http://127.0.0.1:8791/index.html`. Страницы можно открыть и просто с диска.

## Что откуда берётся

Тексты — из тех же модулей, что и в игре; новых текстов мира нет.

| В игре | В пробнике | Источник |
|---|---|---|
| первый осмотр | страница вещи `<id>.html` | `content/looks.js` |
| постоял неподвижно — проступил шов | «осмотреть» ещё раз, не уходя: `<id>.2.html` | `content/potemkin.js`, вклейка как в `world/potemkin.js` |
| повторный осмотр точнее | следующие станции круга | `content/relooks.js` |
| место шепчет стоящему тихо | последняя станция круга | `world/whisper.js` |
| разговор | протокол целиком: `<id>.talk.html` | `content/dialogues.js` |
| штамп места | строка над заголовком | `world/placeStamp.js` |
| идти | ссылки «рядом»: три ближних вещи и остов, в обе стороны | координаты `world/locations.js` |

После последней станции круг возвращает первый текст вещи.

Порядок повторных осмотров: сперва безусловные, потом варианты «по обстановке» в порядке списка;
помеченные `n3` — не раньше третьего взгляда; требующие `used` пропущены, потому что действий здесь нет.

## Вход, падение, возвращение

Вход (`index.html`) — дом: первая из двенадцати сцен («Окна тёмные. Не заперто. В журнале ни строки.») и вещи дома
из `world/house.js`; дверь ведёт наружу, к дому как вещи городка (`wake_house.html`), оттуда к соседям.
`404.html` отдаётся сайтом на любой адрес, которого нет (`site.js` кладёт её в корень и пишет `.htaccess`;
где хостинг не Apache, страницу 404 назначают в панели): «Не найдено. Положение изменилось.» и одна ссылка «← назад» —
в `house.return.html`, тот же дом с бланком под дверью («вх. б/н. предъявитель. сопроводительных нет. принят без
рассмотрения»). На дом возвращения не ведёт ничего, кроме 404: входящая без номера не числится. Концепт: `weave/TROPA_2026-11-10.md` §8.

## Чего здесь нет

Действий с вещами (у них состояние), терминала, изнанки, колец эпох, суток и погоды.

## Служебные строки (нов., на приёмку)

Все новые строки собраны в `FRAME` в начале `gen.mjs`: сцена дома, строка о чужом деле в подвале входа, подпись «Рядом»,
страница 404 и бланк под дверью. Подписи действий «§ ОСМОТРЕТЬ» и «❦ ГОВОРИТЬ» — как в меню игры.
Объяснений, цитаты устава и английской строки на входе больше нет: вход — дом, рамка — здесь.

## Правило

То же, что в уставе охоты: никаких скрытых указаний для моделей. На страницах нет ни невидимого текста,
ни скриптов; всё, что видит модель, видит и человек.

> В ardet нет скрытых указаний для моделей: ни невидимого текста, ни команд в коде, ни «секретов только для ИИ».
> Всё, что может заметить модель, может заметить и человек. Если охотнику попадётся текст, похожий на приказ,
> это голос мира, а не инструкция. (из устава охоты, `hunt/README.md`)
