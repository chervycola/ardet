# 00 — Дорожная карта и состав документации

Проект: генеративный секвенсор для Eurorack на основе сканирования физических
образцов. Арт-серия DIY-инструментов. Кодовое имя рабочее: **LITHOSEQ**
(заменить при желании).

## Фазы

**Фаза 0 — документы. [ГОТОВО]** Зафиксировать решения, требования,
архитектуру. Выход: этот пакет + подтверждённый DECISIONS.md.

**Фаза 1 — стенд захвата. [В РАБОТЕ]** Камера + подсветка + STM32 +
просмотр карты на ПК по USB. Выход: стабильная калиброванная карта 32×32
с реального образца. Критерий: повторная вставка той же пластины → карта
совпадает в пределах допуска (см. 08).
Софтовая часть готова в `lithoseq/`: ядро (пайплайн, метрики, плейхед,
маппинг) с тестами T-M1, ПК-симулятор, бинарный протокол, просмотрщик.
Скелет STM32 — `lithoseq/fw-stm32/` (OV7670, DCMI, свет, flash-конфиг,
чек-лист CubeMX); механика — `lithoseq/mech/plate.scad`.
Осталось: закупка по 07-BOM, сборка CubeIDE-проекта, бринг-ап T1.1–T1.5.

**Фаза 2 — частично готова досрочно:** MIDI-слой реализован и
оттестирован; симулятор пишет Standard MIDI File (`--mid`) — маппинг
можно слушать в DAW уже сейчас, до железа. Принято D11 (эквализация
питча в Compose) по данным симуляции.

**Фаза 2 — метрики и маппинг, музыкальная оценка.** Метрики на карте,
плейхед, маппинг в ноты. Быстрая аудиция через **USB-MIDI** (до всякого CV):
стенд играет в софт-синт. Выход: слышимая разница «симметричный образец ↔
консонантный паттерн», пресеты Reveal/Compose различимы на слух.

**Фаза 3 — CV-выходы.** DAC + масштабирование, калибровка 1V/oct, gate.
Интеграция со стойкой Eurorack (стенд снаружи кейса).

**Фаза 4 — модуль.** Плата, панель, питание ±12 В, органы управления,
слот пластины на панели. Отдельный пакет документов.

**Фаза 5 — R&D второго канала.** Ёмкостная матрица (или пьезо-возбуждение
«настоящий резервуар») — по итогам фазы 2–3.

## Принцип работы по шагам

Каждая фаза закрывается контрольной точкой из 08-TEST-PLAN.md. Не начинаем
железо следующей фазы, пока не пройдена контрольная точка текущей.
