# 08 — План бринг-апа и проверки

Каждая фаза заканчивается контрольной точкой (КТ). Не переходим дальше,
пока КТ не закрыта. Результаты фиксируются в `docs/eurorack-sequencer/lab/`
(журнал: дата, кадры, выводы).

## Фаза 1 — стенд захвата

- **T1.1 Камера жива.** DCMI+DMA, кадр QVGA в RAM, дамп по USB на
  просмотрщик. Критерий: стабильные 10+ fps без срывов DMA 10 минут.
- **T1.2 Авторежимы убиты.** Два кадра одной сцены с интервалом 10 мин
  идентичны в пределах шума (|Δ| медиана ≤ 1 LSB): AEC/AGC/AWB выключены,
  подсветка стабильна.
- **T1.3 Юстировка.** Мира MIRA: ROI покрывает окно 25×25, фокус даёт
  различимость клетки 0.8 мм.
- **T1.4 Flat-field.** После калибровки BLANK-пластина → карта, плоская
  в пределах ±2 LSB.
- **T1.5 Повторяемость вставки (КТ фазы).** 10 циклов вынуть/вставить
  реальный образец: карты совпадают, средний |Δ| ≤ 2 LSB, максимум ≤ 8 LSB.
  Если нет — дорабатывается регистрация (04 §3), не софт.

## Фаза 2 — метрики и музыка

- **T-M1 Метрология метрик** (на PATTERN-SET):
  - D монотонна по трём плотностям случайных точек;
  - S: шахматка ≫ BLANK; радиальная мира — градиент S от центра;
  - R: радиальная мира > 0.9; случайные точки < 0.3; повёрнутая на 90°
    шахматка не меняет R (инвариантность).
  По результатам фиксируются константы нормировки (05 §3) — далее
  не трогаются.
- **T-M2 Слепой тест пресетов (КТ).** Один образец, 8 фрагментов по 30 с
  вперемешку Reveal/Compose; слушатель (не автор прошивки) сортирует.
  Критерий: ≥ 7/8.
- **T-M3 Главный тезис (КТ).** Пары образцов «регулярный vs нерегулярный»
  (соль vs пемза; купорос vs губка). Слушатели ранжируют фрагменты по
  «упорядоченности/консонантности» вслепую. Критерий: ранжировка совпадает
  с физической регулярностью в ≥ 80% пар. **Это главный тест проекта.**
- **T-M4 Детерминизм.** Перезагрузка стенда + повторная вставка → та же
  MIDI-последовательность побайтово (при том же клоке).
- **E3 (эксперимент, не КТ).** Скрещенные поляризаторы на купоросе:
  оценить прирост контраста карты; решить, входит ли поворотное кольцо
  поляризатора в модуль фазы 4.
- **E4 (эксперимент).** «Живой» образец: скан во время роста соли из
  капли рассола, 2–4 часа, таймлапс карт + MIDI-лог. Материал для
  инсталляционного режима.

## Фаза 3 — CV

- **T3.1 Калибровка 1V/oct**: по мультиметру во всех октавах ≤ ±3 цента.
- **T3.2 Gate**: фронт < 1 мс, без дребезга на медленных G.
- **T3.3 Интеграция (КТ).** Стенд играет VCO+VCF+VCA в кейсе 30 минут:
  без петель земли (гул), без зависаний, паттерн музыкально управляем
  ручками стенда (CLI): темп, траектория, пресет, root.

## Регрессия (постоянно)

Golden-тесты core на ПК (05 §8) — на каждый коммит прошивки. Записанный
набор кадров реальных образцов пополняется по мере выращивания корпуса.
