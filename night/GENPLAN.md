**Мир:** планета-диск, радиус — время, **лучи — традиции**. Городок в
центре, кольца эпох общие для всех лучей, белый обод «сейчас» — общий
финал, за ним брейнрот. Интерактивная карта с номерами: артефакт
«genplan» (claude.ai/code/artifacts).

1. **Генерация** (Higgsfield) — качество борда рефов: красно-чёрная
   живопись, один тёплый источник.
2. **Ротапринт-пост** (обязателен): 4 краски НОЧЬ/УМБРА/ПЕПЕЛ/КОСТЬ +
   Байер 8×8; тепло (свеча/киноварь) НЕ растрируется; края осыпаются.
   Скрипт: `scratchpad/rotaprint.js` (перенести в tools/ при
   промышленном прогоне).
3. **Бумага**: оттиск всегда на листе — гриф, подпись, кривая печать.
4. **Слоты в игре** (рантайм остаётся вектором):
   - *лист местности* — полноэкранный оттиск при входе в зону;
   - *вклейка-осмотр* — объект/здание по E;
   - *протокол* — портрет в диалоге.

## Правила (нарушение = откат)

- Красный один: печать = полдень = кровь луны. Тёплых пятен ≤ 3.
- Растр живёт только на оттисках; голым на экран не кладётся.
- Тон — только точками матрицы, градиент без растра запрещён.
- Идеальная печать — подделка: гриф криво, края осыпаются.
