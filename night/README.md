# ardet · «Ночь и канцелярия» — векторный прототип

Прототип нового направления (арт-библия 2a): мир — ночной офорт в векторе,
вся система — казённая бумага, растр живёт только на вклейках.

## Запуск

Открыть `index.html` в браузере. Файл самодостаточен: шрифты
(Cormorant Garamond / Montserrat / UnifrakturMaguntia) и обе вклейки
вшиты base64, сети не требуется.

## Что внутри (два квартала)

1. **Городок** — жертвенный костёр с Шутом (протокол беседы + вклейка-тушь),
   пифос, погасший фонарь, канцелярия с окном №3, доска объявлений
   («утеряно: смысл»), блюдце молока, врата.
2. **Веха дороги · за вратами** — кровавая луна с гравюрным ореолом
   (линии неба обтекают диск), горящий изнутри собор (роза-колесо,
   стрельчатые окна), пожары на руинах, кресты, мёртвое дерево,
   пустая рама в конце дороги.

## Топология: свободный ход по диску

Мир — поверхность, не коридор. Две оси: **вверх экрана — к центру
диска (в прошлое), вниз — к ободу (в будущее), вбок — вдоль кольца**
(по кругу через традиции одной эпохи; кольцо замкнуто — уйдя влево,
вернёшься справа). Переходы между кольцами — просто дойди до кромки:
угол сохраняется, ты остаёшься в своей традиции. Врата остаются как
именованный портал (строка первого прохода — за ними). Ходить можно всюду.

**Закон края** (полный тезис, канон дословно; хвост «назад — всегда»
отдельно не тиражируется): *«в безвременье никто не падает — туда
заходят сами, последним движением, при открытой дороге назад».*

**Городок не тиражируется.** Сделав полный круг по кольцу и вернувшись
в центр, странник находит городок постиндустриальной развалиной:
окно №3 темно, приём окончен. Уцелели костёр, Шут и блюдце — молоко
в нём свежее. Гераклит ногами: войти второй раз некуда.
Сектора юга/востока/запада и дальние кольца — строятся.

## Управление

- `← →` / `A D` — идти
- `E` / `Enter` — осмотреть · говорить (или клик по подсказке)
- `Esc` — форма 0 (меню-бланк)
- `1 / 2 / 3` — вечер / ночь / красный полдень (фазы также сменяются сами, цикл ~12 минут)

## Устройство

- `scene_gen.js` — генератор гравюры: display list (`rect|poly|circle|glow|path`)
  + штрихи, сгруппированные по цвету и толщине. Тональная система: плотность
  штриха = свет; 4 чередующихся порога. Небо — потоковые линии (обтекание
  цилиндра) вокруг луны. Работает в node (офлайн-превью) и в браузере (SVG).
- Все цвета — токены двух регистров палитры 2a через CSS-переменные:
  фаза суток меняется заменой переменных, без перерисовки геометрии.
- Правила библии соблюдены: красный один (печать = полуденное небо = кровь
  луны), тёплых пятен ≤ 3 (костёр, окно №3, фонарь странника), скруглений
  нет, растр — только на вклейках протоколов и листов осмотра.
