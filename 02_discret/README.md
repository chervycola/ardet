# 02 · ДИСКРЕТ

Материалы форума **ДИСКРЕТ** — научно-технического форума творческого
приборостроения (сайт [diskret.space](http://diskret.space/) · дискрет.рф).
Форум прошёл **19 сентября 2026 года в Зеленограде, в МИЭТ**: экспо из 29
участников, лекторий в двух залах, мастерские, детская программа и живая
программа.

Здесь лежит всё, что было сделано для форума: визуальная система и шаблоны
карточек, готовые карточки и афиши для Telegram, Instagram и печати,
мини-приложение для Telegram (оно же сайт), бот, тексты для прессы и
канала, генераторы карточек.

Слоган визуальной системы: **«Не растворяется. Переключается.»**

## Как пользоваться

- **Посмотреть систему.** Открыть [`branding/preview.html`](branding/preview.html)
  в браузере. Правила и рамки описаны в [`branding/README.md`](branding/README.md).
- **Сделать карточку участника.** Взять шаблон из
  [`branding/frames/`](branding/frames/), подставить фото и текст
  (порядок описан в [`branding/frames/README.md`](branding/frames/README.md)),
  экспортировать в PNG.
- **Найти готовую карточку.** Каталог серий с датами — в
  [`branding/renders/README.md`](branding/renders/README.md). Почти у каждого
  PNG рядом лежит SVG-исходник с живым текстом.
- **Пересобрать серию генератором.** `node branding/tools/gen_<серия>.js`
  (Node.js 18+, пакеты ставить не нужно). Скрипт перезаписывает SVG в
  `branding/renders/<серия>/`; PNG после этого надо отрендерить заново.
  Таблица «скрипт → файлы» — в [`branding/tools/README.md`](branding/tools/README.md).
- **Развернуть сайт / мини-приложение.** Содержимое [`branding/app/`](branding/app/)
  заливается в корень хостинга (Apache + PHP для формы Д-10). Подробности и
  подключение в Telegram — в [`branding/app/README.md`](branding/app/README.md).
- **Поднять бота.** [`branding/bot/README.md`](branding/bot/README.md);
  переезд на новое имя — [`branding/bot/MIGRATION.md`](branding/bot/MIGRATION.md).

## Чего нет в репозитории

Эти файлы живут только на хостинге или у оргкоманды, сюда их не добавляли:

- `branding/bot/config.php` — токен бота (в `.gitignore`), шаблон — `config.example.php`;
- `branding/app/telegram-web-app.js` — SDK Telegram, лежит на своём домене; если его нет, страница грузит SDK с telegram.org;
- `branding/app/photos/f26_*.jpg` — снимки для галереи «Фото 2026»: если файла нет, плитка просто не показывается;
- `branding/app/d10_inbox/*` — присланные анкеты Д-10 (папка закрыта от чтения через `.htaccess`).

## Известные недочёты снапшота

Рабочие файлы не правились, чтобы не расходиться с тем, что лежит на хостинге:

- в мини-приложении у девайса № 28 «СОЮЗ 017 FET» нет фото: в данных указан
  ключ `soyuz017`, а в `window.PHOTOS` его нет, хотя файл
  `branding/app/photos/soyuz017.png` на месте. Исправление — одна строка, см.
  [`branding/app/README.md`](branding/app/README.md);
- `branding/renders/wave5/soyuz-photo.png` остался от первой версии карточки
  СОЮЗ, финальная `soyuz-01.svg` его не использует;
- исходная инструкция в [`branding/photos/README.md`](branding/photos/README.md)
  («запушьте в ветку…») относится к работе в ветке и сейчас неактуальна.
