# Редактируемые макеты (для Illustrator / Photoshop)

**SVG** — основной редактируемый формат. Illustrator открывает нативно, все надписи
остаются живым текстом. Фото вшито в файл (base64), ссылки не бьются.

- `frame-A-pribor-groovebox-editable.svg`
- `frame-D-forum-groovebox-editable.svg`
- `*.pdf` — то же в вектор-PDF (текст = текст), открывается и в AI, и в PS.

## Шрифты (замените текст своими — гарнитуры системные)
- Имя (жирный гротеск): **Helvetica Neue / Arial Bold**
- Номера и метки приборной рамки: **Arial Narrow**
- Подписи, роли, техданные: **Courier New** (моно)

## Как править
- **Illustrator:** открыть `.svg` → кликнуть по надписи → изменить текст.
  Фото — заменить/перелинковать. Экспорт: File → Export → PNG/JPG (1080×1350, 2×).
- **Photoshop:** текст в SVG/PDF при импорте растрируется — для правки текста
  используйте Illustrator. Пустые мастера без фото — в `branding/frames/`.
