# Готовые карточки и макеты ДИСКРЕТА

Сюда складывается результат: фото из [`../photos/`](../photos/) и
[`../app/photos/`](../app/photos/), вставленные в рамки из
[`../frames/`](../frames/), плюс серии, собранные генераторами из
[`../tools/`](../tools/).

Почти у каждого PNG рядом лежит SVG-исходник с живым текстом: его можно
поправить в Illustrator / Inkscape или в текстовом редакторе и отрендерить
заново. Формат по умолчанию — 1080×1350 (4:5, лента Telegram и Instagram),
отклонения указаны в таблице. Фото в карточки волн подключены ссылками
`../../photos/…` и `../../app/photos/…`, поэтому папку `renders/` нельзя
переносить отдельно от `photos/` и `app/`.

> Исходная заглушка этого файла (13.07.2026): «готовые карточки участников
> (PNG 1080x1350); сюда я складываю результат из branding/photos через
> branding/frames».

## Как пересобрать

- Серии с генератором (`afisha/afisha-tg-sostav`, `afisha/programma-tg`,
  `afisha/setka-a3`, `cert/*`, `final/`, `insta/`, `insta-mk/`, `mk-post/`,
  `photos-post/`, `prize/`, `setka-post/`, `wave5/*-01`) пересобираются
  скриптами из [`../tools/`](../tools/README.md) — они перезаписывают SVG.
- Остальные серии генератора в репозитории не имеют: правится сам SVG.
- PNG получаются рендером SVG в нужный размер (например, headless Chromium,
  команда — в [`../README.md`](../README.md)).
