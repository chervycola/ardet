# Рамки карточек участников

Пустые мастер-шаблоны визуальной системы ДИСКРЕТ. Все файлы — SVG 1080×1350
(4:5), открываются в Figma / Illustrator / Inkscape и в браузере. Правила
системы и выбор рамки — в [`../README.md`](../README.md), наглядно — в
[`../preview.html`](../preview.html).

## Как собрать карточку

1. Скопировать шаблон рядом с фото (или в нужную папку `../renders/<серия>/`).
2. Заменить `PHOTO.jpg` в `<image href="PHOTO.jpg">` на путь к снимку —
   кадрирование по слоту автоматическое. В пустых шаблонах эта ссылка
   никуда не ведёт, так задумано.
3. Поправить узлы с пометкой `EDIT`: имя, роль, номер, дата, место.
4. Отрендерить в PNG (см. [`../README.md`](../README.md), раздел «Как собрать
   карточку участника»).

Готовые примеры: [`../renders/editable/`](../renders/editable/) — те же рамки
A и D с вшитым фото, плюс PDF.
