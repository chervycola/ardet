# ДИСКРЕТ · Telegram Mini App

Приложение — **`index.html` (~140 КБ) + папка `photos/`** (фото отдельными
файлами, подгружаются лениво по мере открытия карточек). Работает как Mini App
внутри Telegram и как обычная веб-страница (фолбэк).

**Заливать на хостинг нужно ОБА: `index.html` и папку `photos/` рядом с ним**
(структура как в этом каталоге). Новые фото: положить jpg в `photos/` и
добавить ключ в `window.PHOTOS` вверху `<script>`.

## Вкладки (нижнее меню, 4 шт.)
- **Форум** — стартовый экран: манифест «Что такое Дискрет», дата/место и **хроника анонсов**
  (прогресс-бар: сколько постов вышло из `EVENT.total`; ось строится автоматически, напр. 0·5·10·15·20).
- **Лента** — дубли постов из Telegram: карточка с фото, датой, №, текстом (сворачивается до 5 строк).
  Тап → пост на весь экран (карусель фото, полный текст, кнопка «В Telegram»).
- **Девайсы** — карточки прибор-первым: фото, №, название, компания-ссылка · суть · город, 4 тега
  (форм-фактор · воис/эффект · MIDI/CV · аналог/цифра). Тап → детальная карточка (листается ‹ ›).
- **Расписание** — таймлайн по рабочей сетке (черновик), фильтр по залам (тап по залу),
  тап по строке → карточка автора/девайса.

## Меню (кнопка ▦ в шапке)
- **О нас** — манифест, принципы, ссылка на сайт.
- **Компании** — список компаний; карточка = логотип/название → участники → товары; с товара переход обратно на компанию.
- **Обратная связь** — Telegram / почта + поле сообщения.
- **Конкурс** — розыгрыш среди гостей с билетом: номер билета → заявка (локально + `sendData` боту).
- **Сканировать QR** — сканер стоек (открывает карточку прибора по коду).
- **Язык** — три варианта: **Русский · Пацанский (90-е) · Зумерский**. Переводится весь интерфейс и манифест; факт-данные (спеки, имена, расписание) остаются как есть.
- **Тема** — светлая ⇄ тёмная (по умолчанию светлая; при старте подхватывает тему Telegram).

## Данные (правятся вверху `<script>` в `index.html`)
- `P` — девайсы (id, название, автор, `company`, суть, город, роль, спек, сцена, время, теги, `desc`, фото, ссылки).
- `POSTS` — **Лента**: `{ date, title, text, photos:["ключ"], link }`, новые сверху. Хроника форума считается от длины `POSTS`.
- `SCHED` / `ROOMS` — расписание и залы.
- `A` — авторы/спикеры (страницы-заготовки).
- `C` — компании (логотип/фото, участники, `products[]`, ссылки, описание).
- `EVENT` — дата, место, `total` (план постов для хроники).
- `CONTACT` — Telegram `diskret_space`, сайт `diskret.space`, почта `contact@diskret.space`.
- `LOTTERY` — приз и дата розыгрыша.
- `PHOTOS` — картинки (base64). Новые кладём в `branding/photos/` и добавляем в `PHOTOS` тем же ключом.
- `L` — словарь переводов (ru / bratva / zoomer). Хром берётся через `t("ключ")`.

## Deep-links (QR у стоек, кнопки бота)
Приложение открывается сразу на нужном месте. Токен передаётся через `?k=…`
(web-app кнопка), `?startapp=…` (ссылка `t.me/бот/апп`) или `#…` (браузер):
- `d_<id>` — девайс (напр. `d_archeon`)
- `c_<id>` — компания (`c_efemi`)
- `a_<id>` — автор (`a_polina`)
- `t_forum | t_posts | t_devices | t_schedule` — вкладка

## Как включить в Telegram
1. **Захостить `index.html` по HTTPS** (Netlify / Vercel / GitHub Pages / свой хостинг).
2. **@BotFather** → `/newapp` (Mini App со ссылкой `t.me/бот/апп`) и/или `/setmenubutton` (кнопка у поля ввода).
3. **Бот с действиями** — см. `../bot/` (готовый PHP-вебхук: `/start`, команды, кнопки, приём заявок).

> SDK: `<script src="https://telegram.org/js/telegram-web-app.js">`. Вне Telegram не обязателен — фолбэк.

Хостинг: Apache с `mod_rewrite` и PHP 7.4+ (как для бота) с расширением `mbstring`
(`fileinfo` желательно: без него тип фото берётся из заголовка браузера, а не
по содержимому). Каталог заливается в корень сайта (`RewriteBase /`), скрытые
`.htaccess` и `.user.ini` — тоже. В
репозитории нет и подкладываются на сервере: `telegram-web-app.js` (если его
нет, SDK грузится с telegram.org) и `photos/f26_*.jpg` для галереи
«Фото 2026» (отсутствующие плитки скрываются). Локально `index.html`
открывается и без сервера; маршруты и форма требуют Apache + PHP.
