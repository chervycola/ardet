# ПАСХАЛЬНЫЙ ФОНД
### опись скрытого · к делу о мире · пополняемая

Правила фонда (из законов каркаса):
1. **Пасхалка — не кнопка.** Упоминается вскользь, стоит в тени,
   никогда не подсвечивается. Награда — сам факт замечания
   (глубина не геймифицируется: без ачивок, отметка — только
   в терминале для нердов).
2. **Юмор несущий.** Каждая позиция несёт смысловой груз, а не
   только подмигивает. Отсылка без груза в фонд не принимается.
3. **Три глубины**: **I** — видна при внимательной прогулке;
   **II** — вторым взглядом / с другого ракурса; **III** —
   археология (сопоставить несколько картин, эпох, документов).
4. Цель плотности: **10–15 позиций на картину**, из них не больше
   трёх глубины I — остальное глубже.
5. Раскладка по клеткам — отдельным листом после набора фонда.
