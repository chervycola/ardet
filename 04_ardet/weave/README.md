# weave/ — рабочая мастерская мира

«Ткань мира»: задания, расчёты, аудиты текста, промты генерации и эталонные картинки,
по которым строится игра. Канон и философия лежат в `../src/assets/`; здесь — то, что
делается по канону: проектные записки с решениями автора, сырые данные проверок и
принятые эталоны. Большинство документов начинается со строки статуса и даты.

Начинать с [`HANDOFF.md`](HANDOFF.md) — передача сессии: где что лежит, как собирать,
ключевые правила канона. Пути вида `src/…`, `weave/…` в документах — относительно папки
игры `04_ardet/`.
