# assets/ — файлы, которые лежат рядом с собранной игрой

Медиа, которые не вшиваются в `build/index.html`, а грузятся рядом с ним: на сайте — из
`assets/` рядом со страницей; при локальном запуске музыка и портреты находятся в
`../assets/` относительно `build/` (у плеера и загрузчика есть запасной путь), а значки
страницы — нет (их путь в `<head>` жёсткий, `assets/icons/…`).

## Содержимое

| Путь | Что это |
|---|---|
| `icons/` | Значки сайта: `favicon-32.png`, `apple-touch-icon.png`, `icon-512.png` (из эмблемы) |
| `logo/ardet-emblem.jpg` | Эмблема автора — источник значков |
| `music/` | Музыка мира: `title.mp3` (заставка, 24,6 МБ); правила эфира и имена будущих треков — [`music/README.md`](music/README.md) |
| `portraits/` | *Пока нет.* Сюда кладутся портреты для диалогов (`jester.png`, `sol.png` и т.д., список — `../src/assets/manifest.js`, задание — `../weave/PORTRAITS.md`). Игра подхватывает файл сама; пока файла нет, рамки нет |

## Деплой

На хостинг рядом с `index.html` и `mobile.html` заливаются `assets/icons/` и
`assets/music/` (подробнее — `../weave/HANDOFF.md`, раздел «Где всё»).
