# build/ — собранная игра

Вывод `node build.js`. Три HTML закоммичены, чтобы играть без сборки; всё остальное,
что сборка кладёт сюда (например, `build/assets/`), в git не попадает (`../.gitignore`).
Руками эти файлы не править — они перезаписываются при каждой сборке.

| Файл | Что это |
|---|---|
| `index.html` | Игра для компьютера — один самодостаточный файл (~3,4 МБ) |
| `mobile.html` | То же для телефона (`window.ARDET_MOBILE=1`) |
| `ardet.html` | Копия `index.html` под историческим именем |

## Как открыть

Открыть `index.html` в браузере. Музыка (и портреты, когда появятся) ищется в `assets/`
рядом со страницей, затем в `../assets/`; музыка грузится через `fetch`, поэтому надёжнее
через локальный сервер из `04_ardet/`: `python3 -m http.server 8000` →
`http://localhost:8000/build/index.html`. Полезные ключи адреса: `?stream` (режим
охоты), `?dev` (отладочные клавиши), `?editor` (редактор текстов), `?nohouse`
(старт с места сохранения), `?net=local` / `?net=off`.

## Происхождение

Сборка из ветки `origin/claude/philosophy-architecture-update-oDemg`, снапшот `8b36e63`
(2026-10-24): HTML пересобраны и закоммичены в этом же коммите. Оттиск версии в файлах —
`2c24907 · 2026-10-24`: `build.js` пишет в оттиск текущий `HEAD`, а сборка делается до
коммита, поэтому в оттиске стоит родительский коммит. Пересборка исходников `8b36e63` при
сборке монорепо дала тот же результат до байта, кроме оттиска.

Значки страницы (`assets/icons/…` в `<head>`) при локальном открытии не находятся: путь
считается от `build/`, а `build/assets/` сборка не наполняет. На сайте `assets/` лежит
рядом со страницей, и значки работают.
