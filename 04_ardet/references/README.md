# references/ — референсы автора

Картинки, которые автор прислал как образцы настроения, палитры и сцен для эпох мира.
Загружены одним коммитом `e6a2999` («ref», 2026-07-09) в корень ветки
`claude/philosophy-architecture-update-oDemg`; при сборке монорепо перенесены сюда без
переименования (имена файлов — авторские, см. навык `ardet-ref-intake`: «не переименовывай
файлы пользователя»).

В игру эти картинки не входят: сборка `node build.js` их не копирует. Их используют:

- опись клеток диска `../src/content/world_weave.js` (`KNOWN[…].refs` — имена файлов);
- таблица ролей `../src/assets/EPOCH_SCENES.md` (сцена / событие / интерьер / объект / вставка);
- прототипы `../prototype/epoch-walk.html` и `../prototype/hybrid-scene.html` грузят их
  по пути `../references/<имя>` (путь поправлен при переносе; раньше был `../<имя>`).

4 два очага · 5 мелкий шрифт · 6 пар и тени · 7 век катастроф · 8 неон · 9 сейчас · край.
