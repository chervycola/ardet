# test/ — тесты игры

Тесты — обычные скрипты Node (ES-модули), без тестового фреймворка и без зависимостей:
подставляют заглушки DOM, canvas и `localStorage` и гоняют модули `../src/` напрямую.
Каждый скрипт печатает `✓`/`✗` по проверкам и итог `N/N passed`; при провале выходит
с ненулевым кодом.

## Запуск

Из папки `04_ardet/`:

```bash
npm test                    # восемь наборов подряд (см. package.json → scripts.test)
node test/systems.mjs       # один набор
npm run test:architecture   # именованные скрипты: test:sprites, test:logic, test:systems,
                            # test:content, test:effects, test:ulitsa, test:potemkin
```

Сборка для тестов не нужна. Строка `[load] error: SyntaxError …` в выводе `logic.mjs` —
ожидаемая: так проверяется загрузка повреждённого сохранения.

## Наборы

| Файл | В `npm test` | Проверок | Что проверяет |
|---|---|---|---|
| `smoke-sprites.mjs` | да | прогон | Отрисовка всех NPC и игрока по кадрам — ловит ошибки выполнения (≈19 200 вызовов) |
| `logic.mjs` | да | 25 | Невизуальные модули: терминал, погода, сохранение, мир |
| `systems.mjs` | да | 180 | Частицы, камера, свет, монстры, питомцы, память сессии, зоны, диск и кольца, городок, изнанка |
| `content.mjs` | да | 30 | Реестр локаций, покрытие осмотров/диалогов/«использовать»/терминала, машины состояний |
| `effects.mjs` | да | 23 | Мох на экране, умирающие пиксели, трещины, Web Audio, концовка, переходы зон |
| `ulitsa.mjs` | да | 25 | Улица на поверхности мира: данные, привязка, физика коридора, звук зон |
| `potemkin.mjs` | да | 11 | Потёмкинская скорость: неподвижный взгляд проявляет подделку |
| `architecture.mjs` | да | 33 | Постройки эпох: контракт модулей колец, раскладка, осмотры, изнанки, глубина |
| `net.mjs` | нет | 28 | Сеть странников: фильтр, локальный транспорт, правила, Supabase-транспорт на подставном сервере |
| `house.mjs` | нет | 14 | Дом пробуждения: пол и мебель, выход в сени, окно по времени суток, свет |
| `backstage.mjs` | нет | 8 | «Машина за стеклом» (`render/backstage.js`): строки командной строки, блок-схемы, раскладка |

Три последних набора в `npm test` не входят — запускать отдельно: `node test/net.mjs` и т.д.
