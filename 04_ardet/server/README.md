# server/ — база для сети странников

Серверная часть одна: схема PostgreSQL для Supabase. Сеть странников (`../weave/NET.md`):
игроки, которые одновременно на сайте, видят друг друга, говорят рядом и оставляют
записки на земле. Шаги и речь идут через Supabase Realtime и нигде не хранятся;
в базе — только записки и отметки.

## Содержимое

| Файл | Что это |
|---|---|
| `supabase.sql` | Схема: записки живут 30 дней, три жалобы — записка скрыта, не больше 10 записок в сутки и одной в минуту от странника, брань и ссылки база не принимает. Выполнить один раз в Supabase → SQL Editor |
| `check.sql` | Проверка схемы без Supabase на любом PostgreSQL 15+: заглушки ролей и `auth.uid()`, затем `supabase.sql`, затем действия четырёх странников; печатает PASS/FAIL |

## Как проверить

```bash
createdb ardet_check
psql -X -v ON_ERROR_STOP=0 ardet_check -f server/check.sql 2>&1 | grep -E "PASS|FAIL"
dropdb ardet_check
```

(из папки `04_ardet/`). Сеть целиком (вход, Realtime, PostgREST) так не проверить —
только правила базы. Клиент — `../src/net/`; адрес проекта и публичный ключ —
`../src/net/config.js`; без сервера — режим `?net=local`, выключить — `?net=off`.
Тесты клиента — `node test/net.mjs`.
