# prototype/ — пробы рисовки и механик

Отдельные HTML-страницы, на которых проверялись стиль и идеи до переноса в игру
(`../src/`). Каждая открывается прямо в браузере, без сборки. Две страницы грузят
картинки из соседних папок, поэтому лучше открывать через локальный сервер из
`04_ardet/`:

```bash
python3 -m http.server 8000        # из папки 04_ardet/
# затем http://localhost:8000/prototype/epoch-walk.html
```

## Содержимое

| Файл / папка | Что это |
|---|---|
| `epoch-walk.html` | Маршрут эпох: цепочка сцен-задников из референсов (`../references/`), связанных переходами; странник с перспективным масштабом. Раскладка — `../src/assets/EPOCH_SCENES.md` |
| `hybrid-scene.html` | Гибридный рендер: растровый задник (`../references/реф город 1.jpg`) + процедурный странник, свет, зерно, рамка |
| `axial-south/index.html` | Клетка «чаша на фундаменте» (осевое время, юг) в регистре «Волшебников» Бакши: многоплановый кадр |
| `etching-game/index.html` | Играбельная проба «офорт»: петля как у Don't Starve, но без полос — состояние показывают свет и чернила |
| `etching-max.html` | Офорт «на максималках»: перекрёстный штрих Доре, свет как вещество |
| `red-noon.html` | «Красный полдень»: час без теней, кость и киноварь |
| `rotaprint-menu.html` | Нейростиль «казённый ротапринт»: квантование в 4 краски растром Байера, меню «форма 0» |
| `style-variants/index.html` | Одна сцена городка в четырёх рисовках: `?v=1` офорт «красная луна», `?v=2` ротапринт, `?v=3` театр теней, `?v=4` бумага дела |
| `world-map.html` | Карта-схема диска — лист 1 дела о мире (снятая копия данных `world_weave.js`) |
| `world-cells.html` | Опись клеток диска — лист 2 дела о мире |
| `fund-browser.html` | «Опись скрытого» — просмотрщик пасхального фонда с фильтрами |
| `shared/ardet-audio.js` | Плеер музыки v2 (треки по очереди, радио, коллекция) для прототипов; файлы — `../assets/music/`. Копия для игры — `../src/audio/ardet-tracks.js` |

Иконки страниц берутся из `../assets/icons/`.
