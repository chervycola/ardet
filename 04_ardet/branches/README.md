# branches/ — материалы боковых веток, не влитые в основную линию

Основа папки `04_ardet/` — ветка `claude/philosophy-architecture-update-oDemg`. Здесь
лежит то, что есть только в боковых ветках и не может быть положено на своё место
в основном дереве:

- файлы, путь которых совпадает с файлом основной линии, а содержание другое;
- файлы, которые основная линия сознательно заменила (их появление на штатном месте
  изменило бы поведение игры или противоречило бы текущему канону);
- правки кода в `src/`, которые не вошли в основную линию, — в виде патчей.

Всё, что из боковых веток легло на штатные места без конфликтов (`../night/`, новые файлы
в `../weave/`), здесь не дублируется. Общая картина по веткам, коммитам и статусу —
в [`../BRANCHES.md`](../BRANCHES.md).

## Как пользоваться патчами

Патчи сняты `git show --format=email` с исходных коммитов и ограничены путями `src/`,
`test/`, `build.js`, `package*.json` (сгенерированный `build/` исключён). Пути внутри
патчей — относительно папки игры. Из корня монорепо проверка выглядит так:

```bash
git apply --check --directory=04_ardet 04_ardet/branches/improve-writing-style/patches/08-4cbd940-obraz-blocks.patch
```

Ни один патч не прикладывается к текущему дереву чисто (проверено `git apply --check`
при сборке монорепо): основная линия с тех пор переписала те же тексты (аудиты, «ножницы»,
переплавка) или удалила модули. Патч — источник текста для ручного переноса, а не готовое
слияние.
